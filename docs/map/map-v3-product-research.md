# 地图 3.0 Goal02：产业园与混合办公市场研究

- 基于 Goal01 研究模块契约增量实现；PR 与 Goal01 有前置依赖，先完成 Goal01 的集成。
- `marketProducts` 来源为当前授权、在营、tracked、非未来供应的完整子市场目录。已知市场配置仅为目录不可读取/为空的后备值；地图筛选和研究 focus 不改变区域长期定位。
- `trends.all/a/b` 和 `stockCount` 保持传统 A/P/B 的原有范围；独立 `trends.park` 仅接受 BP/产业园；不生成跨产品综合租金。历史数据使用单次目录查询和共享分批历史读取，仍限制行数。
- 仅锁定、非草稿、真实年份及季度；复用确定性记录选择和原有正式季度统计分母及共同样本计算。价格和规模分布按有资格的项目观测计算分位数，不伪装为加权市场均价。
- 正式事实保留单个样本供系统核查。新产品研究展示以至少两个独立有效样本为最低可展示门槛，并保留季度、样本数与面积覆盖；单个样本不得呈现为市场均价或连接成趋势。此为防止单样本误导的最低规则，不等同于统计学代表性保证。
- 市场指标用完整授权范围；代表项目用当前可见项目，优先已有发布研究中的精选项目；缺少产品时从真实目录补充一个观察样本，不虚构项目描述。未来供应继续单列。
- 2026Q2 生产只读复算：上地 BP 50/50，租金 106.14、空置率 23.99%；望京-酒仙桥 A/P/B 37/37，126.81、17.57%；BP 34/34，116.97、25.57%；四季青 BP 6 个、仅 1 个有效样本。此处为开发时核验记录，不是前端常量。
- 不写生产数据，不治理 Q3，不改 AI 统计、权限、审计契约或 CI。回归夹具为合成数据；实际 CI 状态以 PR 检查为准。
