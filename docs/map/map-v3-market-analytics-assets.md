# 地图 3.0 Goal 03 — 市场分析与资产关联

开发以 #341 合并后的 main 为基础，未修改 #342 涉及的子市场路由、趋势模型或工作区布局文件。分析入口暂置于代表项目标准/完整研究面，后续 Goal 04 可复用独立组件重新编排，不另建地图系统。

## 数据与安全

- 深度分析由用户主动打开，走既有 /api/map/data 认证、角色、模拟用户和 no-store 边界，仅查询选定 1–3 个授权子市场及一个真实季度的正式 building_metrics，按 ID 去重，P 归甲，BP 独立。使用共享季度资格规则；空置率不从比例倒推正式季度空置面积。地图初始加载、过滤器与季度原始数据不变。
- 租金分布的中位数、四分位数为楼宇等权统计，市场平均租金按面积加权。少量样本不绘直方区间。散点同一行租金、面积与空置面积计算，不因没有地图坐标排除样本。
- 供给仅使用现行 future 状态、未入市、非 pending 记录；未确定年份单列。
- 成交使用统一 lease_transactions_read_v1 的 live/OPERATIONAL/exact 记录，按 source_record_id 去重，明确不与 history 混加。服务器仅传匿名聚合，非全市场成交；小类不足三笔不单列，不输出租户、合同、佣金、备注或联系人。仅在既有 live 成交读取授权下执行。
- 项目沿用稳定 ID、已有楼宇详情入口和现有授权照片 gallery、来源及许可显示。未新增外部照片。
- 生产只读核验（2026-11-27）：2026Q2 CBD A/P 40、B 34， 上地 BP 50，望京-酒仙桥 A/P 13、B 24、BP 34；全部有有效租金与配对空置面积。上地 BP 中位数 95.1、面积加权平均 106.1。未发现 Q3 符合正式资格的观测；未写生产数据。2025 起 exact building/期间/租户/面积跨来源重复组合初查为 0，不代表所有历史语义重复均已治理；因此明确只使用 live。
- 图片沿用已有签名预览与业务阅读审计，不请求原始楼书或批量全历史。深度分析失败与资料/供应失败互不伪装为零。

本 PR 不修改生产数据、权限、认证、CI 或 AI/Pitch。必要工程验证由 CI 按实际变更分流。
