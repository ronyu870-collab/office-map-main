# AI 回答引擎：本轮实现与验证边界

- Phase 01：保留正式季度快照、精确数值、权限及审计；新增 AI/地图同季度、同样本、无比例回填条件下的加权指标一致性测试。地图最新状态可混合季度、允许零租金及有效空置率回填；AI 使用指定季度、正租金、有效空置面积。这些既有业务差异不能通过显示层强行消除，须另行核对正式口径及数据库迁移，未改变生产规则。
- Phase 02：要求各期样本时优先返回样本表；服务端检查明确要求的样本数及各季度数值是否完整，未知不填零。
- Phase 03：依据提问偏好和数据结构选择直接指标、表格、图表；两期变化不称连续趋势；正文以获权计算结果为准。
- Phase 04：紧凑两期表、数字对齐、来源可核查、同口径样本摘要；保留完整表格工作台。
- Phase 05：趋势线、坐标轴格式及导出使用同源刻度和数据点；默认两期表格避免无必要图表请求。保留手动图表和导出。
- Phase 06：阅读宽度、信息分组、段间距及移动端局部滚动优化；不改变权限与主页入口设计。
- Phase 07：新增上述行为回归及数据完整性测试；成本优化仅针对不必要的图表请求，不声称完成全量模型评估或新增线上质量仪表盘。

回归测试为合成数据，不代表实际 CBD 生产数值。真实生产样本数、租金重算、全量模型评估和视觉验证应以独立真实结果为准。没有数据库写入或新增模型调用。
