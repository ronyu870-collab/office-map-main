## 提案套装（8，版本 1）

统一继承项目、语言、期间与主题；可逐页省略并保持注册顺序。每节可分别配置正式素材，或复制合成示例建立独立私人演示项目。

- **招商代理提案**（leasing-agency）：委托任务摘要 → 楼宇照片与核心参数 → 市场观察看板 → 招商策略摘要 → 目标客群分层 → 招商渠道分工 → 招商活动路线 → 项目负责人及团队 → 服务费用与范围 → 决策请求与行动。
- **租户代表提案**（tenant-representation）：委托任务摘要 → 租户需求概要 → 选址候选项目 → 租赁方案评价 → 续租与搬迁决策 → 租户成本驱动因素 → 选址服务流程 → 搬迁关键里程碑 → 商务条款清单 → 决策请求与行动。
- **办公空间咨询提案**（workplace-advisory）：提案议程 → 客户需求优先级 → 办公空间设计原则 → 办公空间意向 → 标准层方案对照 → 项目技术条件核对 → 租户成本驱动因素 → 项目工作流 → 报价方案条件 → 提案结论与依据。
- **市场研究汇报**（market-review）：提案议程 → 市场观察看板 → 租金趋势与解释 → 空置变化与样本 → 供需双图分析 → 子市场数据与观点 → 政策事实与适用性 → 市场情景假设 → 研究结论与证据 → 来源与证据索引。
- **资产定位与提升**（asset-positioning）：委托任务摘要 → 项目空间叙事 → 现场观察记录 → 项目定位框架 → 改造前后方案 → 项目配套图集 → 目标客群分层 → 收益测算前提 → 项目阶段门 → 决策请求与行动。
- **办公组合策略**（portfolio-strategy）：决策事项简报 → 租户需求概要 → 选址候选项目 → 租金空置成交三图 → 成本方案比较 → 成本敏感性分析 → 提案假设与条件 → 项目工作流 → 范围变更影响 → 提案结论与依据。
- **项目尽职核查**（due-diligence）：服务范围边界 → 楼宇技术参数 → 项目技术条件核对 → 项目到达体验 → 数据质量记录 → 项目风险摘要 → 风险与责任人 → 商务条款清单 → 客户确认事项 → 项目移交计划。
- **业务回顾与计划**（business-review）：委托任务摘要 → 分期间市场回顾 → 招商目标与实际 → 招商机会清单 → 预算与执行 → 服务价值案例 → 阶段成果对照 → 项目复盘与经验 → 下一阶段行动 → 提案结论与依据。
