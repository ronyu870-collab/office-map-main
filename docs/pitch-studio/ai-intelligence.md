# Pitch Studio AI、资料处理与持续学习

阶段 06 基线：阶段 05 `ceec2d288280f8029224e2f6ec60ae466bfca1a3`（PR #313）。迁移 `20261126090000_pitch_studio_ai.sql` 只增加结构与默认关闭配置，不开启试点、不授予账号权限、不上传生产事实。前五阶段协议与内部研究报告契约保持兼容。

## 使用入口

进入 Pitch Studio，创建或重开项目，在左侧“辅助”中输入单页需求，查看识别结果后点击生成。普通读数、生成、排序、筛选、导出、模板匹配、查找素材和提纲建议均不调用模型。素材选择后可按同一模板生成多人团队或案例组合。推荐可以忽略。

“提案结构建议”按已发布获权的公司、团队、案例、研究资料推荐板块。可修改标题、上移、移除和用所选素材替换。明确点击确认才逐项执行最多 8 个板块；复用阶段 05 持久生成任务、乐观版本、权限检查及真实状态，不把排队当作完成。失败时保留完成页面。停止后续操作不撤销服务端已领取的单页任务，后者在原任务记录中取消或恢复。关闭浏览器后完成页面保留，尚未提交的提纲编辑需要重新选择；不宣称无人值守完整提案自动生成。

已有 Colliers AI 遇到明确 Pitch Studio／商务提案请求时，只按需携带 4 个准备工具。普通查询目录不加入 Pitch 工具。其余严格工具注册在现有 `toolRegistry`，执行器复用工作台、可信数据适配和真实导出，不能执行 SQL、脚本或任意 XML。普通 Agent 的模型观察仅有素材 ID、受控计划及状态，不带企业正文、标题或客户名称；既有 `knowledgeModelObservation` 的私有正文保护未修改。工具返回的项目链接可直接恢复获权项目。

管理员本人可在“管理中心 → AI 与持续学习”维护模型、指定素材版本处理授权、查看任务与费用样本、形成草稿与审核主动提交的页面。既有 AI 审计台提供该入口，复用同一供应商适配器、`createModelRuntime`、`agent-model-attempt/1` 和 `ModelOperationsSummary`，不建立另一套模型 HTTP 客户端。现有 Colliers AI 的 admin 限制、OpenAI 操作账号名单和数据权限不放宽。普通员工仍可使用 Pitch 确定性功能。

## 十二类任务与执行路线

| 任务 | 实际路径 |
| --- | --- |
| 内容分类 | 明确标题／结构规则直接完成；歧义可经授权交给提取模型 |
| 结构化提取 | 获批文本 → 提取模型 → 严格证据校验 |
| 摘要 | 获批文本 → 模型；标为 AI 摘要，不升级为事实 |
| 案例理解 | 提取事实、业务用途、观点、敏感类别、时效与复用类型 |
| 模板匹配 | 结构化内容、分类及已注册业务模板的确定性候选与理由 |
| 布局推荐 | 原生图、表、团队、案例、时间线、图片对应不同布局 |
| 语义相关检索 | 现有中文二元关键词、标题和结构筛选回退；不伪装向量能力 |
| 案例推荐 | 已发布、语言、范围、服务、物业、日期过滤；市场、子市场、行业、体量、标题与标签评分 |
| 市场观点 | 已授权证据 → 分析模型；数值不由模型计算，未知项保留 |
| 自然语言配置 | 严格独立请求，显式当前选择，现有可信期间／语义计划，不继承旧会话范围 |
| 多页结构 | 结构筛选和已存在素材构建可编辑候选提纲；确认后有限执行 |
| 文字修订 | 原文段落／标题的 ref → 修订文本；保留数字，双语目标，形成待核对草稿 |

检索、推荐、自然语言和提纲有独立端点操作，不把这些任务伪装成文档摘要批处理。误投文档任务接口明确返回 `PITCH_AI_TASK_ROUTE`。

## 模型设置与成本

设置包含默认、分类提取、分析表达 3 个文本模型槽位；每个槽位指定现有 DeepSeek 或 OpenAI、真实模型名、输入输出合计 Token 上限、输出 Token、超时、任务美元预算与运营方每百万 Token 费用上界。提取／分析未指定时继承默认槽位。模型密钥只使用既有服务端环境，浏览器、迁移和数据库配置不含密钥。

管理员可设置全局及任务开关、每页输入 UTF-8 字节、0–2 次显式重试、1–3 并发、批次、每日、每月美元预算。每日／每月按上海时区与**实际预留时间**计算，不按很早创建的任务时间计算。数据库原子预留账本防止多实例并发透支。任务跨日期重试仍计入本次期间。供应商未报告用量保留全部上界预留；已知用量记录真实报告与估算，规划账本仍保守保留，实际超出预留则补记。费用不是供应商账单，实际账单保持 `null / not_reconciled`。普通 Colliers AI 预算与此任务队列独立。

每个文档任务最多一次模型调用，SDK 不额外自动重试，不继承普通 Agent 的工具、多轮或降级。手动重试才领取新租约与预留。输入超限明确失败，不截断正文。未配置模型、密钥或独立授权时显示未完成原因；不会影响确定性制页与导出。

视觉、图片 OCR、Embedding、受控内部 AI 执行器与跨供应商降级当前未实现，因此配置明确关闭或不可运行。不能将内部模式自动改成外部服务，也不能以文本模型声称已读截图。

## 独立资料处理授权

| 方式 | 服务端约束 |
| --- | --- |
| `deterministic_only` | 默认；不向模型发送资料 |
| `controlled_internal_ai` | 保留明确策略，当前没有受控内部执行器，外部执行拒绝 |
| `redacted_external` | 管理员逐项核对后提交单独文本，只发送该文本；不运行“尽力脱敏”后自动发送全文 |
| `approved_provider` | 指定素材版本、供应商、模型，并且仍满足已有 `ai` 资格、版本允许外传、正式状态与非测试数据条件 |

策略绑定素材版本、修订、期限（最长 90 天）、批准账号及依据。每次模型前、预算预留前及完成交付前复核当前策略、配置、身份会话、原件与资产权限。模型名／供应商不匹配即拒绝；全局故障降级开关不会扩大授权。历史备注、隐藏页对象、图片原始字节、外部链接不会进入证据构造。

脱敏不是删除客户名称的前端 CSS。只允许经核对的新文本进入模型；模型的缓存、错误、运营记录、导出元数据不携带限制正文。模型错误只保存固定错误码。现有知识模块仍只向普通模型返回元信息，不能通过 Pitch 工具读取原件。

正文与模型产出保存在私有任务／缓存表中，无浏览器、anon 或 service-role 直接表访问；受控 RPC 为唯一入口。任务结果读取也复核当前权限。缓存按账号、素材／内容哈希、版本、解析与提示协议、模型／配置、授权策略、任务参数和脱敏文本哈希隔离。缓存有效期 30 天；撤回或权限变动使旧命中失效，不把缓存键当作授权。没有跨权限相似图片或向量去重通道。

## 理解协议、证据和再生成

`pitch-understanding/1` 分开记录原文逐字事实、AI 摘要／建议、未确认项、敏感类别、用途、分类推断、时效、模板、布局与可复用类型。事实必须 `text === quote` 且 quote 在指定证据 ref；不能引用不存在的隐藏备注。摘要数字必须存在于获批上下文，不接受任意新数字、脚本、任意模板 ID 和明确夸张因果表达。这些是防错约束，不宣称能证明模型全部语义正确，仍需要业务核对。

文字修订只修改支持的标题和段落 ref，所有数值保留；表格和图表数值由代码保留。脱敏修订仅覆盖获批片段，形成明确标识的单独页面草稿，不冒称全文翻译。复杂案例形状、SmartArt、图内标签翻译仍需原素材编辑或双语企业资产；不会将未获批准的其余正文补发模型。

管理员“形成待核对资产”原子创建私有、内部、未发布草稿及来源依赖。普通理解保留全部原始段落、表格和图，并附加标为建议的观点。原件、页码、数据截至日与版本继续可追溯。模型不刷新资料业务日期。草稿可在原素材库编辑、核对及发布，再通过原模板／布局引擎标准化生成真实可编辑 PPTX。理解、保存、发布和导出是不同状态。

模板候选、研究方法和表达以理解结果的复用类型及候选资产沉淀；新模板仍须通过现有注册 Schema 与布局引擎，AI 不写任意模板脚本。尚未建设自动跨案例归纳、模型重排序或外部向量服务。

## 任务、反馈与运营

`queued → processing → completed / failed / paused / cancelled` 持久化；一批最多 10 页、账号最多 30 个未完成任务。Next `after` 每次限时 25 秒与最多 10 步，供应商超时最多 18 秒；租约 35 秒，状态读取、管理列表、直接恢复及下次领取会回收失联任务；从管理列表恢复不依赖先打开原页面。页面轮询／显式恢复触发下一受控时间片，关闭页面后未领取的剩余任务保持 queued，需要重新进入管理任务记录继续；没有隐藏常驻执行器或无人值守大批承诺。

领取保护防止并发重复执行；相同账号和缓存键正在处理时后续任务暂停等待复用，合法恢复后直接命中完成结果。取消不抹掉已预留成本；在途尝试仍使用原租约令牌可靠结算，未结算的短期调用继续占并发名额。中断不会永远显示 processing。预算暂停在已完成结果之外逐项保留，新增合法预算后可显式恢复。

工作台记录选择、采用、忽略、修正、匹配错误与人工反馈；真实页面保存、生成成功／失败、导出结果追加无正文操作事件。私人 Pitch 不会自动公开。只有用户点击“推荐为企业素材”才提交固定页面版本；候选列表只返回标题；管理员点击核对后重新授权读取该页的完整文字、表格、图表数据和来源，媒体仍在素材库按原权限核对。管理员只看到该候选及其已获权来源，不因此看到整个私人项目。原件／媒体仍需独立权限；账号绑定的动态数据快照不能借候选发布扩权。确认候选后形成私有草稿，再正式发布。撤回候选或原始来源，旧生成文件与旧读取接口同步拒绝。

运营按时间、任务、模型分页（每页最多 100）展示当前获权范围的尝试、报告用量、估算、未知预留、错误、平均与 P95 模型延迟、任务状态、缓存、预算暂停、权限拦截和使用组合。使用现有统计组件，不将有限样本冒充整账户账单。敏感配置和策略修改、任务和结算均在受控事务中记录；拒绝另行记录无正文事件，审计服务失败不伪报成功。
