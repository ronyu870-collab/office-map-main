# Pitch Studio 3.0 房地产视觉资产

视觉资产以共同提交 `820a793a` 的 [VisualAssetReference](../../src/lib/pitch/integration-contracts.ts) 交接。视觉数据由服务端根据当前项目与来源授权取得。工作台保留完整 `PinnedVisualReference`，其中包括恢复查询所需的 `origin`、原内容摘要、尺寸、日期口径和使用许可。渲染界面与导出共用 [resolvePitchVisualAsset](../../src/lib/pitch/visual-data/resolve.ts)，并按 `id`／`version` 将返回的 `SceneMedia` 传给现有渲染器。解析使用当前服务端权限和真实来源，校验已锁定的版本和完整哈希。系统拒绝用新版本静默替换已确认的来源。

## 服务端入口

| 入口 | 输入与结果 |
| --- | --- |
| `getBuildingPhotoChoices` | 接受 1–20 个目录楼宇 ID、封面／概况／对比用途与已使用原件摘要。按选择顺序返回每栋主图、备选和统一的裁剪策略。无合规可用图时 `primary` 和 `placement` 为空，页面可使用无图布局。 |
| `readPitchLocation` | 取目录项目点位或指定子市场样本。返回示意图结构、可解析引用，以及 2560×1440 PNG 媒体。单项目或竞品图支持按序编号、目标项目高亮及同点标签分离。 |
| `readPitchStackingPlan` | 接受项目 ID、可选的 1–2 个真实楼座 ID 和 `level_order` 闭区间。返回按楼座、楼层和单元组织的结构化图形数据。可选输出宽 2048 px、按楼层数增长的 PNG。 |
| `resolvePitchVisualAsset` | 在当前会话重读、复核并恢复用户已确认的引用。照片输出可直接嵌入 PPTX 的 JPEG／PNG 字节；区位图输出 PNG；历史堆叠图优先交付结构，可按需取同版本的 PNG。 |

调用方须先走原有 Pitch 会话和项目权限入口。图片及点位再检查楼宇目录和内部导出权限。历史堆叠图额外重新检查真实管理员会话、独立 Stacking Plan 授权、楼宇范围和导出权。所有本批引用按内部范围处理，历史资料限定管理员。AI 可以使用允许显示的引用元数据；文件内容与历史租户明细需要留在获权的服务端渲染链路。含历史堆叠图的最终交付仍须由工作流执行来源模块的导出审计，并在重新打开和下载时重新授权。

## 数据、日期及许可

- 照片沿用 `building_photos` 和 `building-sales-materials` 私有桶。文件需匹配楼宇、图片 ID、对象路径、尺寸、长度及 SHA-256，并实际解码。网页可看的 `ready` 资料中只有已知 CC BY 4.0／CC BY-SA 4.0 且保留来源及署名的私有原件可自动入稿。CC BY-SA 保持完整画面。照片来源层无拍摄日期时 `businessDate` 为 `null`，兼容来源字段保留已标明口径的采集日期。渲染方在页面保留署名、来源 URL 和许可条款。私有原件更新时，必须重新确认引用。
- 地图读取同一楼宇目录，沿用现有地图展示坐标并投影计算位置和近似图尺。来源日期字段记录目录观察日，业务日期保持未知。示意图仅画自有楼宇点位及目录中的子市场分组。高德静态底图商业嵌入权限和独立的子市场边界几何未获确认，图上明确标明无底图，子市场分布图明确标明无边界。见[高德静态地图文档](https://lbs.amap.com/api/webservice/guide/api/staticmaps/)和[开放平台服务协议](https://lbs.amap.com/pages/terms/)。
- 霄云路33号 A/B 座资料使用来源日期和独立单元核验状态。面积与分配沿用 Stacking Plan 现有模型。历史来源的空置标记随图标注，不进入当前库存；缺日期或未通过来源审查的空置标记按待确认显示，结构仍保留原标记。源表缺少可核验行业字段，返回 `null`。原件路径、合同租金和内部备注不进入 Pitch 结构。

旧版动态模板目录仍由专项分工中的页面组合和工作流管理。在组合、保存及下载复核使用同一引用前，旧版 `competition-map`、`stacking-plan` 保持原可用性状态。

## 四项资料复验

| 场景 | 本地隔离结果 |
| --- | --- |
| 五矿广场推介 | 使用原目录登记的开放许可原图。3401×2268 原件与目录 SHA-256 一致，实际 SVG 预览和 PPTX 包内图片均与原件一致。 |
| CBD 五个项目 | 环球金融中心、中信大厦、国贸大厦A座(三期)、银泰中心、嘉里中心五点均定位。批量选图结果为 0／5，当前可核对的样本目录未给这五栋提供可自动复用的图片。 |
| 霄云路33号 | 真实试点迁移在隔离 PostgreSQL 17 生成 A/B 两座、49 层、64 个来源单元。通过 B 座 18 层结构核对 941.84／691.57㎡，来源日期为 2026-11-18。对客解析拒绝。使用历史点位另生成目标楼宇和燕莎竞品示意图。 |
| 北京季度报告 | 从历史楼宇目录样本生成 5 个子市场、293 栋项目分布图，验证 PNG 能嵌入单页 PDF。目录时间与季度数据时间分别保留。 |

照片和坐标使用有来源可追溯的本地证据。生产私有桶未访问，应用服务授权回归使用隔离会话与请求夹具。PostgreSQL 验证执行实际试点和日期迁移及原有角色、写入、审计回归。
