# Pitch Studio 3.0 文档工作流

项目继续使用现有页面、快照、版本和私人所有权。此处的工作台命令使用 `/api/intelligence/pitch/workspace`。导出使用 `/api/intelligence/pitch`。

| 命令 | 调用与结果 |
| --- | --- |
| GET `document_bindings` | 传项目 ID。返回页面固定素材版本、披露、原始来源及内容块的业务／人工／素材来源。现有季度与成交快照记录字段、查询参数、政策、权限版本及业务日期。 |
| POST `preview_data_refresh` | 传 `projectId`、`slideId`、`expectedVersion` 和可选正式 `period`。按所选页的快照复核同组关联页，比较数据值和真实来源版本，并返回审阅指纹及结论复核提示。 |
| POST `apply_data_refresh` | 使用相同参数和审阅指纹。正式事实和来源、项目版本或权限出现变化时需重新核对。保存同时提交替换数据的私有归档及项目新版本，历史恢复沿用 `restore`。版式或分页无法安全保留时拒绝保存。含独立研究素材的组合页暂不开放自动刷新。 |
| POST `apply_modification` | 传共享 `DocumentModificationPlan`，支持已有 `PageEdit` 的受控更新。默认 `scope: selected`，其余页自动保留。显式 `scope: document` 时传完整目标顺序和原始页版本，可复制、删除及排序。可选 `theme` 指定已注册主题版本。`PageEdit.manualNote` 保存页面标题区的人工说明，传 `null` 清除。`chartPresentation` 按块索引切换原生条形、柱状或折线图，系列和来源保持固定。经预览的正式数据更新可与这些页面编辑一次提交。 |
| POST `review_handoff` | 传共享 `AddToPitch`。楼宇与子市场由当前账号查询授权及正式季度数据解析。Colliers AI `analysis-result.id` 接受获权查询的请求 ID，`resultId` 可固定其中一项结果。正式楼宇及季度查询保留原指标、字段、筛选、分组和期间。需要指定正式季度时返回 `period_required`。成交库可传 `lease-search`，包括 `dataset`、`from`、`to`、`buildingIds`、`submarkets`、`view` 与可选 `direction`。`view` 可为 `transactions`、`industry-count` 或 `industry-area`。服务端沿用成交查询的独立导出、明细权限和分组披露阈值。 |
| POST `add_to_pitch` | 传相同 `handoff`、预览 `fingerprint`、稳定 `taskId` 和显式 `target`。追加使用 `mode: append, expectedVersion`；新建使用 `mode: create, projectId, title, scope, themeId, themeVersion`。新建和排队在同一事务。后台重新读取并核对事实，应用整个任务结果时持有项目版本锁。 |

任务收据保留 `state`、`attempts` 和实际阶段 `preparing`、`assembling`、`saved`。查询已入库的排队任务可恢复后台执行，并发查询仍由数据库原子领取。请求结果不确定时用原 `taskId` 与原始参数重放，已完成的任务返回原回执。跨模块确认请求的精确重放在新查数之前读取原任务，保留原目标版本及审批指纹。取消、重试及审批继续使用现有权限和版本控制。

确认后的正式提案可使用独立任务租约。确认收据固定审阅指纹、源项目版本、任务编号和目标项目。工作进程重新核对审阅及数据权限，完成时由同一事务保存子项目、审计及成功收据。取消或源项目改版会阻止未完成任务写入。重复确认从同一收据读取进度，已有任务可使用工作台的状态、取消和重试接口。正式提案路由通过发布分支集成此工作流。

正式提案切换季度后会生成独立子项目。审阅按页显示指标、表格和图表前后值、业务日期与增减页面，并提示复核结论。已审阅的新季度快照提供正式数值与来源，旧稿中的可匹配版式、人工说明、图表类型和所选图片继续沿用。工作台保存与生成收据使用同一事务。若已编辑页面无法安全对应或旧项目版本已变化，生成终止并保留原稿。切换入口与新版策划、画布和图片权限适配一并在发布分支集成。

市场报告可重查当前保存季度的正式数据。审阅比较原查询范围、正式来源版本及数值，忽略新查数产生的临时回执编号。来源或数值发生更正后可确认生成独立子项目。保存时再次核对同一查询范围、父项目版本和已确认的正式快照。资料一致时直接提示已是最新数据。查询范围变化或历史缺少可核验的正式快照时停止刷新。

历史 Stacking Plan 使用 `stacking-plan` 来源，调用方传楼宇 ID 和可选楼座与楼层范围。服务端核验管理员会话、原系统授权和目标项目城市，按历史资料的来源版本排队。已确认的资料日期进入 `binding.dataAsOf`。暂未确认资料日期时保留 `null`，目录观察日单列为 `binding.observedOn`。追加以原子事务保存来源、页面和任务回执，内部导出沿用源系统复核与关键审计，受限页面不能对客导出。具体楼层读取与生成适配在发布分支安装。

历史楼层页可保存独立的人工标题和说明。获权管理员内部导出时仍核验固定楼层图及正式提示的来源。附加外部资料或改引正式提示的出处会触发披露拦截。

新版审阅式提案按对象返回其已归档的正式查询收据，包括实体、查询参数、字段、权限版本、资料日期和披露范围。对象依据版控素材中的精确引用关联收据。正文及画布编辑会保护带正式数据依据的段落，人工说明仍可单独录入。市场结论保留来源并以分析内容标识。

`document_bindings` 的 `pages[].materials` 返回固定素材版本的哈希、业务日期和使用范围，以及仍有权查阅的原文件版本、来源页和媒体版本。对象的 `sourceIds` 连接来源记录，`mediaRefs` 指向图片或团队照片的具体版本。历史素材保持素材来源类型。素材版本和原件策略随来源显示，对客资格沿用独立的导出复核。读取绑定只查询元数据。

楼宇照片、地图与历史楼层图的原生引用保留在 `materials.visuals`。对象通过来源 ID 和媒体版本关联，返回楼宇、原始查询筛选、固定版本和来源范围。图片登记日或地图观察日保留为 `sourceDate`，未知的业务日期为 `null`。历史楼层图如有归档的授权版本则一并返回。预览和导出按来源权限独立复核。

同一生成任务内，相同查询参数的章节共享一次正式读取及一份归档结果。标题和经确认的研究说明仍按页保存。刷新预览会列出使用同一事实快照的相关页面，并在一次保存中更新这些页面。

结构化修改可使用 `plan.refresh: { kind: "reviewed-data", slideId, period?, fingerprint }` 引用复核后的数据差异。调用方从 `preview_data_refresh` 取得变更页和指纹，将同一快照影响的所有页版本加入 `basePageVersions`。服务端重算差异，校验获权数据及绑定，再将快照、受控编辑和审计保存为同一个新版本。单页校验失败或审计写入失败时保留原稿。旧提案计划编号仍须获取有效差异预览后才能应用。

季度研究交接传 `source: { kind: "quarterly-research", edition }`，版本沿用研究页的管理员可读版本清单。服务端从该版本确定季度，对北京甲级写字楼的获权跟踪样本重新读取已锁定的正式数据，保存实际样本 ID、统计口径、业务日期及授权版本。目标项目须在北京。

子市场交接使用所选正式季度汇总市场指标，保留有效样本与分母。

Colliers AI 的正式查询会在审阅和后台保存时重新核对原存档、结果身份和资料权限。较宽的结果拆成可编辑表格，各续页保留分组和期间列。日期已明确的导入沿用原期间。后续确认换季时，跨季比较和趋势继续使用原窗口长度与统计口径。搜索摘要等缺少可重放正式查询的结果沿用各自入口。

GET `export_eligibility` 返回指定受众是否获授权、项目版本以及每页拦截原因。POST `export_start` 保留既有 `page`、`pages` 选择约定，支持 PPTX、PDF、高清 PNG、SVG 与 XLSX。所选页面中任何一页不符合要求时返回 403 及页面列表，调用方可以改选。审核通过的导出按所选页固定资产和图片版本，下载时复核；已完成的文件继续使用自己的权限清单。PPTX 继续由统一 Scene 写出原生对象。PDF 逐页复用 2560 像素场景渲染，适用于固定版式阅读。旧导出记录沿用原工作流读取。同一账号重复导出相同版本、页序、格式、受众和权限清单时，可复用同一渲染版本的归档文件。每个请求仍保留自己的回执和下载鉴权。

GET `export_status` 可以恢复尚在排队的导出，继续使用原收据的版本、选页、格式和受众。多个同规格请求同时到达时，由一个任务渲染，其余收据报告 `waiting_for_package`。成功归档时，同批收据在同一事务内就绪。首个任务失败或租约过期后，下一次查询可以启动仍有效的后续任务。

工作台提交 `export_start` 时同时传入核对过的 `expectedVersion`。项目在这期间被另一个会话重新排序或保存时，服务端返回 409 并撤销本次任务入库，调用方须重开项目后再选页。已收到回执的同一请求可按原编号和版本重试，继续使用原有选页。旧调用方可以省略此字段。

楼宇图片、地图、Stacking Plan 的新授权解析和新 Scene 由各自专项接入。项目编辑仍限所有者。现有页面素材可按记录版本复用。


## 指定账号演示

| 命令 | 调用与结果 |
| --- | --- |
| POST `share_create` | 所有者传 `projectId`、`expectedVersion`、`shareId`、`recipientId`、可选有顺序的 `slideIds` 和 `expiresAt`。创建内部实名只读演示，并固定当前保存版本。重复原请求返回原回执。 |
| GET `shares` 和 POST `share_revoke` | 所有者查询最近 50 条回执，按 `projectId` 和 `shareId` 撤回。过期或撤回后的旧入口失效。 |
| GET `shared_presentation` | 收件人用自己的登录会话和 `shareId` 打开页面目录。分享指定了页面时，目录沿用该顺序。 |
| GET `shared_slide` | 收件人传 `shareId` 和目录中的 `slideId` 获取同一 Scene 渲染的 SVG。服务器在渲染前后复核账号、授权、版本、来源和媒体。 |

接收账号须具备项目所在范围的 Pitch 查阅授权，并能查看页面所用的已发布素材。所有者可以显式分享自己撰写的页面。包含租赁与季度快照的生成页暂未开放跨账号分享，继续沿用账号绑定的授权。对客交付使用独立的披露检查和正式导出。持有分享编号本身不产生访问权限。共享版本复用修订历史，活跃分享保留固定版本，后续编辑不会改写演示内容。
