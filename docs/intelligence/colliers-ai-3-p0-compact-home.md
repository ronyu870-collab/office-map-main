# Colliers AI 3.0 P0 — 紧凑 AI 与综合业务首页

基线：远端 `main` 的 `195063eef7924b7ee9b627321cbab95bc36b06c6`（体验 2.0 P2 已合并）；分支：`codex/colliers-ai-3-p0-compact-home`。本记录只对应 3.0 P0，PR 编号、精确 head、工程结果、main 合并与生产发布分别以本次实际记录核实。

## 1. 授权与阶段边界

用户要求实际开发、必要工程验证、创建 PR，并在不可省略检查通过后直接合并 `main`，无需再次请求合并确认。首页是房地产综合业务平台；AI 是独立且紧凑的入口，地图、成交、季度填报、研究资料、其他已有获权入口与团队动态保持原有地位。

本轮只调整首页 Compact 展示的布局、尺寸与视觉密度。不新增点击或聚焦输入即展开的逻辑；后续 P1 的切换行为不在本轮范围。既有手动展开、收起、历史、来源与研究工作空间继续使用原有链路。

用户明确豁免独立人工视觉评审、重复人工浏览器观感审查和真实手机设备人工验收。三项均记录为 `waived`／未执行，不能冒称通过。授权及撤除条件见 [06 本次决策](../standards/06_规范维护与决策记录.md#colliers-ai-30-p0-首页紧凑变体与单次人工验收豁免2026-11-18)；本次豁免不适用于其他 PR 或后续阶段。

## 2. 设计范围与角色映射

具体尺寸由 [01 系统设计语言](../standards/01_系统设计语言.md) 的首页 Compact 命名变体维护。本轮采用以下布局关系，最终实现及验证范围随本次代码差异核对：

| 区域 | P0 处理 | 保留条件 |
| --- | --- | --- |
| AI 功能区 | 减少默认空会话的上下留白，独立浅蓝灰背景；不靠固定高度裁切内容 | 产品标识、必要状态、权限提示与既有展开按钮 |
| 欢迎区 | 简洁问候和“今天想研究什么？”共用紧凑对齐线 | `displayName` 安全回退，不暴露邮箱、内部 ID 或未经清理的称呼 |
| 输入面 | 更窄的白色单行视觉输入，柔和边框、既有 AI 输入圆角、右侧发送 | 保留同一 textarea、完整草稿、中文组合输入保护、发送条件和失败恢复；长内容允许增高 |
| 示例与说明 | 默认最多三条轻文字建议；能力和低频说明按需展开 | 只使用服务端获权示例；点击填入完整原问题，不自动提交；审计告知继续可读 |
| 业务导航 | 保留独立白色工作面及入口地位 | 地图及所有已有获权入口的顺序、资格、受限处理和访问审计不变 |
| 团队动态 | 保留原次级背景、位置与功能布局 | 公告、团队交流、问题反馈及各自原操作不删减 |
| 无 AI 权限用户 | 继续显示原有业务首页 | 不以 AI 授权结果阻塞地图、业务导航或团队动态 |

颜色和圆角继续复用 `--cd-color-ai-surface`、`--cd-color-ai-border`、`--cd-radius-ai-surface`、`--cd-radius-ai-composer` 及既有内容面令牌。Compact 命名样式只影响首页展示，Expanded 的欢迎、阅读区和输入工作面保留原有设计。不得因默认目标高度裁切错误、长姓名、草稿或窄屏触控目标。

## 3. 行为边界与回归范围

受影响调用路径是首页 `HomeWorkspace` → `HomeQuery` → 欢迎、输入、建议和说明的展示。核对首次认证渲染与无 AI 权限主页，避免出现空白或仅“主页”标题；已有会话、数据资格、本人历史和结果来源仍依赖原服务。

重点复用实际父组件回归核对连续输入和光标、中文组合输入及 229 保护、只填草稿不发请求的建议、发送与忙状态、恢复／澄清／历史／来源、手动展开后的同一输入节点，以及无 AI 权限的全部业务导航与团队动态。已有全屏工作空间回归继续进入 CI，不能只验证空首页。

本轮不修改 AI 查询后端、模型调用、统计计算、数据库结构、RLS、审计协议、历史结果或业务数据；不新增生产数据操作。不改变加载链路或发起性能优化；若实际修改产生这些影响，须另按 VERIFY-03／06 补齐对应证据，不能因“样式改造”略过。
