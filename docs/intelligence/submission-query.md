# 主页填报查询、同源图表与导出

本包把 [Q13 只读基础](submission-observations.md) 接入现有主页提问、正式请求审计、不可变结果、本人恢复、柱状图及内部文件链。仅本地与一次性合成环境；没有生产迁移、真实账号授权、付费模型调用、后续 main 合并或正式启用。当前 admin 本人是必要条件，查询、质量、范围、导出和审计仍分别要求独立资格。

## 能查什么

受控问题语法版本为 `bounded-business-question/9`，以下九种动作都接受“当前填报季度 + 子市场”或明确年季；子市场也可使用既有的全部获权楼宇范围。完整问题中的额外条件不会被忽略。不属于已支持语法的表达先澄清，尚不代表开放自然语言或连续追问完成。

| 问题示例 | 输出 |
| --- | --- |
| 当前填报季度CBD填报进度 | 四个互斥楼宇状态及已分配楼宇提交覆盖 |
| 2026Q3CBD填报明细 | 获权候选楼宇、当前分配、该季提交、原始提交数与最新时间 |
| 当前填报季度CBD哪些楼还没填 | 没有该季提交的楼宇；分配状态单列 |
| 当前填报季度CBD未分配楼宇 | 当前无有效负责人关系的楼宇，包括已有人提交的楼宇 |
| 当前填报季度CBD人员填报进度 | 按账号的当前分配、本人已提交及本人未提交任务 |
| 当前填报季度CBD谁还没填 | 仍有本人未提交任务的账号，不把他人代填等同本人已填 |
| 当前填报季度CBD填报数据质量 | 每栋最新整条提交的八项原值、五项输入齐全状态与待核事项 |
| 当前填报季度CBD填报缺项 | 缺少必填项，或尚无记录/无法确定最新记录；后两类明确为无法检查 |
| 当前填报季度CBD填报异常 | 无效、不一致及无法确定最新记录，不自动修改业务数据 |

“当前填报季度”只读系统配置。“本季度”按服务器接收时刻的北京时间日历季度解析，保留原问题与解析结果。配置缺失或非法时明确回答“不知道：当前填报季度未配置或无法确认”，要求明确年份季度，不能用当前日历季度、历史指标或最近有数据季度代替。澄清也保存正式问题、原因和实际交付凭据。

原表没有历史任务快照，因此所有期间的任务分配均标为当前关系。四个互斥状态为已分配/有提交、已分配/无提交、未分配/有提交、未分配/无提交。人员任务按楼宇与账号去重，与楼宇覆盖采用不同分母；同名账号不合并。质量显示原始填写值与异常，零值不变缺失、空白不补旧值，完整不等于有效或审定。质量数值图用于查看原填报值，不据此证明市场指标有效。

## 同一结果与来源

`submission_progress` 计划仅允许 tracked 存量范围，不接收数值筛选。结果包含所用实际季度、配置季度、配置/明确期间依据、当前库存/分配语义、确定性质量规则版本、完整候选分析和字段来源。复用原主页“结论—表格—来源”的阅读顺序，细节与口径放在既有展开区域。切图、恢复和下载均使用归档结果，不重新读取最新事实并冒充旧快照。

表格分页、图表点及单元格来源绑定同一 result_id。CSV 附完整 manifest；SVG 使用同一表格数据并附 manifest；XLSX 除原数据、精确值、来源和口径页，提供填报覆盖、楼宇填报、人员任务，以及有质量资格时的填报质量页。数值保持 Excel 数值类型，百分数字段 0.5 始终代表 0.5%，不猜测为50%。统计单元格来源过长时按完整 ID 分段，以 entity_id/field 与段号重建，不截断证据或重复统计。进度查询的结果与文件不包含质量字段。

来源包括 buildings、building_assignments、quarterly_submissions 与实际采用的 app_settings 配置记录。数据库记录未关联原件就保留该限制。未提交结论来自完整授权快照，不伪造缺失提交的记录。

## 权限、撤回和审计

沿用 admin-only/1：当前可信角色表中的 admin 本人、有效真实会话、能力开关和资格/范围交集。普通角色即便持全部资格仍拒绝；模拟别人和模拟本人均拒绝；另一 admin 不能按编号恢复本人的结果。进度资格不自动包含质量，质量不自动包含历史指标、导出或审计原文。

新增服务端专用 `ai_query_submission_sources_allowed`，检查当前 admin/会话/资格修订、结果所有者及 succeeded 状态、完整审计链与当前来源范围。只有 service_role 可调用包装和私有实现。配置键、字段、季度及楼宇归属逐条匹配；分配移动、提交季度改变、来源删除、楼宇合并/停用/离开授权范围都会拒绝旧来源。合法更新数值不修改已存快照；读旧快照与读最新事实是不同操作。

首个结果响应在准备交付凭据后再次查身份与来源；恢复、作图、导出复用归档并复查当前资格与来源。失败不返回结果，撤回追加未交付审计。来源检查本身写入结果访问记录。前端隐藏只是呈现，数据库和服务端承担强制拒绝。

回归接入现有单测、搜索焦点检查和真实 Auth HTTP CI。覆盖九种动作、配置/日历/明确季度、错误配置澄清、分母与质量、完整原文、文件回读、同名账号、超过1000来源、admin降权/模拟身份/跨账号、缺资格、旧结果来源撤回，以及首个响应前的撤回故障注入。具体已执行命令、数量、截图和源码摘要随 evidence 记录，不把脚本存在当作已通过。
