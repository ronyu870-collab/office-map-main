基线：远端 `main` 的 `f600c6bb4cbbb8cdac13275b729cb9ea4b361694`（3.0 P0，PR #208 已合并）；开发分支：`codex/colliers-ai-3-p1-focus-transition`。本记录只对应 3.0 P1；工程完成、PR、精确 head CI、合并和生产部署分别核实，不从上阶段成功推断本阶段已完成。

## 1. 授权与范围

用户要求实际修改代码、执行必要工程验证，创建 PR，并在不可省略的仓库 CI 与分支保护满足后直接合并 `main`，无需再次请求授权。本轮保留 P0 综合业务首页布局，仅扩展 AI 紧凑入口到专注／全屏工作空间的交互；已有地图、成交、季度填报、资料、业务导航和团队动态继续存在于主页。

本次明确豁免独立人工视觉评审、重复人工浏览器观感审查、真实手机人工验收，以及无必要的额外演示和反复确认。人工项目均为 `waived`／未执行，不能作为实测通过；自动工程、真实浏览器功能回归、性能预算及分支保护继续有效。独立规则决定及撤除条件见 [06 本次决策](../standards/06_规范维护与决策记录.md#colliers-ai-30-p1-专注工作空间与单次人工验收豁免2026-11-18)。

## 2. 状态与操作契约

| 状态／操作 | 目标行为 | 必须保留 |
| --- | --- | --- |
| 初始 `compact` | 沿用 P0 紧凑 AI 区域，主页维持综合业务页面 | 原首页布局、业务入口、权限和页面滚动位置 |
| 主动点击／聚焦输入 | 同一输入面作为空间起点进入 `focus` | 原 textarea、草稿、选区、中文组合输入，不触发查询 |
| 点击建议 | 填入完整原问题并展开专注；允许编辑，等待用户发送 | 服务端获权示例、原始问题全文、显式发送语义 |
| 桌面 `focus` | 居中大工作面、背景遮罩、居中阅读区和稳定底部输入 | 清晰的主页返回、进一步全屏、按需历史及研究资料 |
| 窄屏 `focus` | 贴合可视区域的近全屏，跟随键盘与安全区域 | 必要触控按钮和可见输入、主页返回位置 |
| 进一步 `expanded` | 在原状态机中全屏；退出全屏回到专注 | 相同会话、历史、来源、导出、图表和分页 |
| 返回主页／收起 | 反向空间过渡回到原 P0 布局 | 当前对话、结果、草稿及仍在处理的请求 |
| 快速反转／视口变化 | 新动作接管旧动画，控件持续可用 | 不执行迟到完成回调、不重复提交或交付 |
| 减少动态效果 | 直接完成等效布局变化 | 完整功能、焦点与状态保持 |

模式切换只调整同一个 DOM／React 会话树的空间，不增加第二个真实输入框，不通过路由、Portal 重挂载或会话 key 切换实现动画。查询、恢复、历史、来源和导出继续复用原链路；普通点击失焦不作为关闭动作。P0 已有回答时的紧凑结果展示保留，不额外引入一套隐藏结果或展示审计规则。

## 3. 受影响路径与保护

- `HomeQuery`：输入焦点、建议填入、显式发送、工作空间工具栏与结果展示模式；单一 `HomeQuerySession` 继续以真实身份边界隔离，模式切换不参与 session key。
- `useQueryWorkspace`：三态空间、原生动画、取消／反转、可视视口、焦点环、背景隔离、滚动位置与清理；`useQueryScroll` 继续处理阅读位置和新消息跟随。
- 工作空间 CSS：`focus` 大工作面、全屏与紧凑变体，输入面连续性、安全区域、短视口与 reduced motion；不增加动画依赖。
- 间接依赖：历史与研究面板、地图上下文、来源／导出／分页、客户端展示回执、进行中的 `trustedQueryClient` 请求。切换不调用 submit／recover／历史重新执行，不自行取消正在处理的查询。

本批无数据库迁移、业务数据生产写入、角色／RLS／字段授权、模型配置或正式计算口径变更。已有 CI 的真实 PostgreSQL／Auth／HTTP 与业务回归继续执行；既有成功结果不替代当前提交的回归。
