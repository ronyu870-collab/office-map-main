## 2. 执行架构与关键文件

执行顺序：有界请求接收 → 验证实际身份 → 完整问题加密接收与幂等登记 → 当前资格 → 回读已授权父轮上下文 → 读取有界可用期间 → 确定性语义解析／必要时一次模型候选 → 查询计划及字段／范围校验 → 原一致快照执行 → 确定性补充分析 → 结果与来源归档 → 交付前再次核权 → 前端呈现。

模型不读取全库、不接收业务记录或原始资料、不输出正式统计数值，不获得 SQL、工具调用或写库权限。正式数值继续由原查询执行器和精确计算产生。

### 多轮、重试和隔离

客户端使用 `{ id, parentRequestId? }` 引用对话，不能提交自定义 `context` 或把旧条件当成可信输入。服务端以原审计中的 `sessionId`、actor／effective identity、conversation ID、当前权限版本和原计划核验继承。模拟身份仍拒绝使用 AI；同账号重新登录的新认证会话也不能直接继承旧会话上下文。

原始问题、原请求正文、首次解析计划、模型调用状态、实际执行计划和完整结果分别留存。先取得原接收记录再准备语义；同一幂等键的重试回读首次计划／澄清，不因业务最新季度变化或模型输出变化重算。相同键改变正文仍产生受控冲突。旧答案上的建议绑定其来源请求，不能串到后来一轮。

前端持续输入、在途修改、停止等待、恢复及重试沿用 P0 归属保护。点击澄清或建议不会清掉用户正在编辑的草稿。身份、会话、资格版本变化或撤权时清除旧可见结果和上下文。停止等待仍只表示客户端停止等待，不宣称取消服务端审计或计算。

## 3. 时间、筛选和真实数据范围

### 时间语义

| 表达 | 执行含义 |
| --- | --- |
| 最新季度／最新有数据季度 | 当前获权子市场、楼宇、inventory 和指标字段范围内，存在有效非草稿记录的最大季度；不是系统当前自然季度 |
| 最近四个季度／过去一年 | 截至上述真实最新季度的连续四季；中间缺期保持缺失 |
| 最近 N 个已结束季度 | 按接收时北京时间，结束于上一日历季度；日历结束不证明数据已齐备 |
| 本季度／上季度 | 接收时北京时间的当前／上一日历季度；无数据也不改查其他季度 |
| 去年同期 | 有已确认上轮期间时以其末季为基准，否则以真实最新可用季度为基准，向前四季 |
| 今年 | 本年 Q1 至本年最新有数据季度的逐季结果；不计算未定义年度平均 |
| 明确季度／两期／范围 | 保留用户明确期间；不存在的数据不补零、不估算、不退回其他季度 |

可用期间索引最多返回最近 40 个有有效数据的季度，超过时明确标记索引截断；更早的明确季度仍以执行快照为准，不能仅因不在索引中判定不存在。期别依据不证明审核／发布状态。

当前季度和历史季度查询均沿用获权的当前目录。子市场、等级和 tracking scope 不被当作历史时点目录。因楼宇范围、级别或有效样本变化形成的均值变化，不能直接解释为市场价格变化。

### 数值筛选与跨来源查询

支持既有白名单字段：季度总面积、空置面积、净有效租金、建筑高度、楼层数、总车位数。支持大于／不小于／小于／不超过／等于等比较，明确单位，及“万／千／亿”的精确十进制换算。纯 AND 或纯 OR 条件使用原 `Predicate` 执行；混合优先级不能确定时澄清，不猜括号。

例如：`找出2026Q3 CBD季度总面积超过5万平方米的楼，并查看净有效租金` 规划为已有楼宇列表，筛选 `totalArea > 50000`，显示 `netEffectiveRent`。`建筑高度 > 100米 且 总车位数 ≥ 1000个` 可作为楼书来源筛选，再关联同一获权楼宇的季度租金；筛选依据即使不显示为表列，也仍在来源证据中。

`近五年建成、建筑面积超过5万平方米` 不会被改写成季度面积筛选。建成年份、GFA 及相关权限尚未接入，本轮明确说明限制。修改继承筛选时，确定的同字段新条件覆盖旧条件，其他条件保留；无法安全局部修改 OR 组合时澄清。

## 4. 确定性分析、异常规则与样本口径

补充分析复用原 `aggregateQuarter`、`compareQuarters`、分组及分布计算，不重新定义正式租金或空置率。租金为有效总面积加权；空置率为同一有效记录的空置面积合计除以总面积合计。内部保留未舍入有理数，展示层才格式化。

- 租金／面积变化率：`(期末 − 期初) ÷ 期初 × 100%`；基期为零则相对变化率未知。
- 空置率变化：`(期末比例 − 期初比例) × 100`，单位为百分点；不会把 0.05 的比例变化写成 0.05 个百分点。
- 环比仅比较相邻季度；同比仅在本次快照同时包含相差四季的记录时计算。
- 任一期无有效值时保留空值和缺期说明，不把缺失当作稳定或连续下降。
- 两期对照同时提供各期有效样本与两期共同有效样本；多期趋势另提供全期间共同交集。楼宇进入／退出有效样本不等于实际开业／退市。
- 每期保留样本成员、有效与排除数量、分子、分母、正式指标和逐楼简单平均。简单平均只作口径核查，不替代正式指标。

| 异常规则 | 判断及证据 |
| --- | --- |
| 同楼租金相邻季变化 | 相邻季度、同一楼宇、有效净有效租金绝对环比变化达到 **30%** 时提醒；保留两期原值、精确变化、阈值和记录来源 |
| 同楼空置率相邻季变化 | 同楼相邻季度有效空置率绝对变化达到 **10 个百分点** 时提醒；保留同季度面积口径和来源 |
| 同组 IQR | 同组同季至少 4 个有效楼宇，复用 Type 7 分位数；严格超出 `[Q1−1.5×IQR, Q3+1.5×IQR]` 时标记，保留样本数和围栏证据 |
| 数据覆盖 | 缺失、无效、来源冲突和未核验分别计数；不按零填补 |

30%／10 个百分点是明确的固定筛查阈值，不是统计显著性结论，也不证明录入错误。异常记录继续参与原正式统计，不写回生产数据，不自动删除，也不补编市场原因。单季度查询不会为检测环比暗中额外读取前季；跨期提醒只基于本次实际查询快照。

补充分析当前覆盖 `aggregate`、`compare`、`trend`、`group_aggregate`、`group_trend`。交叉表、排名、分布、关系及目录保留已有同源结果和自身分析，不把交叉单元格扁平化为市场均值。

### 资源与费用预算

| 边界 | 当前实现 |
| --- | --- |
| 对话 | 最多 40 轮；上下文回读只取有界解释事件，服务端最多 16 个事件；数据库解释内容超过 512 KiB 拒绝 |
| 趋势窗口 | 连续 2–40 季度；原执行器的数据完整性及同步范围保护保持 |
| 语义模型 | 每个新请求最多 1 次；不自动重试；12 秒期限；问题最多 3,000 字符，总输入最多 18,000 字符；输出最多 1,200 token、响应最多 32 KiB |
| 跨实例调用准入 | 以已有审计接收计数：同 actor 最近 1 分钟不超过 12 次、最近 24 小时不超过 120 次；简单查询也计入该保守预算，不能冒称精确模型调用账单 |
| 补充分析输入 | 最多 5,000 个楼宇×季度观察、15,000 个来源引用、1 MiB 不同来源标识字符 |
| 补充分析输出 | 最多 4 MiB，合并结果最多 15 MiB（既有归档上限 16 MiB）；异常明细全结果最多 100 条及 5,000 个异常证据引用；前端按需展开、分组和异常分页 |
| 超限处理 | 明确区分补充分析未完成与已检测但明细未完整列举，保存 detected／returned／omitted，原查询结果继续保留 |

已核查目标项目存在 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`、`DEEPSEEK_API_BASE_URL` 配置；密钥不进入客户端、日志或本文。代码复用既有 DeepSeek 接口配置，常用表达走无需模型的快速路径。对供应商错误、非法候选、超时及预算拒绝，保留澄清／不可执行状态，不生成替代数字。记录供应商返回的 token 用量，无法确认的货币费用保持未知。本记录初稿未取得新 P1 生产模型调用成功证据，不能把配置存在当作生产调用已验证。

模型只允许已经验证的业务槽位之外少量整体匹配的非约束询问句式；无法证明已表达的残余条件均澄清。绿色认证、临街、所有权等未支持条件不能因模型声称没有遗漏而消失。这是受约束的语义补充，不是通用自然语言理解。

## 5. 来源、数据权限与审计

每个正式结果保存 `parameters.executedPlan`、`interpretation`、`dataPlan`、可用期间索引及适用的 `researchAnalysis`。每项研究结论和异常记录引用原结果的 source IDs；不属于原快照、版本或范围的证据拒绝绑定。恢复、CSV／XLSX 元数据与现有结果快照保持一致，不另取一套数字绘图或导出。

首页默认呈现数据期间、样本与统计方式，展开后可查看实际计划、数据库表／字段、完整口径、版本、原始记录及原件关联情况。分析和来源明细按需挂载；不会把内部 conversation 状态直接铺在普通用户结果中。原件未知仍明确未知。

权限继续要求真实有效会话、当前 admin 本人、独立查询资格和具体字段／行范围。期间索引也受相同当前权限和 `map_building_visible` 谓词约束，未获权楼宇的最新记录不能改变当前用户看到的“最新季度”。资格撤销或版本变化后不交付旧范围结果；服务不可用不能被写成“数据为零”或“已撤权”。

三个新增 RPC 均为服务端入口：公开 invoker 包装仅授予 `service_role`，内部 definer 使用空 search path 并调用既有权限检查。`anon`／`authenticated` 无直接执行权。没有修改 RLS、既有授权记录或生产业务数据。上下文访问继续留痕。
