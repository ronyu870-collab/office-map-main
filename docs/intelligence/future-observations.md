# 未来供应目录与季度任务数据基础

本包增加内部只读适配器，覆盖 `future_supplies`、`future_supply_assignments`、`future_supply_submissions` 及实际采用的季度配置。仅本地和一次性合成环境，不开放主页新问题，不迁移生产、不授予真实账号、不调用模型。Q13/Q14 用户查询、结果归档与图表导出继续实施，不能把本包计作这些功能已经交付。

## 身份、范围与审计

仅当前可信角色表中的 admin 本人、有效真实会话可以使用。普通角色即使持全部资格仍拒绝；模拟自己或别人也拒绝。抽取原身份检查为不可由客户端或 service_role 直接执行的私有 principal，原存量 authority 保持原响应与准入规则。未来目录、进度、质量使用三个独立资格，未来实体范围使用新 `all_future_supplies` / `future_supply_ids`，默认 false / 空数组；存量权限不自动带来未来权限，未来专用资格也不能借用存量接口。

新增公开 RPC 为 invoker 包装，实际 definer 放在 private，固定空 search_path，只有服务端角色可调用受控包装。读取必须先有同一请求、操作人和有效身份的 running 审计流，且完整链校验通过。SQL 和 TypeScript 均检查当前范围与资格修订；读取后重新校验，撤回资格、实体范围或当前 admin 身份后不返回已读取数据。此次不新增 HTTP 路由；新来源尚未接入归档交付复查，不能绕过这一后续门槛直接用于历史结果恢复或下载。

## 目录与时间口径

- 以 `future_supplies.id` 区分记录，保留实际 `building_id`，不按同名猜测关联。当前唯一关联约束与隔离夹具一致。
- 仅取明确 `is_entered_market=false` 的获权记录。已入市、入市状态未知、关联楼宇已转存量/停用/合并不进入候选；pending 及未知分类保留标记，不能称为已核实未来供应。
- Q1–Q4 是确定季度，H1/H2 是半年范围，仅年份为全年范围；缺失或非法值明确未知/无效。竣工年不替代预计入市年，预计时间已过不代表实际入市。
- 面积保留精确十进制原值，缺失、零/负值及非有限数字分别识别。原字段不自动等同办公或可租面积；未实现面积汇总。坐标仅检查数值范围，不证明坐标系或地址正确。
- 目录、季度配置、分配及提交在一个数据库语句快照内完整读取。超过 20,000 项目、100,000 分配/提交或 16MiB 拒绝同步返回，不能偷偷截断成完整结果；分析超过 200,000 来源也要求后台任务。

## 任务与质量口径

未来任务有年季，使用指定季度当前保存的分配；与存量的无季度当前分配区别明确。任务分母包含该季度对所有候选记录的任务，不限定预计入市也恰好在该季。单独区分明确当季、可能当季、时间未知、预计不在当季；不把这个任务统计冒充现有管理看板按确定入市季度筛选的数量。

楼宇记录覆盖按当季任一提交计算，人员任务按记录 ID × 账号 ID 去重且只认本人提交；同名账号不合并，未知提交人不猜归属。没有任务时覆盖率未知，不写 0%。未分配、缺报、重复记录、本人未填分别保留。

最新质量选同一条完整记录，沿用 created_at 微秒及 ID 排序；存在缺时间记录时明确无法确定最新，不跨期或从旧行补值。质量复用五项必填和八字段检查；0.5 仍表示 0.5%，异常只提示复核。进度资格不读取质量数值，版本哈希也不含隐藏数值；目录不读取人员/提交/配置。备注、联系方式及业主等字段不进入白名单或其版本哈希。

所有结果带实际表/记录/字段/版本/原值及期间来源，数据库未关联原件就明确仅数据库来源。当前保存的历史季度任务不称为当时冻结快照。此阶段质量资格为一组八字段，进一步细分字段资格、历史任务快照和正式统计确认仍在完整计划内。

## 验证与发布边界

新增九项单测覆盖时间区间、任务分母、未知与非法值、最新整条、来源、同名/未知人员、无任务、完整性与独立权限。七组真实 GoTrue / PostgREST / PostgreSQL 17 适配器回归接入现有 Auth CI，覆盖未来专用与混合资格、默认拒绝、超过1000行完整读取、隐私字段排除、身份/审计/直接 RPC 拒绝、读取后撤权。既有存量查询、恢复、导出与审计回归一同执行，避免共享身份抽取改变旧路径。

具体已执行结果与文件摘要见 [验证记录](future-observations-evidence.json)。本包不改界面，不产生新的视觉验收结论；没有远端精确 head CI、生产迁移或后续 main 发布。回退先停用未来资格和调用方，保留 admin-only 与审计，不破坏原始业务表和已有记录。99项 Goal 与 T01–T60 全部保留，后续先接入主页问题、不可变结果、来源复查和同源输出。
