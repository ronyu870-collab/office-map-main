## 可复用的受控启用操作

`scripts/intelligence/ai5-enablement.mjs` 只读取本地明确计划并输出待审阅 SQL，不连接数据库、不自动发现或授予所有管理员。计划字段仅 actorId、expectedRevision、documentIds、changeReference；真实账号和文件标识不要写入仓库。

```sh
node scripts/intelligence/ai5-enablement.mjs /secure/reviewed-plan.json > /secure/reviewed-enablement.sql
```

DBA 审阅后在指定环境执行。事务要求：已有有效 AI 管理员、基础 revision 完全一致、总开关开启、选定在线原件处于基础楼宇范围；若已有任一独立资格（包括已撤销资格）则整笔拒绝，不覆盖、不重新启用。三个资格原子插入，锁及语句时间有界。撤销走既有独立资格维护路径，不能重跑本工具绕过撤权。

`supabase/tests/ai-production-enablement/run.mjs` 在隔离 PostgreSQL 17 执行真实 SQL，覆盖角色／到期／总开关／revision、文件范围／关联／可用性、SQL 注入、原子性、原资格不变、独立审计、重复执行及撤权不重启；已接入必需 CI。
