# 成交查询的数据基础

2026-11-14；基线 `6b6c3557406f1054c906caaf3de9c5f378dd3572`。本包只接通内部完整读取、确定性统计与字段来源；Q15/Q16 的主页问答、归档结果、图表及导出仍需后续接线。没有生产迁移、启用或真实账号授权。

## 数据与口径

- 复用 `lease_transactions_read_v1`，保留日常 `live` 与历史 `history`、逐记录修正、exact/reference/project/unmapped 身份。项目关联多个楼座仍只读一条成交，不复制或分摊面积；reference 不冒充运营楼宇。
- 支持按来源、子市场、稳定记录 ID、精确企业文字及楼座/项目关联筛选。企业名称不等于法人身份，不做模糊身份合并；跨来源未有确认的去重映射，因此只给分来源统计和原始记录总数，不给“合并独立成交笔数”。
- 字段白名单为成交面积、表面租金、有效租金、租期月数、行业、子行业、需求类型和历史来源文字。人员、联系方式、备注及 AI 猜测企业身份不读取、不进入版本摘要。基础名称、关联和期间随获权记录提供。
- 租金单位沿用成交读层的元/㎡/月，表面/有效分别统计；估算、未标估算、估算状态未知分别计算。加权只取同一来源及同一估算类别中租金有效且面积大于零的配对记录，保存精确分子、分母和参与 ID。未标估算不等于已核验合同价。
- 日常估算标记取实际 `lease_transactions` 字段；历史读层未提供可信估算标记，保持 null/未知，不制造历史列来源。真零、缺失、无效分开；零租期无效。成交面积不称净吸纳量。
- 日期、季度、年份保留原精度；原始值与视图推导期间不一致时标记冲突。成交时间不等于起租或到期，未知不推算。历史租期原文保留供核验。
- 每个读取字段生成数据库 SourceRef，历史来源文件/工作表/行号保留原文字。文件名不等于受控原件 ID、版本或已核验文档，因此 `original` 保持 null；不生成虚假文档链接。

## 权限、审计与完整性

所有 AI 仍只允许当前服务端可信 admin 本人。普通角色即使持完整资格也拒绝，任意模拟身份拒绝；admin 身份还须叠加独立 `query:leases`、来源、记录、子市场和字段权限。复用既有资格表和审计体系，不另建身份或事实库。存量与未来资格不能替代成交资格，新列默认无权限。

读取前要求已持久化且链完整的 running 请求审计；数据库复查身份、会话、全局开关及资格修订。返回前再次查询当前权限，读取期间发生撤权或资格修订即拒绝交付。private definer 函数固定空 search_path，public 仅 invoker 包装，客户端 anon/authenticated 无直接执行权。

同一 SQL 语句对获权全集形成记录、计数、稳定身份检查和快照。筛选及权限在计数之前执行，不泄漏范围外数量；没有前台分页截断。超过 20,000 条或 16 MiB 明确要求后台任务，不返回截断统计。相同读取 ID 或相同来源记录身份重复则拒绝，不用静默去重掩盖损坏映射。来源展开另有 200,000 项上限，超限明确失败。

版本摘要只包含获权且本次选择的字段，不含 updated_at 或隐藏字段；隐藏租金、备注、原件文字改变不会通过可见摘要泄漏。解析层再校验全集计数、身份、范围和字段集合，分析结果递归冻结。

## 验证与边界

回归入口为 `leaseObservation.test.ts` 和 `ai-lease-observation-scenarios.mjs`；后者已接入现有 `verify-ai-query-auth.mjs`，由现有真实 Auth CI 任务运行。数据全部为隔离合成样本，实际加载最新成交视图定义、PostgreSQL 17、GoTrue 登录和 PostgREST RPC。历史基础表使用既有 F6 夹具，不把它描述为生产全库迁移重放。

回归覆盖项目/参考/逐行映射、分来源求和、加权 11、精确筛选与注入文字、字段最小读取、隐藏字段变更不影响版本、无审计/非 admin/模拟/直调拒绝、读取后撤权、1,205 条完整读取、零与缺失及重复身份拒绝。旧企业 AI 场景也在实际成交读层的合成记录上重新执行；其模型供应商仍为本机合成服务。

首次真实读取复现 SQL 中 JSON 取值与包含比较的运算符优先级错误（`operator does not exist: boolean -> unknown`），修正显式括号后七组成交实际场景通过。解析层新增历史估算标记反向测试也先复现错误放行，随后修正。真实测试生成的 CommonJS 依赖包曾被全库 Lint 扫入；按现有适配器规则，仅将这一生成文件加入忽略，业务源码和测试脚本仍完整检查。

最终全量 verify 为239文件/1579测试，类型、构建与审计覆盖通过，Lint826警告0错误；真实PG17/Auth/HTTP共138场景通过，焦点30项通过，安全顾问warn级无问题。执行结果见 [验证证据](lease-observation-evidence.json)。本包没有用户界面、自然语言语法或公开成交查询动作，视觉验收不适用；不能据内部适配器测试宣称主页成交查数、图表或下载已可用。后续必须先完成不可变结果、来源交付复查、恢复与同源文件，再开放主页入口。
