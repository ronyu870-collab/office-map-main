## 实际操作与数据路径

主页原结果下提供按需柱状图、双字段散点、两期比较图；保留原表。图元及数值按钮绑定同一 resultId/tableId/entityId/字段和来源；更换图种不执行新查询。柱图超过 25 条时显式分页，坐标尺度由完整图示范围确定，不重新截断 Top N 或并列。散点只绘制两字段均有效的联合样本，未知数量和原表保留，不暗示因果关系。

显式双字段列表语法新增到 `bounded-business-question/2`，例如“2026Q3CBD建筑高度与净有效租金列表”。两个字段均按权限核验；无年份、含糊租金、重复字段、尾随额外条件不会被丢弃或猜测。开放模型、多意图和连续追问仍未接通。

沿用主页的浅色连续布局、系统字体、20px 标题/14px 正文和 400/500 字重；图形只用品牌 #003e7e、正文 #172033、辅助文字 #667085、白色 #ffffff 与原有边框，不增加装饰卡片或新大字号。图表在主动点选后展开，正文、图表及原表共用阅读轴；下载选项收在展开菜单。手机保留数值按钮、来源、下载和原表，散点在局部滚动容器内显示。

比例水平图固定 0–100%，17.5% 不画成铺满横条；其他数值使用含零的共同尺度。变化百分点不与两期比例水平混在同一轴。比较图标题使用实际指标名，季度只作分类标签；新比较表记录 comparison-table/2，空置率差值使用原有精确百分点结果（5 而非 0.05）及 percentage_point 单位。既有归档不被静默改写，本包尚未生产启用。未知不填零，精确标签从原始分数舍入，几何位置使用明确的数值近似。样本数与图示项数分别标明。SVG 长标签换行，保留范围、样本、限制、结果编号及完整图元绑定，不接受外部 SVG、HTML、脚本或图片地址。

## 下载与资格

`POST /api/intelligence/query/artifact` 接收 requestId/resultId 以及受 schema 校验的 chart/export 动作。客户端不能上传数值、来源、角色、任意字段、SQL或下载路径。接口复用已有恢复控制边界：有界接收 → 真实登录/模拟身份验证 → 持久提问审计 → 当前资格 → 本人原请求/完整加密结果 → 当前全候选来源 → 生成 → 持久响应准备审计 → 再检查资格、来源和原流版本 → 返回。

`export:internal` 是独立能力，不因能查数、属于 admin 或能模拟别人而自动获得。沿用实际/有效身份能力交集、会话有效期和资格修订号。迁移只允许登记这个能力，不种入任何授权，不开启功能，也不授予数据库表访问。服务角色仍不能直接修改资格。

- Excel：实际 XLSX，保留数值类型、精确分数/来源、范围/公式/分母、快照版本与内部用途说明。已修正库 `type: array` 实际返回 ArrayBuffer 而函数错误声明 Uint8Array 的问题；边界返回真实 Uint8Array，文件摘要可核对。
- CSV：ZIP 内同时交付 data.csv 与 manifest.json，不丢弃来源或范围文件。文本公式注入防护沿用既有实现，真实数值保留数值含义。
- SVG：ZIP 内同时交付 chart.svg 与 manifest.json；后者含原结果的所有来源、条件、口径和图表规格。图表不由 AI 生图生成。

文件通过有身份校验的 POST 直接返回，不产生公共存储地址、长期签名链接或可绕过撤权的静态下载接口。`private, no-store`、安全固定文件名及 MIME；客户端核对 resultId、SHA-256 和当前身份后才交给浏览器。下载菜单仅展示当前资格，真正授权仍在服务端。服务端准备返回与浏览器开始保存都不能证明用户已读或保存完成。

单文件上限 32 MiB；SVG 支持最多 1000 条柱/5000 个散点，超出明确拒绝，不截断冒充全集。更大结果的持久导出任务、私有文件保留/撤权下载和资源配额仍待后续建设。已下载到用户机器的文件不能被服务器远程收回。
