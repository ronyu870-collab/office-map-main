# Colliers AI 回答决策与阅读体验

日期：2026-11-22。代码基线：`4833df3e581f631c2d26962c513c239a8bdacbb2`。本次为回答策略、归档兼容和呈现的纵向改动，沿用 AI 6.1 的工作集、文件、证据面板和状态保持机制。

## 结果与恢复

- `select_answer_results` 只接受本轮工作集或正式重新鉴权导入的结果引用；主结果、比较、辅助角色独立。多项独立查询没有合法选择时不使用最后一项充当答案。
- 历史数据任务及实际读取的历史结果同样参与选择判断；比较必须保留比较引用。寒暄与纯方法说明不因历史结果数量触发额外选择。地图链接带具体结果编号，比较／辅助结果不会跳到主结果；未选编号仍由服务端拒绝。
- 兼容响应字段 `answerSelection` 使用 `answer-selection/1`；原 `result` 仍为主快照。归档保存最多三份完整原快照，每份恢复、续问、来源、图表、地图及导出都复用既有领域授权复核。文件生成后的原始快照及 digest 不回写。
- 最新单笔成交按业务日期、精度、并列和明确范围判断；汇总明确标为替代信息。未给范围时提出必要澄清。模型供应商不可见的明细不等于用户无权，用户已获权正式结果仍完整交付。新聚合结果不公开受控分组计数。
- 旧协议与旧历史继续读取；没有可验证结构数据时保留原文，不从 Markdown 提取数字造图。
- 回答、图表及恢复会话共用一次获权恢复，选集与主结果共享原始快照对象；不通过放宽工作集碰撞或密封校验支持图表续问。覆盖新回答／旧 chart-only 修改成功、恢复会话与来源撤权拒绝。

## 默认阅读与保留能力

普通事实使用原始单元格，单实体呈现紧凑字段；排名与多期趋势默认显示合法主图，缺期留缺口。只有一个有效时间点时保留其原期间与数值，先前缺失期间不会占掉事实展示预算。全未知成交使用中性状态，合法零值保留。正式清单继续显示数据表；短汇总、方法和全字段明细按需展开。

数值列、联合散点样本、真实期间与真实楼宇身份共用资格判断；季度聚合不能进入地图。来源按成交、业务、知识、公开资料与楼宇季度命名，不再统一回退楼宇目录。详细限制与原始依据保留在数据依据中。

正文、用户消息、操作与输入共用居中阅读轴，普通图按阅读宽度显示；宽表保留数据宽度。成功保存不常驻，重查与长结果收起进入更多。表格筛选、三态排序、跨页选择、范围导出、真实文件、焦点返回及同一成果子树保持不变。320px 顶部按两行排列，保留全部触控操作。
