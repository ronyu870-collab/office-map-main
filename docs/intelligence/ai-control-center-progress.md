# AI Control Center 实施与验收记录

目标：用户 2026-11-25 的 AI 管理中心专项。基线 main `b303d3f6`（AI6 已合并）；复用独立干净工作区，分支 `codex/ai-control-center`。原工作区其他任务的未提交改动未触碰。

## A. 实际完成的功能

入口为管理员后台 `/admin?section=ai-management`，按需加载独立工作空间。沿用系统字体、颜色与控件；标题 20px、正文及说明 14px，两种常规字重，共同阅读轴及手机完整操作。

| 页面 | 实际行为 |
| --- | --- |
| 运行总览 | 完整区间请求／业务完成／运行与中断、P95、Token、费用、时间桶、执行路径、被动供应商证据及覆盖缺口 |
| 模型管理 | 真实登记目录、环境显式继承、候选修订、四项固定协议证明、独立批准；不自动启用候选 |
| 路由策略 | 三模式模型与回退、语义／总结职责、请求限制、已注册工具限制；预览、草稿、发布及并发冲突 |
| 用量与预算 | 供应商、模型、任务、模式、路径、状态、职责及获权用户筛选；完整区间排行与维度成本；真实日／月占用与余量 |
| 任务监控 | 服务端筛选、时间双向排序、游标分页、当前／历史状态及有界元数据时间线 |
| 故障诊断 | 预算、供应商、编排、工具、数据／交付、安全及配置分类；被动工具证据；可配置阈值、样本、窗口与告警处置 |
| 权限管理 | 管理、查询／导出、审计读、审计导出、成交、业务／Stacking、知识七类独立资格；版本、期限、范围、原因及真实操作者审计 |
| 评估测试 | 固定离线路由／正式计算／多轮／图表／Excel 内容检查与存档对比；固定合成连接、结构化、工具及流式供应商测试 |
| 配置记录 | 不可变历史版本、实际操作者、原因与合法回滚；回滚生成新版本，不解除暂停或恢复撤销资格 |

紧急控制支持新增付费暂停、供应商暂停、单模型暂停及既有全局 AI 开关。运行中任务保留请求配置快照，但后续模型发送必须重新核对当前暂停、资格与预算。

候选测试必须确认真实调用、明确原因及费用上界；最多一次调用、256 输出 Token、12 秒，测试日预算始终硬限制。测试不读取业务数据，不自动批准模型、发布配置或调用未登记地址。按同协议查看不同模型最新用量、时延和费用，明确其不代表业务质量。

## B. 模型切换与执行接线

- 统一契约在 `src/lib/intelligence/control/config.ts`，正式版本绑定模型目录及费率；共享 AI6 `modelRuntime.ts`，没有第二套 Agent 或付费预算账本。
- Quick／Professional／Deep、语义理解及结果总结的选择进入真实适配器参数；新请求读取新版本，旧请求保持原快照。模型切换不把确定性任务变成付费任务。
- 修复 `completeWithDeepSeek` 忽略传入 Model ID：旧实现的合成 wire 测试期望 `deepseek-v4-pro`，实际收到 `deepseek-flash`；修复后同测试通过。另有新旧请求版本、三模式、职责与回退接线回归；能力接口读取同一绑定模型，动态 OpenAI 不依赖旧环境 Model ID，仍核对本人披露资格与暂停。
- 以上为真实适配器构造的合成传输与隔离执行证据，未宣称已向真实供应商验收任一新型号。
- 密钥仍来自部署环境，管理响应仅给是否配置；端点保持适配器固定校验，浏览器不能提交任意地址、脚本或 SQL。OpenAI 披露名单及跨供应商许可保持独立。

## C. 指标与费用口径

请求和模型尝试独立计数；模型尝试按请求／尝试号去重，发送前拒绝不计付费发送。请求量覆盖已投影 AI 接口请求，包含恢复等操作；业务完成率只使用已知非问候任务的完成、部分完成、未完成及失败状态，排除澄清、安全拒绝和取消。历史未知任务类型不进入业务分母。

统计覆盖所选完整区间，分页只影响列表。区间为左闭右开，北京时间生成分钟／小时／日连续桶，跨日、跨月有真实 PG 回归。已知请求汇总时长用于 P95，单模型尝试时长不会混入请求 P95。

费用分为供应商报告用量对应估算、未知调用保留预留、账本占用和真实账单；真实账单及余额未接通，始终未知／未对账。缓存输入是输入子集，推理 Token 是输出子集，不重复相加。价格来源、日期、上下文和能力保持显式记录；无法核实的环境价格日期与限制为未知。

支持模型、任务、路径、模式、状态、调用职责和获权用户筛选；模型比较需按相同任务类型判断。排行包括费用、已报告 Token、调用、工具及耗时；费用未知的均值不冒充零。零模型调用只统计明确记录为零的请求。恢复指标表示重新验证后准备交付的合法结果，最终撤权会撤销成功状态，不冒称浏览器已收取。

原审计正文保持加密并作为正式来源。运营投影只提取固定元数据白名单，不复制问题、参数、业务结果、供应商原始错误、密钥或原生续接内容。当前覆盖起点、投影请求、审计请求及缺失事件均可见；不扫描解密历史记录填补未知。

## D. 数据库与生产启用边界

迁移：`supabase/migrations/20261125152942_ai_control_center.sql`，事务化创建以下私有数据：

- 独立管理资格、候选目录、不可变版本、当前指针、操作者草稿、实际管理事件。
- 请求／事件运营投影及时间、状态、配置、模型、错误与请求索引。
- 全局／供应商／模型／测试的北京时间日月额度与请求尝试结算。
- 注册模型测试、离线评估结果、告警规则／实例、跨实例告警时钟和管理请求限额。

全部私有表启用 RLS、撤销直接读取／写入；固定 RPC 仅 service role 可执行，空 search_path，实际身份、会话、角色和独立资格由服务端重新验证。运营读不授予审计正文、审计导出或业务数据资格；禁止通过管理页修改本人资格。管理事件写入失败会原子回滚变更。

全局硬预算使用整数美元纳单位、稳定锁顺序与原子预留，配置换版不重置余额；发送前拒绝可释放，未知用量或进程中断保留预留，重复结算幂等，跨日结算仍归属准入日／月。

初始迁移不创建任何真实管理资格、模型配置或候选验证，不提高预算、不打开原来关闭的 AI。旧部署仅在准确确认 RPC 尚未迁移时保留环境兼容；数据库故障和非法配置会拒绝付费发送，确定性结果仍可执行。

**本轮没有执行生产迁移、真实账号授权、生产模型变更或付费测试。** 实施步骤：

1. 获得对应生产写入授权后，对照实际目标项目执行此迁移，验证初始全局状态保持原值且目录／正式配置为空。
2. 通过已批准维护流程，核对真实管理员稳定 ID、所需独立能力、到期时间、维护人和变更依据，显式建立首位管理者；不得批量或自动授权。
3. 部署代码后，管理员显式登记原部署模型，核对价格来源、未知项及部署上限；预览并发布首个动态配置。新的候选仍需受限协议证明及独立批准。
4. 生产验收遵守费用与披露授权；确认新请求版本、预算与紧急控制。回滚创建新配置版本，不能恢复权限或解除紧急状态。

本轮未删除或批量改写正式审计。按每事件最多 8KiB、请求详情最多 512 事件做接口上界，实际元数据通常更小。运营归档／清理需要独立数据治理授权，当前不自动清除历史。已有正式审计继续按原制度保留。

## E. 与 AI6 及持续监控的集成

AI6 已在基线 main。语义解析、Agent、总结与供应商回退都进入同一运行时、请求累计预算及全局预留／结算。业务查询、数据计算、工作集、研究任务、文件生成、来源与交付授权沿用原实现。

投影合并到原审计 RPC 内，无额外投影网络往返；投影异常不撤销原正式审计，但会留下可查询覆盖缺口。告警在真实 AI 响应结束后通过 Next `after` 调用，并由数据库全局合并为每分钟至多一次；管理诊断读取也有限补算。页面关闭仍能依据新 AI 请求形成持久告警，不探测付费模型，不发送外部通知。

没有新增付费基础设施或队列。此机制按真实事件触发；完全无请求且无人查看期间没有独立定时探测，因此闲置期的中断判定在下一次触发补算，不宣称有全天主动探针。

管理端仅可见时 30 秒刷新、单请求链无重叠；Web Locks 协调同账号多标签。次标签只初次读取并重试锁，获得锁后接管。隐藏、离开、注销、身份变化和撤权中止请求并清空数据；返回重新验证。编辑有未保存保护、服务器草稿及并发冲突，不静默覆盖其他管理员发布。

普通首页、地图与业务页面没有新增监控组件、定时轮询或 Realtime 订阅；已有 AI 能力接口在获权后读取一次运行时绑定，确保模型切换和暂停在实际入口生效；唯一 UI 入口在 admin 动态分片。AI 响应后告警和付费准入的必要原子调用均独立于普通页面加载。

实际发现并修复：所选 DeepSeek Model ID 被忽略；脱敏包装导致投影遗漏；模型尝试时长污染请求 P95 的风险；最终交付只核对“任一管理资格”的撤权漏洞；无动态版本时环境模型暂停遗漏；发布成功后编辑器仍使用旧 revision；多标签可见性切换期间锁的旧闭包；配置校验及 UI 事件异常边界。均有针对执行路径的回归。

原有 Auth/HTTP 实际样本继续通过：全部获权子市场统计零供应商调用；CBD Top10 Excel 真实文件回读零供应商调用；图表／已有结果导出不重查；总结失败仍保留正式结果；取消检查点、跨用户、撤权和来源撤回拒绝。

PG17 本地合成审计基准 25 组对照：原审计中位 **0.496ms**、P95 **0.895ms**；合并运营投影中位 **0.571ms**、P95 **1.620ms**，两者均一次数据库往返。详情查询实际使用 `ai_operation_events_request`，该小型隔离样本执行约 **0.025ms**。这是本机数据库开销证据，不能当作生产或供应商性能承诺。

本轮未设置独立视觉、截图、真机或 Preview 审批门槛。普通页面零轮询由入口隔离和生命周期测试核对；生产规模容量、真实供应商延迟及付费质量没有模拟成实测。

## G. 模型测试费用与外部依赖

本轮真实付费模型调用 **0**，没有供应商真实 Token 或账单可报告。协议和业务适配器测试采用合成传输；真实模型验收状态为 **BUDGET_BLOCKED**，不能写成 DeepSeek／OpenAI 生产模型通过。管理页面具备实际有界测试与结果对比能力，但未擅自执行。

尚未正式启用的能力：生产迁移后的管理入口资格、真实新模型的协议／业务质量证明、真实账户余额与账单对账，以及独立无请求定时探测。前两项需要生产／账号／费用授权；后两项需要可用账户接口或部署调度配置。没有用占位成功、假余额或假健康补齐。
