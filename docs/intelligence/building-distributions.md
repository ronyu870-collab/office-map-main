# 楼宇分布、分位数与箱线图

本地隔离工作包，继续当前admin本人及独立数据/导出/审计资格。无新增数据库迁移、生产启用或模型调用；复用既有一次性获权快照、完整提问审计、来源复核及文件交付链。

## 输入与统计契约

支持`CBD建筑高度分布`、`2026Q3CBD、金融街净有效租金分布`、`2026Q3全部获权楼宇空置率分布`等完整问题。语法版本`bounded-business-question/7`；属性可查高度、楼层、车位，季度可查租金、空置率、总面积、空置面积，也可在明确季度跟踪楼宇范围查看来源属性。来源属性始终按当前可用来源候选解释，不能把查询季度说成属性的历史有效日期。附加未识别条件、含糊租金和相对日期继续澄清，不忽略后缀。

结构化`distribution`必须选择登记measure、获权scope与适用季度，可复用既有数值过滤。季度measure缺少季度直接拒绝。数据资格按实际输入字段检查，租金需总面积和净有效租金，空置率需总面积和空置面积。统计基于完整获权候选，经筛选后再计算；不让显示分页或无权楼宇进入分位数与数量。

各楼一票、等权分布。租金/空置率逐楼复用现有季度有效性引擎，租金严格为正且总面积有效，空置面积可为0但不能超过总面积；直接数值属性按字段注册规则验证。原表保留有效、缺失、无效、冲突和未核验；未知不作为0，异常记录不能悄悄删除。

分位采用Type 7：升序有效样本n，位置h=(n−1)p，在相邻观察值间按精确有理数线性插值。给出min/P05/P25/median/P75/P95/max及明确标注的逐楼简单平均；这里的平均不替代市场租金面积加权口径。原始排序、差值、分位、围栏、区间判断使用未舍入值；图形位置为近似投影，数字标签最终展示时才舍入。

离群围栏为Q1−1.5×IQR、Q3+1.5×IQR，仅严格超出围栏者标记；值等于围栏仍在内。少于4个有效样本不判定离群，须线用min/max；其他样本须线到围栏内实际记录。所有离群值仍参与均值、分位、直方分箱及导出，标记不等于数据错误，也不推断市场规律。

直方分箱采用ceil(log2(n)+1)个等宽箱，最多20；左闭右开、最后一箱含上界。常量仅一个两端均包含的箱；没有有效记录则统计未知、没有伪造的0值箱。每个有效楼宇恰入一个箱，空箱保留0计数。边界判断用精确值，显示标签舍入可能缩短区间，完整精确上下界保留在结果analysis与文件manifest。

精确平均求和的分子/分母超过16384二进制位时拒绝整个同步执行，不截断样本或默默改用浮点统计。大有理数的近似投影避免Infinity/Infinity，但精确值仍保留。后台大规模任务尚待后续，超限不计查询成功。

## 主页、图表与文件

主页给出覆盖、中位数/P25/P75/min/max及离群说明，默认明细为全部候选楼宇。按需查看直方图或箱线图，切图不创建新结果；分位/箱线数值按需展开，同一字体/表格样式与原页对齐。直方区间及数量使用成组表格，数量可打开来源；箱线图离群点使用结果中的精确判定，不用近似图坐标重新判断。手机直方图/表格在内部滚动；单箱线图按容器宽度伸缩，坐标使用百分比、文字保持原字号，避免固定640px使箱体落在初始可见区域外。原表和来源入口保留。最终390px实页：箱线图容器/内容均324px、箱体横坐标203.13–270.21px完整可见、文字14px、页宽390px。

图表统计绑定同一个analysis，观察值同时校验原表实体、数值、状态和来源，分箱校验成员与计数。频数图元明确携带analysisPath，不能冒称原表里的某栋楼单元格；箱线图逐楼值绑定原表。回执布局为histogram_all/box_plot_all，仍不声称用户已经阅读。

XLSX保留数据/精确值/来源/快照页，增加分位统计、分箱统计和分箱成员，成员独立逐行避免把全量ID挤入单元格；数字仍为数值，未知为文字，不可信文本不执行公式。CSV和两类SVG连同manifest交付，来源、边界、成员、算法和离群标记均来自原结果，不重读最新数据。空置率原始比例与百分比显示单位明确区分。

所有AI仅限当前admin本人。最终合成admin降级为viewer后刷新主页，AI输入与Intelligence入口均消失；原有该角色获权的地图、季度填报、成交填报及研究资料入口保留。普通角色即使具备独立资格仍拒绝，当前字段、区域、源记录撤回会影响旧结果恢复与下载；已下载文件不能远程召回。
