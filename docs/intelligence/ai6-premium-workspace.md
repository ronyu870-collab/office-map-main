# Colliers AI 6.1 对话与研究成果体验

本轮基于 AI 6.0（`fd0c159`），保留 `response/1`、`response-presentation/1`、获权结果快照、查询／导出服务和历史恢复。没有数据库、模型、依赖或权限配置变更。

## 最终行为

- `composeResponse()` 依据正式 operation 与经校验的成果描述安排结果块；列表／排名表格优先、趋势图表优先、文件交付附件优先。普通聊天保持正文；未知协议和部分执行警告沿用兼容路径。
- `HomeQueryResult` 按组合顺序分发摘要、指标、研究、文件、分析、楼宇、表格和来源。结论与方法分层；标题从实际范围、字段和业务域生成。
- 来源统一为“数据依据”：默认摘要保留期别、样本与方法，面板展示具体关联记录、原值、原件状态；高级技术信息默认折叠。候选来源不冒充指标实际依据，重要限制继续可见。
- 数据表可组合返回字段中的子市场／等级／行政区条件、逐项移除、恢复原始排序；选中状态区分筛选内外。导出先选范围再选 Excel／CSV 与来源，仍传原快照行索引并由原服务复核权限。
- 表格、图表和研究成果共用工作区；桌面并列、窄屏覆盖。稳定 portal host 保留组件、滚动、筛选、多选和图表配置；切换面板不重新查询。窄屏键盘包含、Escape 和触发点焦点恢复纳入回归。
- 两条既有 SVG 路径共用图表框架与操作；保留各自权威计算和真实导出。增加精确点位键盘访问，坐标设置折叠并验证上下界，下载使用实际应用配置。
- Markdown 保留语义标题层级和自然软换行；菜单统一关闭／焦点规则，文件采用紧凑布局并沿用内部分析限制。手机保留可发现的新对话入口，输入框单实例和中文输入处理不变。

## 验证入口与范围

- `npm run verify`：审计契约、全项目类型／Lint、Vitest 和生产构建；新增用例由既有 Vitest 入口直接执行。
- `home-query-data-table.test.tsx`：组合条件、筛选外选择、恢复排序、不可变快照；同一组合筛选用例在原 main 失败、改动版本通过。
- `home-query-premium.test.tsx`：表格与来源切换、焦点恢复、Markdown、坐标边界及当前图表配置下载。
- `scripts/verification/home-query-experience-p2-browser.mjs`：实际生产构建和隔离 HTTP 夹具；1280／1536／768／390／320 视口、普通角色拒绝、历史／多轮、输入法、表格搜索／选择与展开返回，无新增查询请求。
- 原 Excel／CSV／PDF、图表文件、历史、授权及真实 Auth／HTTP 持续回归由必需 Verify CI 运行。搜索焦点门禁按 PR 精确 head 运行。

浏览器夹具不是生产市场数据，模拟视口不代表真机。未以本轮 UI 测试宣称真实性能提升；合并和正式部署状态以 PR／部署记录为准。
