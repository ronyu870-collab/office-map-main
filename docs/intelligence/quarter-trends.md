# 多季度查数与同源折线

本地工作包，2026-11-13。新 AI 仍默认关闭，只允许当前 admin 本人并继续核验独立查询、数据和导出资格。本包没有生产数据库迁移、推送、main 合并或真实资料出站。

## 查询与口径

- 支持净有效租金、空置率、季度总面积；明确起止季度，包含首尾，连续 2–40 个季度。跨年按季度顺序展开，缺期也占一个位置。
- 示例：`CBD净有效租金2026Q1至2026Q4趋势各期样本`、`CBD空置率2026Q2至2026Q3趋势全期间共同样本`。有限语法整句解析，不忽略额外条件；相对日期、未说明模式、倒序或超限期间要求澄清。示例不代表库内已有相应时期数据。
- 结构化 `trend` 计划复用现有获权范围和组合筛选。查询前明确所有季度及指标所需字段，一次现有 SQL 快照 RPC 完整读取；不按前端分页截断。
- 各期模式分别选择当期有效记录。共同样本模式在逐期筛选及指标有效性判断之后，取**全部查询季度的交集**；不能用每两个相邻季度的不同交集冒充整段固定样本。一期完全缺失时共同样本为空，所有期数值未知。
- 净有效租金按有效总面积加权；空置率用同一有效记录的空置面积合计除总面积合计；总面积累加有效季度记录。继承精确分数计算，不先舍入再计算。空置面积超过总面积的记录无效，缺失、无效、冲突、未核验分别计数。
- 表格逐季列出指标、实际参与数、当期有效数、面积或样本分母、候选覆盖。总面积的分母是有效楼宇数；零参与对应的零分母不表示指标为零。
- 使用当前获权楼宇目录，不宣称历史时点目录重建，也不自动把样本变动解释成市场原因。权限范围外的记录不计入数量和覆盖。

## 快照、来源及图表

- 所有季度必须属于同一个数据版本、权限范围和当前候选全集；缺期保留楼宇行及缺失事实。执行器拒绝不完整、重复、错误期间或混合来源范围。
- 一个不可变 QueryResult 包含完整期间分析、参与记录、排除原因、公式版本和所有季度来源。来源可追至数据库记录/字段/版本；没有原件关联时明确只有数据库来源。
- 表格与折线、柱图、CSV、XLSX、SVG 使用相同 resultId 和已存结果。切图不重新查询；旧结果恢复不悄悄替换成更新后的数据。当前权限和任意参与季度的来源授权在恢复、作图和下载时复查。
- 折线按连续季度等间隔排列，未知点断线，孤立有效点仍显示；真零保持零点。空置率用完整 0–100% 轴，其他指标保留零基线。图形位置使用近似数，表格和图元提示按原始精确数展示。
- 主页在已有结果区按需展开图表，不新增独立聊天页或装饰卡片。手机保留完整季度，通过图表内横向滚动查看；表格继续现有 25 行分页、来源展开和导出操作。
- SVG 包含全部点及来源映射元数据；长区间稀疏显示轴标签，完整季度值仍在同包 manifest。Excel保留数值类型，CSV/Excel未知使用明确文本，不能填零。
- 交付审计支持 `line_all` 软件 DOM 报告；这不表示用户读过所有点，也不证明浏览器已保存文件。
