## 用户入口与权限

沿用主页原位输入、结果、来源与文件入口，不另开 AI 页面。全部 AI 仅当前服务端可信 admin 本人可用，viewer/editor 即使有查询资格也拒绝，任何模拟身份请求（含本人及空模拟头）均拒绝。admin 仍须独立来源、记录、子市场、字段与导出资格，审计正文资格也不由 admin 自动获得。执行、恢复、作图和下载都重新确认当前权限与全部候选来源，不能通过旧结果绕过撤权。

支持完整问题：`CBD全部来源成交行业占比`、`2026Q3CBD日常成交子行业占比`、`CBD历史成交需求类型占比`、`CBD全部来源成交子市场占比`、`CBD全部来源成交2026Q1至2026Q4趋势`。日常、历史、全部来源可分别选择；趋势必须提供 2—40 个连续季度。受控语法更新为 `bounded-business-question/14`，额外未支持的条件不静默丢弃。获权示例由现有能力接口提供。

## 确定性统计与未知

分类使用原行业、子行业、需求类型或子市场，仅修剪首尾空白，不归并行业，也不让模型补分类。分类未记录独立一组，内部身份与原文字恰好等于“未记录行业”的分类分开。每个来源各自计算，不合并日常与历史的分母。

- 记录数占比 = 本组原始记录数 / 同来源全部入选原始记录数；这是数据库记录，不称跨来源独立成交笔数。
- 已知面积占比 = 本组有效面积合计 / 同来源全部有效面积合计。未知分类的有效面积同样进入分母。无正分母或本组面积全部未知时占比未知；真实零面积仍为零。
- 不同记录企业名称数只按原名称去首尾空白、忽略大小写计数；空名称另计，不推断法人身份。同名可出现在多组、多季，各组名称数不能相加为整体企业数。
- 趋势只按原日期或明确季度分配，只有年份的记录仍列“仅可能涉及”，即使整个年份落入查询区间也不猜季度。未知、无效、冲突及范围外各自保留。
- 连续空季度记录数为零只表示获权数据库没有明确入期记录；面积没有有效记录则未知、折线断开，不称现实市场零成交，不解释市场原因或净吸纳量。

数值由 Decimal 精确计算；同一归档结果绑定表格、文字、分类柱图、按来源分别排列的季度折线、CSV/XLSX/SVG及本人恢复。趋势可选择面积、原始记录数、不同记录名称数；改图指标不改快照。占比单元绑定完整分母来源，未入选年份候选也保留覆盖证据；撤回这类来源同样阻止旧结果交付。源数值后改不替换旧快照值。

## 容量边界与未完成项

新增同步计算保护：每个来源最多 100 个分类、整个表最多 100,000 次单元格来源引用；超出时失败，不截断分组或删掉分母来源。沿用现有读取、归档与权限协议，没有新增数据库函数或资格。

实际测试发现 1,005 条成交虽能完整读取并确定性汇总，完整证据结果会超过现有 16 MiB 同步归档限制。当前 HTTP 返回失败且不交付结果，审计保留失败终态；这不是大数据查询能力完成。初始测试错误地假定此规模能同步成功，实际返回 503；补充纯计算/归档边界与真实接口失败审计检查，明确记录限制。容量错误目前仍用通用未交付提示；后续须建设大结果物化/分页归档、后台任务及清楚的容量状态，不将上限任意扩大、截断记录或省略来源当作修复。

自由楼宇名称解析、多条件自然语言、更多成交比较/交叉分析、跨域连接、多轮、PNG/PDF、真实模型与治理、审计生命周期等完整计划项目继续；原 99 项及 T01—T60 全部保留。
