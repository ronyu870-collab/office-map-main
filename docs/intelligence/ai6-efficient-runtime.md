# Colliers AI 6.0 执行效率重构

日期：2026-11-25。基线：`cd9b5410`。本次属于执行架构重构；未调整生产开关、授权、计费上限、数据库结构或业务公式。

## 已确认根因

1. 明确查数与文件任务仍要经历模型选工具、读结果和总结；文件步骤依赖模型再次发起调用。
2. 季度问题的“全部获权”被两套规则收窄成 tracked；`compare_market_segments` 又要求模型先列出 2–8 个子市场，无法直接表达全部获权分组。
3. `semanticExecution → modelIntent` 原有独立供应商请求，未归入 Agent 的累计预算和逐次模型尝试。
4. 完整领域指令、历史文本与工具观察重复传输；模型预算失败会直接中断已有正式结果的交付。普通查询缺少研究任务已有的中断检查点。

## 实际实现

- 五条逻辑路径：direct_response、deterministic_query、single_interpretation、bounded_agent、deep_research。Quick/Professional/Deep 保留为交互与资源策略，不强制普通任务多轮模型调用。
- 完整条件由现有受控语义规划器验证；只剥离完整的 Excel/CSV/图表交付后缀。未消费的排除、复合、领域条件不进入确定性路径。英文只接受完整模板，其他表达仍走受控理解。显式新范围不继承旧 buildingIds；合法槽位续问继承已验证条件。
- 确定性路径直接调用相同注册执行器、工作集、正式 QueryPlan 与既有交付归档；没有合成模型回复来伪造零调用。真实 Excel、图表仍由既有渲染器生成，下载继续重查独立资格与来源。
- 数据权限、可用季度由当前授权及字段有效记录确定性读取；不把当前日历季度当作数据可用期。用户明确禁止外部模型时，路由与供应商入口同时阻断；完整受支持查询仍可本地执行，其余条件说明限制。
- 已重新鉴权的历史表格支持完整匹配的排序、带单位数值筛选及翻页，0 次模型调用；只保存展示条件，完整行与来源不裁剪，归档恢复后沿用。
- 新 `execute_query_plan` 暴露严格、有限的现有计划，不开放 SQL；`compare_market_segments` 支持全部范围、单轴分组和多指标。结构化参数通过同一转换函数执行与去重。
- 语义提取注入同一个请求 runtime，供应商适配、账户 admission、回退、预算预留、取消和逐尝试审计统一。Agent 兼容查询不再嵌套另开供应商请求。
- 不存在经校准的兼容 tokenizer 时，继续使用明确标注的 UTF-8 硬上界；没有把字节机械除以 3/4，也没有提高 60,000 token 或默认 0.25 USD 预算。预留、供应商报告用量和未知用量分别保留；实际账单仍为未核对。
- 指令按领域裁剪，工具按任务及结果阶段选择；较早的大观察压缩为引用与限制，最近两次工具观察保留预览。工具调用配对和 OpenAI 不透明 continuation 保持完整。
- 同义正式计划、参数键顺序与集合顺序统一去重；排序列顺序不重排。相同失败不重复执行后端，允许参数修正；连续无进展有界终止。
- 可选模型总结失败时保留正式结果并标记 partial；取消、硬限和模型故障后，普通中间结果也通过加密归档保存检查点。恢复复用现有本人、会话、当前授权、来源和版本校验；撤权拒绝交付。
- 现有审计台增加当前样本的执行路径、完成数、快速路径数、平均/P95 时延与预算拒绝原因；逐模型尝试增加职责和上下文体积。未把局部样本冒充生产全量统计。

## 输入与调用对照

[可复核 JSON](ai6-runtime-context.json) 来自 `node scripts/intelligence/benchmark-ai6.mjs <冻结基线目录>`；比较实际代码生成的序列化消息与工具目录，**不是供应商报告 token、实际费用或端到端时延**。

| 场景 | 修改前模型调用 | 修改后模型调用 | 旧首轮可发送字节→当前供应商输入字节 | 完成状态 |
| --- | --- | --- | --- | --- |
| 什么是净有效租金 | 至少1轮，离线路径 | 1轮，协议测试 | 14,599→2,951 | 解释路径；工具0，无真实供应商质量验收 |
| 2026Q2 CBD净有效租金 | 至少1轮，离线路径 | 0 | 14,600→0 | 确定性正式结果 |
| 2026Q2全部获权楼宇净有效租金按子市场比较 | 历史budget_exceeded，次数未知 | 0 | 17,001→0 | 真实授权聚合；工具1 |
| 把CBD在2026Q2净有效租金最高的10栋楼导出Excel | 用户历史真实样本4次后失败 | 0 | 16,472→0 | 正式查询与真实Excel；工具2 |

概念问答字节减少约 79.8%；明确查询/文件任务省去模型输入。用户提供的历史 Excel 样本为 4 次真实调用、32,908 输入 token、419 输出 token、估算 0.010375 USD 后失败；当前离线与隔离场景的 0 次不冒充新一轮真实 DeepSeek 验收。真实模型测试状态：**BUDGET_BLOCKED（本轮未获付费测试授权）**。

明确快速路径不产生模型报告 token 或模型费用；付费模型调用实际为0。夹具中的 usage 为协议输入，不能当成真实报告 token。没有真实供应商账单，未知历史实际费用保持未知。新 Auth 专项日志输出 `AI6_EXECUTION_SAMPLE`，仅反映隔离本机的端到端处理耗时、工具数与调用数；没有同环境旧版本端到端样本，不报告时延提升百分比，也不把单次样本当作生产P95。

本地构建后 HTTP 单次样本：全范围租金比较116ms、空置率105ms、核心Excel生成请求106ms；均0次供应商调用，工具分别1、1、2次。Excel另行实际下载并回读。此样本只用于确认执行路径，没有稳定性或生产性能结论。
