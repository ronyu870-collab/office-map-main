# 同一快照的区域、等级季度比较

本工作包在既有季度查询上增加当前子市场、等级分组。所有 AI 仍仅供当前 admin 本人使用，查询、字段、记录、导出与审计资格独立检查。仅本地和可丢弃合成环境；没有生产迁移、真实账号授权、模型调用或后续 main 发布。

## 可执行范围

- 单季度按子市场或等级比较净有效租金、空置率、总面积；显式列出多个子市场或查询全部获权楼宇。
- 2–40 个连续季度的分组趋势；各期有效样本，或每组自身在全部查询季度内的共同有效楼宇交集。
- 结构化计划可组合现有数值过滤。自然语言仍是完整匹配的受控语法，不是开放模型规划，不会忽略未识别的附加条件。

主页可提交的例子：

```text
2026Q3CBD、金融街净有效租金按子市场比较
2026Q3全部获权楼宇空置率按等级比较
全部获权楼宇净有效租金2026Q2至2026Q3按子市场趋势全期间共同样本
```

## 数据与统计契约

所有区域、等级和季度值来自一次受控数据库快照。分组来源使用 `buildings.submarket/grade` 的楼宇记录、版本、原值、字段和 `database_only` 标识；不是另做多个查询再拼接。原件尚未关联时不伪造页码或已核验声明。

分组使用**当前目录分类**，不能声称重建了历史子市场或历史等级。跨期要求相同获权楼宇全集及分类版本，异常拒绝。未填写/空白分类单列未知；字面值 `null` 与真正空值不同。指定但没有获权匹配记录的子市场保留空组，不据此推断现实中没有楼宇。其他无权区域、记录及数量不会作为覆盖分母返回。

租金沿用有效面积加权；空置率沿用同一有效记录的空置面积之和除总面积之和。各组分母独立，不能对组均值再求简单平均或相加空置率。表格逐组逐季保留实际参与数、当期有效数、面积/楼宇分母、候选覆盖、缺失/无效/冲突/未核验以及来源。共同样本是每组自己的全期间交集，不是让不同区域使用同一批楼宇。

先在获权全集建立分组，再逐期筛选和取交集，因此筛选后空组不会消失；未知筛选决策保留在完整条件证据中。无有效样本和缺期表示未知，不补零、不跨期填值。超过 50 组明确拒绝同步执行；后台大查询任务尚未实现，不能称已自动转为后台任务。

## 图表与同源文件

分组趋势默认上下排列的小折线图，采用一个颜色、共同季度和相同纵轴范围；不同组不交叉连接，缺期断开。空置率使用 0–100% 纵轴。仍可切柱图，表格和来源入口不变。手机图表内部横向滚动，不压缩为无法辨认的细线。

图表全部引用原结果单元格，CSV/XLSX/SVG 与正文、表格保持同一 `result_id`、精确值、参数、来源和数据版本。分组字段也进入来源清单，图表交付报告使用 `faceted_line_all`；报告仅表示客户端软件动作，不能称为用户已读。

## 权限与升级

新增迁移 `20261113145743_ai_query_group_dimensions.sql` 只扩展既有来源复核函数的目录字段白名单为 name/submarket/grade，并返回 `catalog-dimensions/1`。保留原管理员/会话/资格、本人结果、获权区域/记录、季度非草稿、字段检查和访问审计；没有新增直接客户端执行权。

新应用恢复分组结果时必须收到匹配来源策略标识，旧库不能以缺少维度校验的响应放行。分组查询、图表和文件仍经过完整接收审计和交付前权限复核。楼宇移出当前获权区域后，旧分组结果恢复、图表和文件均拒绝；不会为了刷新权限而重算旧结果数值。

后续获准发布时先保持新查询关闭，部署匹配迁移和应用并验证，再按正式启用授权开放；本工作包没有执行这些生产步骤。回退优先关闭能力，不撤销 admin 限制或扩大字段、来源权限。
