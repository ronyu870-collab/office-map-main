# Colliers AI 5.0 阶段 10：受控专题研究与综合成果

2026-11-22。实现状态以对应 PR、精确 head 的必需 CI 与实际部署分别判断。本包不操作生产记录、私有原件、生产用户资格或功能开关，无新增数据库迁移。

## 执行流程与范围

`plan_research_task` 接收地区、明确季度范围或最近已结束季度、指标、样本方式及可选数据模块。服务端将规格编译为固定工具步骤，不执行模型提供的 SQL、脚本、工具列表、来源、业务数值、路径或正文。用户未指定期间时为北京时间最近四个已结束日历季度，缺期保留未知，不寻找“最近有数季度”。核心口径不明确时 Agent 先澄清；已确定步骤自主执行。

`advance_research_task(taskId, afterStep)` 每轮顺序执行最多两个已有正式工具。每个步骤记录工具、实际参数、依赖、状态、结果 ID 与安全错误码；步骤完成写入加密审计。游标不匹配拒绝，重试复用已完成结果。最多两个子市场、八个季度、八个数据步骤；超过限制明确拒绝，不能静默裁剪。一个工作集对应一个研究计划；新的专题可在新对话中建立。普通后续查询继续使用原查询路径，不被旧研究结果覆盖。

计划复用以下能力：

- 季度市场：`analyze_market_trends`，多地区按子市场分组；`analyze_rent_vacancy`、`analyze_distribution` 可选。同比、环比、共同样本、分布和异常结论均读取既有确定性分析，不再计算另一份业务数值。
- 成交：`query_lease_transactions`，历史与当前治理视图合并、季度或行业聚合，继承原身份去重、日期精度、小样本抑制及租金口径，不包含客户或经纪人字段。
- 业务：`query_building_dossier`、`query_submarket_profile`、`query_future_supply`。楼宇选择约束季度与成交查询；子市场资料和供应为所选地区的独立模块范围，保留目录与提交资料的区别。
- 证据：`search_internal_documents`、`search_public_building_information`，继续使用阶段 09 的授权、版本、引用及公开服务配置。私有正文不进入 DeepSeek；没有配置公开服务时明确受阻，不虚构联网。

`review_research_task` 检查计划覆盖、未知／受控值、单位注册、单元格和确定性结论的来源绑定、可用图表及成果披露边界。正式引擎记录的“未知指标 + 零有效样本／零分母”可以生成带限制的报告；无来源的业务指标不能生成。有效数据不足不编造结论。

`generate_research_deliverable` 仅在全部步骤完成、已审查且当前授权有效时生成选择的格式。不能以内部研究资格进行对客发布；`purpose=client` 拒绝，需要另外的正式发布流程。

## 成果对象与恢复

根结果 `parameters.dataDomain = deep-research/1`，沿用现有 `QueryResult`，主要对象：

| 对象 | 内容 |
| --- | --- |
| `researchTask` | 计划版本、任务 ID、规格、日历范围、步骤依赖与状态、结果引用、创建及更新时间 |
| `researchSections` | 最多八个完整正式结果及同源图表规格；保留原结果对象及 digest，不以模型观察页代替全量数据 |
| `researchReview` | 覆盖与生成资格、阻塞／警告、确定性事实及来源 ID、独立推断列表、方法和内部用途 |
| `agentReport.sections` | PDF、Word、PPT、Excel 共用的正式成果模型；与研究工作集必须完全一致 |
| `researchDeliverables` | 本次真实生成的格式；未生成格式不能通过根结果下载接口获取 |

模型仅获得安全的任务进度及已有工具的获准观察，不得把模型自行撰写的数字或结论混入成果。事实来自正式结果；当前自动推断列表为空，不输出因果解释或无依据预测。成交面积不代表净吸纳量，未来供应目录不代表实际交付，跨域范围与样本不自动相加。

工作集通过原分块、加密、完整性校验、本人会话绑定的结果档案保存，复用历史与恢复接口。浏览器中断或本轮时间到达后，服务端在身份和来源复核通过、仍可运行的条件下写入 `state=interrupted` 的合法检查点。审计流 `succeeded` 表示档案完整写入，研究自身明确为 `executionStatus=partial`，不代表研究完成或文件已保存。恢复重新编译固定计划并校验依赖、时间范围、顺序和结果引用，已完成步骤不重查。

这是请求内的有界执行与断点恢复，不是后台长任务队列。进程被强制终止、审计不可用或撤权时不能保证写入当轮检查点；可用状态以最后完整合法档案为准。继续执行仍受当前身份、会话、资格、有效期与原来源限制。

## 文件与交付

| 格式 | 实现与内容 |
| --- | --- |
| PDF | 原 `pdf-lib` 与嵌入的 Noto Sans SC 字体，沿用完整长表分页、同源 PNG、来源附件及页码；共用新成果模型 |
| XLSX | 复用 `exports.ts` 的真实工作簿生成，逐结果合并完整数据／来源／口径表，保留数值、比例、未知与安全文本 |
| DOCX | 锁定 `docx@9.16.0`，原生可编辑段落和表格、中文字体声明、重复表头、自然长表跨页、节间换页、页眉及 PAGE/NUMPAGES 字段、同源 PNG |
| PPTX | 锁定 `pptxgenjs@4.0.1`，16:9、原生可编辑文字和表格、明确分页、中文字体、同源 PNG、内部用途和版本页脚 |

Word/PPT 复用一套中文字体及标题／正文两档文字；字体声明为 Microsoft YaHei，阅读设备需提供兼容中文字体，PDF 则自行嵌入字体。表格字段多时分组列示并重复身份列，长表全部保留。图表的重复说明进入可编辑正文及来源页，图元与坐标仍来自现有引擎；不另建图表计算引擎。Office 文件内嵌惰性 `customXml/colliers-research.xml` 记录完整表格、来源、期间、精确值、图表规格与结果版本，不包含外部资源关系、HTML、脚本、宏或任意模型内容。

既有成果预算继续生效：4000 行、15 MiB 档案、800000 文本字符、PDF/PPT 最多 200 页、下载文件最多 32 MiB。Office 表头／图像／标题无法可靠排布时明确失败，不裁剪数据或把失败格式标为已生成。Word 页数由阅读器布局和页码字段更新确定，不虚构固定页数。

当前回答提供实际生成格式的可信下载按钮。服务端生成、浏览器发起下载、实际保存为不同状态；只记录前两种可观察状态，不声称已保存桌面。下载沿用认证 POST、当前来源复核、文件 MIME／扩展名、SHA-256 与签名回执。没有公共文件地址。保留原有单结果导出和操作能力。

## 权限及验证

仍限 admin 本人及独立 AI 查询资格；各数据域的研究／字段／范围权限取交集。供应和子市场资料沿用原模块要求，不因专题研究放宽全楼宇资格约束。导出还需 `export:internal` 和成交／业务模块独立导出资格。文档检索或公开检索不自动取得原文再分发许可，因此包含该类证据的工作集可以查看、恢复，成果生成被阻止；未补建未授权的文档导出路径。

每步、生成前后、归档交付、历史恢复及每次下载均复核当前身份、来源和权限版本。原来源变更、楼宇合并、资格撤回、跨用户、角色降级或会话失效均不能利用旧工作集绕过。

验证进入现有必需 CI：固定计划与游标／依赖／中断恢复测试；确定性缺失与零、事实溯源、无证据和对客拒绝；真实 DOCX/PPTX ZIP/XML、中文、完整长表、图像 PNG 签名、页码字段及 PPT 几何边界；原 PDF 和 XLSX 回读；真实本地 PG17/Auth/HTTP 的多工具组合、四格式下载、恢复不重复查询、原来源撤回、跨用户及生成中撤权。模型仅在测试中使用确定规划夹具，鉴权、数据库、文件生成和正式下载路由均真实执行。

本轮按用户授权豁免人工浏览器、截图与独立人工视觉审查；保留工程、权限、数据一致性和文件解析回归。具体最终测试数量及 PR 状态记录在 PR 中，不把本地通过写成生产已启用。
