# 受控审计导出（本地隔离工作包）

基线 `e275412bce49d0f9296b62d061fa792d529defdc`。本包新增内部 JSON 审计文件，未推送、合并 main、生产迁移、启用 AI 或给真实账号授权。所有 AI 仍只允许当前 admin 本人；审计查看与审计导出是两个独立资格，业务结果导出资格不能代替审计导出资格。

## 用户路径与文件内容

审计检索完成后，展开「导出审计记录」，下载本页匹配记录；详情可下载单条及关联回答。分页范围明确，不能把本页说成全部命中结果。接口接受 1—50 个不同的 intake/stream 目标，不接受查询表达式、任意文件路径或外部地址。JSON 保留原文与结构化数值类型，避免将正文当作电子表格公式执行。

文件包含选定目标、请求编号、原始操作账号、每条读取时点、加密档案校验后还原的提交原文、关联回答快照、来源、事件与完整性状态；明确凭证继续遵守原接收时的脱敏规则。没有原始附件副本，不查询最新业务数据重算回答，不添加模型生成内容。孤立提交允许关联执行为空；历史缺失/不完整回答保留明确状态。缺失目标、事件链损坏、解密失败或文件超过上限时整份失败，不偷偷删除目标后声称完整。

记录使用各自的读取版本，不声称跨记录同一时刻的全库快照。文件中的人员是不可变操作账号，不将当前目录姓名冒充历史姓名。响应生成、响应准备、客户端报告及人类阅读严格区分。

## 权限与审计边界

- `POST /api/intelligence/audit/export` 复用当前真实 Auth 会话、当前数据库角色及审计读取授权，再要求 `ai_audit_export_grants` 明确启用且未过期；默认无资格。不依靠前端隐藏、请求自报 admin、姓名或用户 metadata。
- 匿名、viewer/editor、停用、注销、过期会话、模拟身份（含自模拟）、跨源与无独立资格均拒绝。返回文件前重新核对角色、会话、两类资格及版本；读取后撤权或任一资格变动不能交付已读文件。
- `ai_audit_export_events` 依次记录 read、prepare、client_dispatch。读取事件加密保存提交的目标请求；准备记录绑定准确文件 SHA-256 和字节数；没有可靠审计记录时不返回文件。客户端报告绑定签名、账号、会话、准备编号、文件摘要/大小和至多五分钟有效期，重复有效报告去重。
- 客户端逐字节校验摘要、目标和身份，页面隐藏、超时、切换账号与取消会阻止迟到文件下载；文件名由校验后的 UUID 生成。收到文件后通过浏览器下载，并报告软件动作，不宣称文件已落盘或被人阅读。报告失败提示「不能据此断定文件未保存」。已下载文件无法远程召回。
- 原始数据、授权表、事件表均为 private/RLS，客户端无直读权限；服务身份只能经受控入口。共享原始快照 helper 取消包括 service_role 在内的直接执行资格，只供拥有者受控包装使用；旧审计检索仍先授权并记账后返回。
- 总原始读取、累计解码与最终文件分别限制 64MiB；目标最多50项、RPC/客户端时间有界。当前未执行实际64MiB边界负载，不将静态限制说成容量压测完成。

## 迁移与兼容

新增 `20261113132136_ai_audit_controlled_export.sql`：提取原人员检索/完整链检查为共享私有读取函数，保留原审计读取包装与 `admin-only/1`、`audit-actors/1`；新增导出资格、权限变化审计和导出事件表。新导出响应要求 `audit-export/1`，旧数据库无此入口时失败关闭。

现有审计读取与新导出共用 `auditConsoleDecode.ts`，统一 AES/摘要校验、原始提交解码与分块回答还原。真实 HTTP 全套回归覆盖旧读取路径。人员协议降级测试完成后会恢复最新版受控读取包装，避免测试结束后遗留旧实现。迁移仅在本任务隔离 PostgreSQL17 应用；后续生产需协调应用/迁移和独立资格配置。应用回退应停用导出入口并保留账本，不删除历史导出记录。
