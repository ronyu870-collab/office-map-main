## 本轮修复与验证方法

1. “生成 PNG”没有“导出／下载”字样时，模型只制作网页图表也可能被标作完成。现在同样要求生成图片文件。
2. Excel／CSV／PNG／SVG 没有真实文件时，模型口头成功与虚构链接可能直接出现在回答。现在逐格式核对服务器生成描述与最终归档；错误格式、只调用工具或被后续结果覆盖均不算完成。缺项明确部分完成，回答、执行、成本与历史审计状态一致。
3. 分页按 JavaScript 字符数冒充字节预算，中文页超出 9500 字节；逐行缩页重复序列化，普通翻页每次投影整表。现在按 UTF-8 字节二分求最大前缀、保持连续游标，普通分页只读取所需切片。完整数据、排序、筛选、来源和授权保留。
4. 已有图表的多轮对话转 PDF 时，无关的图表修改规格仍进入模型目录；真实串联请求及预算单元复现生成前被拒绝。纯文件打包复用报告引擎已有图表，减少约 11KiB 无关规格；明确改图仍保留对应工具。原 token／费用预算和全部工具授权不变。
5. 真实 Auth 回归生成的 `agent-model-stream.cjs` 未列入生成物忽略清单，执行回归后再跑全仓 Lint 会扫描打包依赖并失败；只补充该精确生成路径，原 TypeScript、测试及脚本继续检查。

先在原代码复现失败：PNG 错标 completed、四种虚构文件回答、分页序列化 85 次、图表续轮 PDF 预算拒绝。修复回归：`agentOrchestrator.test.ts`、`agentHttp.test.ts`、`artifactFulfillment.test.ts`、`resultWorkset.test.ts`、`modelOperations.test.ts`。新增真实 HTTP 串联脚本 `scripts/verification/ai5-final-hardening-scenarios.mjs`（下称 F）接入原必需 CI。
