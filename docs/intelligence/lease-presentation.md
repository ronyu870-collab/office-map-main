## 依据与范围

上一工作包的实页自检发现：默认回答重复口径和记录总数、面积/占比在质量列后、窄屏四季度图固定640像素而有效点在首屏之外。本包处理这些实际问题，保留完整99项和T01–T60；大结果归档、后台任务、其余数据域、模型治理等不因视觉改进被计为完成。

采用现有系统的连续结果面：结论与范围 → 同源图表/导出控制 → 主要数据 → 可展开完整口径与来源。文字共享左边界，沿用 Arial/PingFang 字体和原正文/字重，不新增字号。颜色沿用工作区 #F5F7FA、结果面 #F8FAFC、正文 #172033、次级文字 #667085、强调 #003E7E 与边框 #D9E0E8。没有新大图、横幅、卡片或动画；对比只来自真实数据。

## 实现与不变量

分类结果默认回答保留候选/入选数、来源区分、面积有效/缺失/无效及分母限制；详细分类规则、名称非可加性和完整计数进入原有“来源、口径与结果版本”。没有删除：完整口径仍在归档结果的 limitations，并随 Excel 查询说明、CSV/SVG来源包交付。旧结果保留原归档文字，不用新查询替换历史。

新的分类 TableSpec 先列分类、来源、面积占比和面积；趋势先列来源、季度和面积。主页分类表把分类与来源在同一固定单元格上下排列，随后立即显示面积占比；趋势表把来源与季度在同一固定单元格排列，随后显示面积；来源点击合并相应两个原单元的 sourceIds，不新增事实或权限。导出继续保留独立分类、来源列，便于筛选。所有质量、名称和分类状态字段仍可横向查阅，未删除。

共享季度折线按实际容器宽度重排坐标，不缩小字体或修改数值。窄屏年份与季度分成两行，四季度可完整显示；较长序列保持最小标签间距、横向滚动和明确起止时间/季度数。所有分组仍共用同一纵轴，未知断线、全未知明确说明，不能当作零。ResizeObserver 随组件卸载清理，不在调整窗口时请求新数据；下载仍使用同一 ChartSpec，允许网页与文件几何布局不同，数值与来源相同。

仅当前可信 admin 本人可用；普通角色、模拟身份、撤权、来源/字段/记录/子市场和独立导出/审计资格继续由既有服务端约束。没有新增数据库迁移、模型调用或真实资料出站，也不以本包替代完整权限验收。

## 验证

同一执行回归先在原实现失败：窄屏容器324像素而图宽640；分类表前四列仍是name/source/categoryState/count。最后一轮320视口又发现趋势表面积仍需横滑，同一组件执行测试复现第二列仍为季度，修正为来源/季度合列后再复验。修改后验证四季度在324/254/800宽度下点位均在范围内，只有一次查询/作图；分类主指标前置，名称非可加性说明仍存在Excel中。单纯静态宽度或源码字符串不作为证明。

真实隔离 Auth/PG17/Next 联跑通过现有 `verify-ai-query-auth.mjs` 和 `verify-lease-analytics-browser.mjs` 进入CI。浏览器覆盖1280/390/320，主占比在初始表视口可见、来源仍同格可读、完整口径展开、四季度第三季有效点不再被横向裁切、40季度仍完整且可键盘滚动、文件回读及恢复。此前未来供应和成交基础浏览器路径同时回归。
