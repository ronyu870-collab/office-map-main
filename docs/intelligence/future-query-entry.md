本地工作区基线：`5863de5235ec1b140245f7480ec7139488c2f4d4`。本包接通既有主页所用的查询、本人恢复、作图、下载和回执接口；尚未推送、合入 main、应用生产迁移或启用真实账号。实际桌面/手机视口路径及本地视觉复核已完成；独立 PR 评审、真机和远端 CI 尚未执行，不代表完整发布验收。

## 身份与资源权限

所有 AI 仍仅允许当前数据库可信角色为 admin 的本人使用。独立资格不替代角色：viewer/editor 即使拥有全部查询、导出和审计资格，也必须拒绝；模拟他人或本人均拒绝。角色、账号状态、会话和独立资格实时核对，不相信自填 metadata 或旧 JWT 内角色。其他管理员的业务结果也不能恢复。

`entryAuthority.ts` 将入口资格和实际业务读取分开。未来查询只加载未来权限；存量查询仍加载存量权限。状态/恢复入口可以接受其中任一资源域的明确资格，但解密归档后必须按原始查询计划重新授权，并复查每条来源。未来权限不会生成存量楼宇范围；存量权限也不会生成未来供应范围。仅在存量资格明确拒绝时才检查未来资格，网络、协议或授权服务失败直接拒绝交付。

主页示例也使用当前权限和资源范围：仅有未来目录时展示未来目录/预计时间精度，不展示质量或存量示例；具有进度、质量资格才增加对应示例。返回前再次检查权限版本。此列表说明支持的语法，不代表库中存在某条数据。

## 支持的查询与数据边界

- `CBD未来供应有哪些` / `CBD未来供应目录`：当前明确未入市的获权未来记录，保留待核实、时间未知、无楼宇关联等状态。
- `CBD未来供应预计时间精度`：季度、半年、年份、未知和无效的完整分类，不伪造季度，也不作为入市时间轴。
- `2026Q3CBD未来供应…` 或 `当前填报季度CBD未来供应…`：填报进度、填报明细、哪些楼还没填、未分配楼宇、人员填报进度、谁还没填、填报数据质量、填报缺项、填报异常。
- `全部获权未来供应…` 只表示当前获权范围；相对季度复用既有北京时间锚定规则，配置填报期与日历季度仍严格区分。

目录问题不得携带一个会被忽略的季度；未来 ID 与存量 building ID 不混用。未支持的附加条件、多意图、联系方式等请求不会被截掉后偷偷执行。无可确认的配置季度时返回澄清“无法确定”，指定季度和无期间目录可以独立查询。

十一种视图复用上一包不可变结果及来源：人物任务数不等于记录数，有提交不等于已审定；历史季度任务仍是当前库中保留的该季任务记录，不宣称历史时点快照。目录、进度、质量分别取获权字段，图表和文件引用同一结果，不重新查询后覆盖旧数值。

## 迁移与调用路径

`20261114034257_ai_future_query_entry.sql` 只扩展 `private.ai_query_result_read` 的本人归档准入为存量或未来资格，保留原本人、会话、成功状态、完整事件链、体积上限、访问审计和服务端专用 ACL。不创建生产资格，不启用控制开关。事实恢复继续由 `recoverOwnResult` 按原计划与 `ai_query_future_sources_allowed` 约束；不能直接把归档准入当事实读取授权。

实际路径：正式提问 → 持久接收审计 → admin/未来资格 → 受控未来快照 → 同源结果 → 持久成功审计 → 最后权限/来源检查 → 响应；恢复、作图和下载都重走当前身份、原计划与来源检查。内部导出另需 `export:internal`。

## 页面阅读、归档原文与持续浏览器验证

未来质量/缺项/异常问题优先呈现核查结论及未知，人员问题优先呈现本人任务，目录/预计时间问题保持对应顺序。共同范围仍给出获权记录数、待核实、分类未知与未关联数量，记录数不冒充不同楼宇数。完整口径保存在原“来源、口径与结果版本”展开区，默认可见内容保留范围排除、时间精度和原件限制；不是删除证据换取简洁。

新结果把 `future-answer/2` 的精确回答段落写进 `parameters.answer`，与分析、表格、来源一起冻结和加密归档。恢复及页面直接使用归档原文，Excel增加“查询说明”页，CSV/SVG manifest也保留同一原文。旧结果没有该字段时保留原有回答生成路径；未知/损坏的新回答协议直接拒绝，不能悄悄用新模板重写它。此项仅覆盖未来供应，其他数据域的完整回答版本治理仍需继续建设。

质量宽表固定首列及表头，表格自身横向/纵向滚动，页面不横向溢出。真实浏览器脚本在旧构建上用同一首列位置断言复现失败，改后通过才算该项完成。原提问示例中的额外存量推荐文字已去除，未来专用账号只看到当前实际获准示例。
