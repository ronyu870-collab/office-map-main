## 评测闭环与证据分层

轻量入口 `npm run ai:eval -- <command>` 支持plan、offline、replay、live、report、resume及案例／失败族筛选。离线先加载网络与进程保护；真实Auth构建需要原生子进程，另用macOS系统沙箱禁止外网。回放按输入／工具schema／fixture／权限／时钟哈希精确匹配；本轮轨迹是脚本模型，不是真实模型轨迹。合成工具点接受原生季度查询、单季度趋势和可解析的旧查数入口等合法等价路径，按实际数值而非固定工具序列判定；未解析的表达不伪造结果。fault injection可识别错季度、错单位、空值补零、附件遗漏、limited冒充完成、错误版本及禁止泄漏标记。

预算SQLite复用原供应商适配边界：任务总额不可变、BEGIN IMMEDIATE原子预留、workflow与请求只计一次、验收／缓冲独立保留、跨重启与两个Node进程共享额度。超时或未知usage保留预留；只有证明未发送可释放。异常usage／未定价模型停发；sent事务再次检查halt，修复“停发前已预留仍可发送”竞态。它只限制本任务统一入口的调用，不覆盖共享key的其他消费；未建设生产计费平台。
