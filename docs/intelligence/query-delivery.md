# 客户端交付报告：本地检查点

适用基线：5469854 之后。仅本地/隔离实现，未生产启用；原99项及T01–T60范围保持。该包推进A03/A07/A10与AUTH的交付边界，不等于完整审计台、可靠任务或全部回答回执完成。

## 语义与边界

| 记录 | 可以证明的范围 | 不可以证明 |
| --- | --- | --- |
| response_prepared | 服务器已持久保存该响应的准备记录、原结果引用和字节摘要 | HTTP已到达客户端 |
| client_received | 当前身份客户端报告已收到并校验完整响应字节 | 用户看见或读懂 |
| client_dom_committed | 当前身份客户端报告可见文档中已挂载指定视图，包含表格页/来源ID或图表布局 | 整页均在视口中、截图与每个像素正确、用户已读 |
| browser_download_dispatched | 客户端报告文件已交给浏览器下载操作 | 磁盘保存完成、文件打开、对外发送 |

后两种都是**客户端报告**，不能因带有服务器签名就变成人类行为证明。签名只绑定服务器准备的响应与身份，恶意客户端仍能谎报自己的DOM；审计展示必须继续标明证据类型。没有回执时保持未确认，不推断未发送或未阅读；回执失败不会重新运行业务查询。原结果流不会因回执改变，避免正常回执与恢复的流头一致性检查相互干扰。

## 实现路径

- 查询成功、澄清、恢复/状态、图表、下载的准备记录包含 `query-delivery/1` 挑战：deliveryId、真实/有效账号、当前session、原交付requestId、resultId、响应SHA-256、响应类型/项数、签发与24小时到期时间。HMAC使用现有服务端审计digest密钥且单独域分隔；加密密钥不复用。最终权限/来源复查通过后才把挑战放入响应头，失败分支不返回挑战。
- POST `/api/intelligence/query/receipt`：有界接收/入口留痕→真实身份（含模拟交集）→加密记录技术回执提交→同源、schema、签名、当前会话/资格、摘要、阶段与页范围验证→追加客户端报告→终态→只返回确认，不返回旧业务内容。无新数据库表、授权或生产迁移。
- 请求中的令牌不明文复制到审计，保留脱敏占位符、令牌摘要和结构化报告；异常技术正文只记有界入口摘要，不允许通过该路径伪造正常用户问题。输入框的未提交草稿不进入此流程。
- 客户端在JSON/文件字节完成、摘要与身份检查和数据结构验证后发接收回执。DOM报告在React提交后、可见文档的两个动画帧之后发出；隐藏文档、卸载和身份变化抑制待发报告。表格每页25条、来源每组最多10条；柱图分页和散点全图分别标注。收起结果会卸载报告hook。
- 回执只在内存持有，最多重试两次、总超时10秒；不把令牌/问题/结果写浏览器持久存储或通用日志。旧兼容响应没有挑战时不会伪造回执。重试是独立接收与审计记录，以deliveryId、phase及viewDigest归并，不能用日志行数当独立交付人数；当前尚无管理统计UI。
- 撤权/注销/跨会话拒绝有效回执登记，并保留拒绝事件；不让回执变成另一种登录或旧数据读取入口。迟到回执可能被拒绝，原交付仍保留未确认。签名当前只支持现用keyId，轮换后旧挑战恢复需要后续多密钥生命周期能力。

## 实际验证

真实GoTrue、PostgreSQL17.6、PostgREST与Next生产构建：41组场景通过，增加接收/DOM/下载分流、原流不变、重复关联、摘要/签名篡改、跨人/会话/Origin、模拟伪造、非法页、审计故障、撤权和注销。已有全部查询/恢复/图表/导出场景继续运行。回归在现有CI脚本内，无另建未运行的测试入口。

浏览器合成账号实际查询170、展开/关闭6条来源、呈现柱图、点击Excel并观察“尚未确认本机保存完成”：数据库11个成功流中8个是客户端回执流。浏览器专项只核对对应合成账号的事件种类/终态；各阶段加密正文解密比对在真实HTTP用例中执行，二者证据不混淆。截图与原始记录见 `../verification/query-delivery/`。

单元/组件覆盖挑战失效和身份绑定、阶段/页边界、坏字节不回执、回执重试不重新查询、账号变化不发送、输入新草稿不改变已呈现报告、隐藏/卸载不发DOM报告。初次全量发现旧恢复竞态测试以 `{value:170}` 代替实际QueryResult；改用真实构造器后该3项竞态回归通过，未改变原409/403断言。另一次完整验证在测试阶段主动停止，以避免本地生产构建覆盖正在进行的浏览器预览产物；最终结果另记evidence。

## 明确剩余

- 当前没有流式分片/中断、全部错误与拒绝文案的交付挑战、离线持久回执队列或服务端崩溃outbox补记；尚不能声明A03/A07全部完成。
- 当前视图描述不是逐像素/完整DOM文本存档；未展开追溯详情、滚动位置、所有交互变化及客户端报告内容真实性不能据此推断。完整审计台需从原不可变快照、原图spec、渲染版本及报告范围重建，并注明这些限制。
- 回执服务发生故障仍可能留有未结流；必须由后续独立接收/终态对账识别，不能只统计成功响应。
- 无真实手机、浏览器真实IME、手机文件保存或完整客户端离线/崩溃验收；无本包远端精确head CI、独立合并视觉评审、生产发布或新模型调用。布局与样式未改变，实际页截图用于证明交互状态，不宣称新设计已获认可。
- 全部图种、PNG/PDF、审计管理台、保留/检查点/密钥轮换、可靠任务、更多业务源、F1–F7、模型/预算治理与H06生产获权入口回验仍继续按完整计划推进。
