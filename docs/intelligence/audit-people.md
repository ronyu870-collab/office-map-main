# 审计人员识别与筛选（本地工作包）

本包继续A04/A05与AUTH/R06/R14/R17：将原来只显示账号UUID的审计列表，接上既有人员目录的中英文姓名；支持姓名包含检索、完整UUID精确过滤，以及从一条记录直接「仅看此账号」。不改变仅admin本人且有独立审计资格的边界，不新增真实账号授权或生产变更。

## 身份含义

- 以提交记录原始 `actor_id` 为事实锚点，通过当前 `auth.users` 与 `public.user_roles` 读取 `chinese_name` / `full_name`。两者相同只显示一次；不同则并列。不会读取邮箱/电话，也不从JWT metadata、问题正文、姓名字符串或授权说明推定实际人员。
- 当前姓名只是当前目录的显示标签，不是提交时姓名快照、历史实名核验证明或权限依据。响应携带 `directoryAsOf` 与 `current_directory_not_historical`，页面说明检索时点；原始账号、提交时间、事件和问答不重写。
- 同名账号分别保留，列表显示短账号辅助辨认，详情保留完整UUID；精确过滤和「仅看此账号」始终使用完整UUID，不依赖姓名或短号唯一性。
- 目录空白、缺失或关联Auth账号已删除时姓名返回null，显示「姓名未知或目录未匹配」并保留UUID，不冒称某种具体缺失原因。目录读取发生错误则整个读取不可用，不伪装成账号不存在。
- 超长名称响应最多160个Unicode字符并提供显式缩短标志；搜索仍匹配未缩短的完整姓名，账号与记录不丢弃。页面按文本渲染，不执行名字中的HTML。

## 检索与访问留痕

`POST /api/intelligence/audit` 的list增加可选 `actorSearch`（去首尾空白、1–120字符）。按当前中英文姓名组合做不区分大小写的字面包含匹配，`%`、`_`及SQL片段均是普通文本。不是姓名同义词识别或模糊拼音推断。可与原文关键词、时间、入口、状态、完整 `actorId` 组合；同时提供姓名和UUID时取交集。

姓名过滤在数据库候选分页之前执行，保持最多50候选、UUID打破同时间并列的完整翻页；签名游标绑定姓名条件，翻页不得替换。当前目录和关联状态会变化，分页不是冻结的人员目录快照；改名后应重新检索或使用不可变账号编号，不声称按旧姓名也能检索所有历史曾用名。

姓名读取发生在已有admin/会话/独立审计资格检查之后，同一事务追加读取范围。搜索条件原文继续加密留存，返回前复查并写入响应摘要/准备凭据。无权者不能获得姓名、候选数、摘要或问答；没有新增公开人员目录接口，也未给客户端增加原始表权限。

迁移 `20261113130012_ai_audit_actor_directory.sql` 仅替换已有私有受控读取函数，保留既有invoker公开包装、definer私有实现、空search_path、执行授权、审计写入和准备返回链。应用要求 `audit-actors/1` 响应标识；旧库会忽略新姓名参数，故新应用遇旧库必须拒绝返回，不能将未过滤的全量结果冒充姓名匹配。后续协调发布需应用与迁移匹配；当前仍只在隔离环境执行。

## 页面与验证

复用现有审计页的字号、字体、颜色和输入系统。在「按人员筛选」展开区并置姓名与完整UUID，相关说明成组；结果姓名和账号同行，详情明确当前目录时点。没有新增看板、装饰图片或独立字号。新增账号过滤按钮保留44px可触控高度。

实际执行证据见 [audit-people-evidence.json](audit-people-evidence.json)：

- PostgreSQL17专项7组：旧函数缺少协议且忽略姓名筛选反例；中英文、同名、ID交集；字面匹配/输入上限；改名/目录缺失/删除；超长名称；54条完整分页；admin/资格/直连RPC/访问账本失败保护。
- 真实GoTrue/PostgREST/PostgreSQL17/Next HTTP58组：包含新增4组人员检索完整路径，验证加密条件、同名账号、名字变化、未知姓名、游标条件绑定，以及实际替换回旧数据库函数后新应用503拒绝、恢复新函数后200。原54组权限、审计、查询、同源导出及撤权检查保持。
- 新增组件回归验证人员输入的焦点/光标/中文组词、在途/空结果/失败持续编辑、翻页使用已提交姓名、同名不同ID精确筛选、恶意名称按文本、未知与缩短标识。加入搜索焦点门禁与现有Vitest；数据库专项和HTTP回归接入现有CI。
- 实际合成浏览器流程：admin主页提问「CBD有哪些楼」→审计页姓名+原文联合检索→仅看此账号→展开完整原文→关联回答。数据库回读1次intake/2次list/1次stream和4次prepare均allowed。390px窄屏可操作，页面超过一分钟自动收起已观察；最终窄屏截图为超时收起状态，不冒称该截图展示了详情。截图位于 `docs/verification/audit-people/`。

浏览器为macOS Codex内置浏览器，引擎版本未独立确认；当前不是iOS/Android真机、独立视觉评审或精确远端CI证据。自检姓名/账号/问题成组，手机输入、说明可折行，无页面横向溢出；目录时点和技术编号仍有必要解释，完整审计管理体验尚待后续优化。
