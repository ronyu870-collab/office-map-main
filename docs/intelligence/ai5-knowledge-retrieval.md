# AI 5.0 阶段 09：文档证据检索与公开研究

## 执行与来源

新增三个独立结构化 Agent 工具：`list_knowledge_documents`、`search_internal_documents`、`search_public_building_information`。先由获权楼宇目录取得真实楼座 ID，再列出当前文档 ID，按明确文档和短关键词检索。多文档按原文片段并列对照；表格的来源分类、资料日期、真实位置和限制均由服务器构造。模型不得编写原文、页码、正式数值或未经核验的综合判断。

复用 `building_sales_materials`、私有 `building-sales-materials` bucket、原件 SHA-256、原有地图楼宇范围及版本，不新建文件系统或公共地址。仅索引明确选择且获权的在线原件；本地归档／未收录的报告、无唯一楼宇关联的提取库、OSS 任意目录和 Admin-only Stacking 原件不自动开放。已有关联、已发布的研究报告可沿相同现有资料入口检索。

原生文字 PDF（真实页码）、DOCX（段落，不推断版面页码）、XLSX（工作表／行）、PPTX（幻灯片号）使用已有 pdfjs、JSZip、SheetJS 在服务器本地解析。扫描件未做 OCR；图片、旧二进制格式、宏和嵌入对象不执行。单件24MiB、500页、2000片段、400万字符和ZIP展开上限，超限整项明确失败，不发布部分索引。每片段至多1120字符，同一位置重叠120字符，不跨原页拼接。表格公式识别后排除，不读取其缓存值冒充静态内容。

## 索引与权限

迁移 `20261121154026_ai_knowledge_retrieval.sql` 在 private schema 建立文档授权、索引元数据、片段与公开名称白名单。中文双字连续词及拉丁词使用GIN数组索引召回，字面子串复核；不引入另一数据库、向量服务或第三方文档解析。关键词为AND；默认最多12片段，可到20，保留总命中数并明确展示上限。没有命中不等于全文无此信息。暂不提供向量语义检索或外部模型自动撰写私有报告综合判断。

沿用当前 **真实管理员本人有效 Auth 会话 + 全局 AI 开关 + ai_query_grants**，再与默认关闭、具有效期的 `private.ai_knowledge_grants.document_ids`、楼宇／子市场范围和原资料 ready/confirmed 状态取交集；不扩大 viewer/editor、模拟身份或默认RLS。无用户授权不读原件。匿名／authenticated不能访问索引或调用包装RPC，service_role也不能直接修改新授权。私有definer固定空search_path，公开wrapper是invoker；授权维护复用策略变更审计。

索引绑定原件哈希、数据库完整记录版本、文档／楼宇ID、解析版本、位置和indexed_at。读取校验当前授权，建索引采用来源版本CAS并原子替换；源记录更新即时清除索引，删除级联清除。每轮工具、模型调用、响应、续问、历史恢复和原件下载再次验证授权revision与所有文档版本。所有依赖（包括混合正式查询）写入原加密结果审计；旧缓存、旧引用、旧会话或别人的resultId不能恢复敏感内容。

内部与外部来源的标题和正文均不发送DeepSeek；模型仅收到真实文档ID、格式、结果ID和数量，用户在既有正式结果表中阅读证据。内部资料含凭据特征时拒绝建立索引，不回显凭据。正文／网页中的系统指令仅是待核查原文，不能变成执行授权。该隐私边界意味着内部资料比较为可引用的原段落对照，不冒称模型读完全文或已得出研究结论。

原件操作使用 `POST /api/intelligence/query/document`，只接受本人审计requestId/resultId/sourceId，不接受路径或URL；复用恢复、同源、当前Auth、审计准备和签名交付回执，校验原件大小与哈希，通过HTTP以附件返回。浏览器只报告“发起下载”，不声明磁盘保存成功。原文检索资格不自动成为Excel/CSV/PDF导出资格；本阶段拒绝把文档原文混入通用数据导出，原有结构化导出不变。

## 公开搜索配置

选用 [Brave Web Search API](https://api-dashboard.search.brave.com/api-reference/web/search/get)，维护者须具有正式订阅／组织批准，在服务器配置：

```
AI_PUBLIC_SEARCH_PROVIDER=brave
BRAVE_SEARCH_API_KEY=<仅服务器密钥>
```

还需要独立 `allow_public_search` 和 `private.ai_public_research_subjects` 中经过批准的公开楼名／城市；本迁移不填入生产授权或公开名称。工具只接受buildingId及completion_year/parking/hvac/green_certification，查询由服务器固定组装，不接受用户／模型任意查询、URL、合同或客户名称。固定HTTPS提供商，无端点覆盖，无重定向；最多5条结果，有响应大小和超时限制。只读供应商摘要，不抓取任意网页或内网地址；过滤非公网URL和凭据特征，不将摘要当作已核验原网页。

结果明确标为external_public，保留URL、检索时间和供应商可解析的资料时间（可能是发布或修改时间，未知不猜）；内部原件页码不用于外部网页。未配置时明确“公开搜索未启用”，无外部请求；供应商失败时明确不可用。真实生产供应商调用需正式服务配置，本轮使用脱敏供应商契约夹具，不声称生产已经联网。

## 持续验证与启用边界

本轮豁免人工浏览器、截图及独立视觉审查，保留工程／自动功能回归。必需CI执行真实PG17索引／权限／CAS／失效／审计、真实GoTrue与Storage及Next生产构建HTTP、PDF字节及页数回读、中文DOCX/XLSX/PPTX文件解析、恶意公式／注入／凭据隔离、撤权和跨用户恢复／下载拒绝。公开搜索用固定契约夹具验证出站查询和返回来源，不请求生产私有原件或真实客户资料。

本次仅提交迁移与应用代码；未对生产应用迁移、建立索引、创建授权、批量读文件或配置第三方密钥。生产启用需单独执行受控迁移、批准文档范围／公开名称和服务配置。私有文档索引维护没有模型可调用的任意写入入口，按需解析仅写派生索引，不写业务原件。
