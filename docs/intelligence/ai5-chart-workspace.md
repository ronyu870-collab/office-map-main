# Colliers AI 5.0 阶段 05：专业图表工作区

## 执行和来源契约

`create_chart`、`modify_chart`、`export_chart` 是独立注册的 Agent 工具；旧 `prepare_chart` 和结果操作菜单继续可用。模型仅提交严格校验的图表规格与获权结果引用，不接受模型数值、SQL、路径、SVG、来源或公共文件地址。新增的租金／空置率联合样本和分布查询工具复用原 QueryPlan、准入、完整快照及确定性统计引擎。

`chart.kind=plot` 支持柱状、横向条形、折线和散点，绑定原表 `x`、同单位 `y[]`、分类 `groupBy`，可指定原结果内季度、排序、标题、图例和轴范围／刻度／单位。横向条形仍用 X 绑定分类、Y 绑定数值，只改变绘制方向。旧时间序列、多系列趋势、热力图、直方图、箱线图继续使用既有统计定义和来源绑定，不另建分箱、分位数或房地产指标算法。

每个图元绑定原单元格或正式分析路径及来源 ID。图表保留 resultId、tableId、完整规格和精确值；导出 manifest 继续包含结果 digest、期间、计算口径、来源、快照和数据版本。改图仅改变投影，不修改正式 table、analysis、sources、dataVersion、snapshotId 或 createdAt。

跨轮改图从本人的加密回答归档恢复同一正式结果：会话、身份、权限版本、当前字段／范围和全部来源必须重新通过校验，才可加入本轮工作集；每次工具执行及最终回答前继续复核。缺少字段、季度或分类时须发起新的合法查询，不从模型上下文补点。普通查询和表格导出的历史条件继承规则保持不变。

## 坐标与显示

- `ratio` 的正式值保持 0–1，绘图投影乘 100，默认轴为 0–100%；17.5% 不自动铺满图高。`percent` 和 `percentage_point` 不再乘 100，0.05 不变为 5；百分点标记 pp。
- 数值轴支持有限 min/max 和 2–12 个刻度；单位必须与正式列一致。拒绝反向范围、裁掉数据、移除柱图零基线、越界比例和非有限数值。分类轴不接受数值范围。
- 负数位于零线正确一侧；真实零保留图元，未知单元格不画成零。季度按时间排序；缺失或跳过季度断线，禁止连接补值。折线重复时间点、重复分类点会明确拒绝，避免覆盖或暗中聚合。
- 通用投影最多 6 个同单位系列，共用坐标轴。不同单位组合、含糊的跨系列 Y 排序被拒绝；本阶段不提供双纵轴或组合图，防止租金与比例共享错误轴。时间／分布的排序由正式时间或统计定义决定。
- 通用图形支持自由字段和完整坐标配置。旧分布图继续使用正式分箱／分位数，明确拒绝自定义轴配置；不声称能够通过显示配置改变统计边界。
- 大样本分类标签按间隔显示并带完整提示；长标签用省略号，完整名称、数值和来源保留于逐点表及 manifest。长标题换行。图形滚动展示完整画布，数值表每页 25 项不影响绘图或导出。

通用柱图最多 1,000 点，折线／散点最多 5,000 点；实际画布尺寸还有独立上限。超限返回明确错误，不截断到模型预览或界面第一页。旧图种继续执行各自既有安全上限。

## 文件和交付状态

`png_zip` 包含真实 `chart.png` 和 `manifest.json`；`svg_zip` 保留 `chart.svg` 与来源 manifest。两种文件与预览使用同一固定 SVG 几何，PNG 由服务端 `@resvg/resvg-js` 原生渲染器以 2 倍尺寸生成。随服务端打包 SIL OFL 1.1 的 Noto Sans SC 字体，生成时不访问外部字体、文件或 URL。Next 路由文件追踪覆盖 Agent、流式 Agent 和 artifact 路由；字体不进入客户端首屏包。

PNG 单边最大 16,000 像素、最多 4,000 万像素，SVG 输入最多 16 MiB，最终包沿用 32 MiB 上限。manifest 记录真实 PNG 尺寸、字体、缩放及 PNG SHA-256；可信交付协议继续核对整个文件的类型、大小、digest 和 SHA-256。

服务端成功只表示 `server_generated`。回答展示图表和真实下载按钮；用户点击后重新通过归档恢复、独立 `export:internal` 授权及来源复核，浏览器触发下载才记录 `browser_download_dispatched`，不声称文件已实际保存。不自动上传公开存储，不扩大任何用户的导出资格。撤权、跨用户访问、来源撤回均拒绝下载，既有审计、恢复与结果菜单继续适用。

## 验证与边界

- `chartWorkspace.test.ts` 用确定数据验证租金 Top 10、四季度趋势、CBD／金融街空置率、多系列、租金 X／空置率 Y 的实际几何、17.5% 和 pp、负数／零／缺失、坐标／排序的数据不变性、恶意标签、超限，以及实际 PNG 签名、解压像素、中文不同字形、尺寸、确定性 SHA 和 SVG／PNG manifest 一致性。
- 分布、交叉热力图旧回归增加 PNG 文件回读；Agent 和加密历史测试覆盖真实服务器生成状态、模型伪造保存话术、来源复核、字段拒绝和跨轮快照不变；组件回归覆盖回答旁展示、图元点选来源、坐标编辑焦点、下载拒绝和重试。
- `verify-ai-query-auth.mjs` 接入 `ai5-chart-scenarios.mjs`，在 CI 的隔离 PostgreSQL／Supabase 上使用真实 Auth、查询、归档、审计和 production Next artifact HTTP，逐一下载并回读 PNG／SVG，验证跨用户、撤权和来源撤回；同时保留阶段 04 的完整文件回归。仅模型工具规划使用可重复脚本 fixture，不将其称为线上 DeepSeek 理解准确率证明。
