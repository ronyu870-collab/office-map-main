# Colliers AI 5.0 内部 PDF 研究报告

## 执行协议

`generate_pdf_report` 接收本轮授权工作集中的 1–8 个 `resultIds`、内部用途及可选既有结构化图表规格。可组合租金、空置率、面积等不同表结构的正式结果；每个部分保留完整表格、来源、期间、统计口径与版本。模型不能传正文、结论、KPI、业务数值、SQL、HTML、文件路径或外部资源。

用户说“帮我把 CBD 最近四季度的写字楼市场情况生成一份 PDF 研究报告”时，Agent 可分别调用 `query_report_market` 取得指标，再组合生成。此报告专用查询默认服务器接收时最近四个**已结束的北京时间日历季度**，不是最近有数据季度，日历结束也不代表数据审定；缺期保留未知。明确指定起止或包含本季度时使用原 `analyze_market_trends`，尊重用户期间。一般相对期间解析规则不变。

报告只消费确定性正式表与原 `researchAnalysis`。KPI 来自原表，环比、同比与百分点来自已保存的确定性研究补充，不另建计算引擎、不跨结果重算指标或推断市场原因。原结果的图表规格优先复用，其他使用现有首选图种；较长楼宇列表默认仅列完整表，可显式请求合规图表。PDF 请求还会沿服务端加密父轮引用，恢复当前对话最近 8 轮中已经完成的正式查询结果；逐个通过原 owner／对话／权限与来源恢复检查后，才导入本轮工作集供选择组合。原报告的部分可复用，原表格导出成品不冒充查询。最多 8 个结果，超限拒绝；历史超过 8 轮会明确告知模型边界，更早或未导入的 ID 必须重新合法查询。模型不能指定任意其他对话的历史请求来导入。

## 文件与排版

服务器使用固定 `pdf-lib 1.17.1` PDF 图元和 `@pdf-lib/fontkit 1.1.1`，直接输出真正的 `application/pdf`，无 HTML 渲染器或浏览器依赖。嵌入服务端静态 Noto Sans SC Regular TrueType 子集及 ToUnicode；许可证、原始来源、构建方法和哈希见 [字体记录](../../private/chart-fonts/README.md)。运行时不联网取字体或资源。

横向 A4，复用平台蓝色、浅灰背景、统一阅读边界和正文／标题两档字号。包括研究范围、核心结论、关键指标、研究分析、图表、完整明细、期间、来源与限制、生成时间、结果版本、页眉页脚和页码。长表重复表头，长单元格跨页，多字段按字段组重复身份列；不受网页分页或模型摘要预览行数影响。字体缺字或版面容量超限明确失败。

图表复用 `buildResultChart`、固定 SVG 几何与既有 PNG 渲染器；PDF 的可见图注将技术追溯移入来源附件，默认网页／SVG／PNG 导出不变。长图按可读比例分页并重叠，不静默裁图。精确单元格、研究补充、全部来源、图表规格、结果摘要哈希及完整版本保留在 PDF 内惰性的 `manifest.json` 附件；正文按业务来源分组，不堆积审计 ID 或技术错误。

上限：8 个研究部分、合计 4,000 行、归档 JSON 15 MiB、排版文字 800,000 字符、200 页，成品沿用 32 MiB 上限。PDF 通用图表最多 100 点、渲染宽度不超过 2,300 像素，其他图种仍执行原安全限制；超限拒绝，建议收窄范围或先导出完整表，不截断数据。

## 权限与交付

现有 admin 本人使用范围、独立查询和 `export:internal` 资格全部保留。生成前、生成后、正式响应前和下载时重新校验身份、权限版本、每个原查询计划及来源 ACL。组合结果通过原 `exportPlans` 多计划恢复协议鉴权，不建立公共文件地址或新的权限旁路。跨用户、撤权、来源撤回均拒绝；文件仍与加密审计、身份、请求、结果和 SHA-256 绑定。

仅生成带“内部研究资料”标记的 PDF。`purpose=client` 明确拒绝，不能从内部生成资格推导对客发布权；本阶段不实现外部发布入口。

Agent 工具真正生成二进制成功才记录 `server_generated`，最终话术由服务器决定，覆盖模型的伪造保存或下载 URL。回答旁下载按钮在表格折叠后仍可用；点击重新恢复鉴权、检查 MIME／扩展名／PDF 签名／结果绑定／SHA-256 后发起浏览器下载，才记录 `browser_download_dispatched`。不自动下载，也不声称文件已实际保存。原 Excel、CSV、SVG、PNG、结果菜单及恢复保留。
