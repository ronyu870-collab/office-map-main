# Colliers AI 5.0 阶段 04：自然语言表格导出

## 执行与保护

`list_buildings` 复用严格 QueryPlan、现有授权与完整快照读取，支持目录及最多六个数值字段。季度租金、面积须明确期间；既有最新有效季度解析继续可用，不猜测季度。

独立注册的 `export_table` 只接受本轮获权工作集 `resultIds`、现有列 key、排序、AND 组合筛选、可选 Top N、`xlsx|csv_zip` 和 `singleSheet`。服务端重新验证参数与独立 `export:internal` 资格；不能提交 SQL、数值、来源、角色、路径或公共 URL。Top N 延续末位并列，未知不当成零。未调用导出工具的文件请求不能标为完整成功。

导出读取完整 QueryResult；模型前六／八行及界面每页 25 行不限制文件。保留原工作集上限（最多八结果、合计 50000 行），派生导出不再次占用相同工作集行预算。归档限制 15 MiB、文件限制 32 MiB、XLSX 行列与单元格限制明确失败，不静默截断。不能合并列结构不同的结果；相同列结构按行追加并增加原结果编号和期间，保留每项计划、快照、范围、分析及来源，不重算跨结果均值。源 ID 冲突明确拒绝。

XLSX 使用原 `exports.ts`／SheetJS 生成真实文件，业务数字为数值、中文为文本，保留单位、原始期间、来源日期、精确分数、筛选及列宽。默认数据、精确值与来源、来源、口径与快照工作表；明确单工作表时将来源与口径按章节接在数据下方，筛选区域只覆盖业务数据，所选业务列不额外加 entity_id。

CSV 继续交付 UTF-8 BOM 的 `data.csv` 与 `manifest.json` ZIP；保留既有状态、精确值、来源绑定与公式注入保护。合法负数业务值保留数值表达；文本分数、来源和名称按原安全规则处理。

## 回答、恢复与交付

工具实际调用 `buildResultArtifact` 生成字节后才返回 `server_generated`。字节不发送给模型，也不写公共存储。最后一次成功导出的完整派生结果通过现有加密审计归档，回答旁提供下载操作，大表折叠时也可用。一次回答交付最后一个成功导出，多个结果可合成一个文件。

点击下载沿用 `trustedQueryClient.download` → 原 artifact HTTP → 本人加密归档恢复 → 当前独立导出资格、**所有原计划**、来源 ACL 与流版本再检查 → 签名交付及 SHA-256 文件校验。文件按归档确定性重建；不新增公开链接。原结果操作菜单、图表、CSV／SVG、恢复与交付回执保留。

历史只继承本人、同会话／有效恢复凭据、同权限修订版本的加密查询及导出条件；跨轮“刚才结果”重新执行计划获取新 resultIds，不直接复用旧工作集。界面明确区分服务器已生成、浏览器已发起下载、尚未确认实际保存；不自动下载，不声称本机保存成功。
