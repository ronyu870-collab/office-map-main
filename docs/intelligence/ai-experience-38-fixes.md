## 2. 实际接口与保护

### 历史时间线

`POST /api/intelligence/query/history` 的 `open` 动作增加可选 `includeTimeline`。原 `selected`、`turns` 和会话接口继续兼容。分页最多恢复5轮，使用有归属与有效期保护的游标，不一次下载全部历史。选择旧请求时截止到该请求，向前翻页保持连续。

每条回复通过既有本人归属、来源／继承计划授权和快照链头重核。可追问的每轮获得绑定自身请求的恢复令牌；加载早期记录不改变当前选中的追问父节点。任一记录撤权或快照变化会阻止该批次交付。每轮结果的展示回执分别绑定，不能把当前结果的回执用于其他轮次。

草稿仅在当前会话内存中保留。打开历史不抹去正在编写的下一条问题；身份／权限变化继续清空原工作空间。新对话、关闭、返回主页和搜索变化取消在途历史打开，防止延迟响应覆盖新上下文。

### 普通回答复制

新增 `POST /api/intelligence/query/copy`，只接受原请求和会话引用。支持原生 Agent 回答与旧版助手介绍。服务端继续检查本人、当前资格、独立内部导出授权、来源范围和原始加密审计；交付前再次检查权限与审计链头。客户端不提交替换文字，拿到结果后与当前显示的原始 Markdown 逐字比较再复制。

正式数值、统计口径、原数据导出和图表来源继续使用现有确定性实现。此次没有数据库迁移、RLS、模型配置或生产业务数据修改。

### 工作空间与阅读

主页维持综合业务入口，紧凑、专注和全屏共用一个输入与会话实例。历史／研究面板保留原组件，窄屏通过抽屉呈现；窗口旋转与缩放不会重建搜索框。正在主输入框编辑时收起会覆盖它的侧栏；侧栏从抽屉变回桌面栏时保留搜索焦点和 IME。

Markdown 只负责呈现返回原文。原始 HTML 不执行；不安全 URL 不可点击；模型提供的图片不会自动发起外部请求。代码和宽表格在各自容器横滚，不撑破会话宽度。原文复制保留 Markdown 结构。
