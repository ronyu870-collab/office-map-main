## 最终范围

入口仍是租赁成交最上方操作栏「租约到期」。桌面时间轴位于右侧，宽度为内容区约40%、最大460px；左侧依次为企业与原成交楼宇、成交时间／租期／面积、行业／子市场。手机完整展示相同资料和明确的「预计到期」日期，保留分页、返回、失败重试和撤权清空。

用户确认「合同」指原时间与租期，不是附件。系统记录的是成交时间，季度不能编造成具体签约日；推定来源显示「成交期间（推定）」。行业和子市场直接来自原记录，缺失显示「未记录」；子市场是当次成交楼宇的sub_market，不是搬迁前地址。用户随后明确本轮完全忽略联网补充：最终代码无新增模型调用、行业推断、缓存、凭据复制或额外操作。

新增迁移 `20261113054057_lease_expiry_context.sql` 只创建 private/public 两个只读函数。沿用原管理员验证及事务角色锁，公开入口为security invoker、仅service_role可执行；匿名、普通角色、封禁／删除和撤权均拒绝。原表、RLS、开关、估算公式、计数／分页、旧备注快照指纹与旧API保持不变。
