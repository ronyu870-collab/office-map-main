# 主页业务入口顺序与管理员标注

基线：main `3002c9da1e4b52182b0437a6ca9da32d2b6b619a`。从左到右、从上到下依次为租赁成交填报、季度数据填报、研究资料库、北京写字楼季度研究、企业选址洞察报告。手机沿用同一顺序。独立的地图主入口保持原位。

两个报告入口仅向未处于身份模拟状态的管理员展示。灰色标注与各自标题左对齐，辅助文字使用系统次要文字色及 12px／400。读屏将标注作为链接描述，链接名称仍是报告标题。既有公开报告分享地址和季度研究服务端鉴权均未改动。

## 执行验证

- 在旧版运行更新后的主页行为测试，四个场景按预期失败，复现原顺序、报告标注及角色展示问题。同一组测试在修改后通过，覆盖管理员、普通用户、原有报告白名单和身份模拟，接入现有 Vitest 与 Verify。
- 现有生产构建浏览器回归补查导航顺序、角色和标注；同时保留公告、交流、菜单焦点、公开报告导航往返和窄屏溢出检查。没有数据库写入、迁移或搜索／加载行为改动。
- 所有截图使用相同合成夹具，不含生产用户资料。手机为模拟视口；未执行 iOS 或 Android 真机测试。

本地 `npm run verify` 完成，203 个测试文件、1,305 项通过，生产构建成功。Chromium 145.0.7632.6 的 [3 组基线](before-browser.json)及 [10 组最终场景](after-browser.json)全部通过。匿名请求公开企业选址报告返回 HTTP 200。

## 视觉验收：通过

评审者：Codex。同角色、同夹具、同视口对照实际生产构建的整页。桌面按行读取五项，手机按列读取五项；两个标注紧接标题并共享左边界，颜色和字重低于标题，与图标、箭头及分隔线的节奏一致。320px 无文字裁切；640px 长标题自然换行，标注仍在其下；普通用户没有多余标注或空白占位。地图及下方团队动态的分组保持原有布局。
