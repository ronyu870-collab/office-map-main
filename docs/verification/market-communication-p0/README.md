生产迁移：\`supabase/migrations/20261113195000_market_communication_p0.sql\`。
原有普通客户端继续可写自己的**纯文本**三列，不允许凭公开客户端写入伪造的富文本/广播字段。结构化发布通过后端经服务端验证会话后调用只授予 \`service_role\` 的 PostgreSQL RPC。RPC 再校验角色、真实用户/停用状态、每个提及的 UUID、回复目标及广播频率；消息、通知、审计为一个事务，任一环节失败全部回滚。
