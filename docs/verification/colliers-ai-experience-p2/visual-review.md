## 独立代码与键盘审查

已检查 `HomeQuery.tsx`、`HomeQueryExperience.tsx`、`HomeWorkspace` / workspace 样式、研究结果与侧栏差异，以及 `useQueryWorkspace.ts` 后续修正。没有发现为视觉改动重写查询执行器、授权或审计路径的变更。建议入口只从当前获权的 `access.examples` 选择已有问题，点击填入原完整问题，不凭标签扩大查询范围或自动发送。

欢迎/对话/展开共用现有 React 树、输入节点与 session key；视觉切换没有新增 portal 或用条件卸载 textarea。原 IME、`defaultPrevented`、请求幂等与可见回执保护仍在。以下是本审查发现并经实现方修正的具体边界：

| 风险 | 已复核的处理 | 仍需区分的证据 |
| --- | --- | --- |
| 短视口隐藏 footer 后，其 summary 仍进入 Tab 集合 | 逐级检查 CSS 隐藏祖先；`:is(...)` 保持控件文档顺序 | 旧失败/新通过日志和矩阵短视口正反 Tab 已取得；真机键盘未测 |
| 轻量建议可见短标签未包含在可访问名称中 | aria-label 同时包含可见标签及完整问题 | 代码已复核 |
| 展开动画仍硬编码旧圆角 | 从 `--cd-radius-ai-surface` 读取紧凑区域圆角 | 代码已复核；最终 head 动画/状态 CI 待核对 |
| Tab 虽聚焦长结果控件但控件仍在内部滚动区之外 | `.focus()` 允许浏览器将目标滚入内部可见区域 | 设计矩阵已检查焦点与 scrollport 相交及背景锁定；最终 head CI 待核对 |
| 工具栏命中区缩至 36px | 恢复 44px，与原 P1 几何保护一致 | 代码及已有测试要求已复核 |
| 程序聚焦 `tabIndex=-1` 来源/摘要后，下一次 Tab 跳回工具栏 | 当前修正按 `compareDocumentPosition` 继续于原阅读位置，正反遍历保留位置；关闭后恢复原触发器 | 已只读复核来源/摘要两条回归及浏览器 source 链路；修正后的精确 head 运行结果尚待核对 |
