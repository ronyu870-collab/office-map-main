# 历史结构化数据独立入库

用户明确指出不需要上传原件。本地归档已经核对，因此取消历史佣金/参数发布对云端原件的依赖；既有云端资料继续使用原私有存储路径及签名机制，不删除原件。

新增迁移仅允许已授权历史资料使用local_archive，storage_path必须为NULL，archive_reference与源文件SHA-256一致；当前房源仍不允许该模式。API继续使用现有身份、角色、楼宇范围，只跳过本地归档记录的Storage签名调用。没有原件链接时隐藏预览按钮，备注和来源页码保留在展开内容中。

真实PostgreSQL17执行25项回归通过；独立导入脚本检查无需Storage、ready发布、未知日期、重复导入与现行资料拒绝。API测试检查数据可读但不签名，缺失cloud路径不能冒充本地归档。组件测试验证备注/来源、无预览入口以及混合版本返回操作；这些回归均在CI执行。

本地IAB合成资料已经验证桌面和390×844窄屏，佣金和项目字段可读、来源可展开，在线原件按钮不出现。没有使用真实手机；本地浏览器证据不等同于生产会话验证。发布和实际入库结果记录在项目交付目录。
