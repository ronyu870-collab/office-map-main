## 证据边界

自动浏览器运行生产构建和真实 React／MapController 执行路径，使用隔离授权数据与高德 SDK 适配器，不向生产数据库写入。几何、状态与事件检查可作为本次布局和行为证据；不能当作线上真实瓦片、私有图片、真实手机软键盘或生产账号权限的实测证明。实际命令与最终结果记录在本次 PR，未执行的检查不计通过。
