## 已实现的主流程

打开管理员入口即读取现有历史成交，按成交期间＋录入租期自动显示未来六个月的预计到期候选。页面强调这是跟进参考而非合同到期事实。进入详情先看预计区间和计算依据；只有主动展开“补充资料或标记问题（可选）”才进入编辑区，查看候选不产生写入或审计事件。

H-08 已具备租期月份和成交季度，直接展示估算，无需先补起租证据。已有“资料不足”记录仍保留，以免抹掉早先发现；该标记不阻止候选显示。H-02 使用数据库现有录入值估算，同时明确提示来源差异，不擅自用本地工作簿覆盖，也不因此阻断其他线索。

页面可见名称调整为“预计到期线索”，数据库表／RPC／API 路径保持兼容。原始历史记录、已有备注、保存版本、请求幂等和审计均不改变；不修改数据库函数或权限。管理员身份校验、模拟身份禁止、撤权处理及并发冲突保护沿用原实现。

## 受影响执行路径

业务智能管理员链接 → 预计到期列表 → 详情即时估算 → 可选资料编辑 → 原 API → 原事务／审计 → 保存回读。新增行为主要是可选编辑区默认折叠、问题提示直接展示，以及选择记录后回到详情顶部。未编辑时返回清单不提示丢弃，也不发送保存请求；编辑后原离开保护继续生效。
