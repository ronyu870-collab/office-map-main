## 建议试用顺序与通过条件

1. 登录后阅读环境说明，确认是隔离预览及十条候选。对照私有清单找到 H-02。
2. 打开来源定位，核对租期单元格、表头、信息日期和 W0 差异。理解“候选区间”与“合同到期日”不同。
3. 在 H-02 的依据定位和备注补充人工发现，保持“来源差异”，保存；刷新，再次打开，核对内容和版本。仅在本地演练，不改原始成交。
4. 对 H-08 走一遍“单位明确但起租证据缺失 → 资料不足”；对 H-01 核对后续交易缺口。不得将“保存成功”理解为“已确认到期”。
5. 试用搜索、返回清单、范围切换。确认备注未保存时切换记录有提示；保存失败或版本冲突不悄悄丢失输入。
