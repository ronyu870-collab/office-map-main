## 可复现验证

- `npx vitest run src/app/map src/components/stacking-plan src/app/compare/__tests__/BuildingCompareWorkspace.test.tsx src/lib/broker`：相关 48 个文件、292 项通过；追加异步滚动恢复测试单独通过，共 293 项。
- `npx tsc --noEmit`、改动相关 ESLint、生产构建通过；Lint 保留现有告警，零错误。
- `scripts/verification/verify-map-continuity.mjs`：生产 React、真实控制器，隔离授权数据和 SDK 传输；桌面、手机、减少动态效果下验证往返、原分区/模式/视角/宽度/阅读档位、来源排序、两轮前进后退、未保存取消、慢刷新/失败、快速反向和 resize 次数。
- `scripts/verification/verify-map-workspace.mjs`：1536/1280/1024/768/390/320 宽度，检查地图、筛选、列表、研究、图表、浮层、长名称和短视口等既有行为。
- 同一“项目尺度至少 14”实际页面断言在只读 main 基线失败、新实现通过；覆盖原来只移动中心、不恢复合适缩放的问题。

隔离样本记录：600 单元就绪 138–181ms，筛选 39–50ms；关闭面板各 1 次 SDK resize；采样窗口帧间隔 P95 约 16.7ms、无超过 50ms 的长任务。这些是本地隔离适配器数据，不是生产高德渲染性能保证，也不是同设备完整前后性能对比。
