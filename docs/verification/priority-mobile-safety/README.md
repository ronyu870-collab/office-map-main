# 成交关闭保护、手机楼宇对比与季度指标一致性

日期：2026-10-25。开发基线：`c915b249326b2664f22a72fdb849f61c817a3e95`（main，#76）。

## 范围与行为

- 成交表单的遮罩、关闭、取消和 Escape 统一进入关闭保护；未保存时可继续编辑、明确放弃，新增记录还可保存草稿后关闭。保存失败或保存期间又有输入时保留表单。编辑记录不冒用新增草稿。保存／正式写入期间阻止关闭，并阻止重复进入同一写入。刷新／关闭网页使用必要的浏览器离站提示。
- 已有成交记录只在首次打开该记录时初始化，异步选项返回不覆盖用户已输入内容。公共 Dialog 与此抽屉共用滚动锁计数，确认层和父任务关闭后正确恢复页面滚动；其他界面的外观与组件参数保留。
- 楼宇对比在小于 1024px 时使用可展开的选择与筛选区，默认给比较结果完整宽度；桌面保留固定选择栏。固定指标列、最多五个竞品、目标单独计数、条件和差异开关均保留。指标分组改为真正的按钮并表达展开状态。
- 基线 main 已有手机单项目切换及完整指标对照，本次保留。桌面与手机共用 `quarterlyPresentation`；净有效租金显示两位小数，沿用手机已有精度，历史数值统一展示规则；比例／变化一位小数、面积变化整数。只读展示中的缺失使用 `—`，有效零值保留；无效输入不产生误导性派生值。原始存储、提交公式与 payload 未因显示格式改变。

本批按当前用户已授权的完整手机操作目标实施三处具体修复，不代表其他模块已经全部迁移。原工作区的地图、销控及其他未提交功能未纳入本批。
