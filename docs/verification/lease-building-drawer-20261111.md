# 楼宇成交抽屉本地验证

日期：2026-11-11（Asia/Shanghai）。分支：`codex/lease-visual-polish`；本地差异基于已取得的 `origin/main` `d898a8c`，包含此前确认的租赁成交视觉微调。

## 路径与边界

- 租赁成交填报 → 团队成交汇总 → 点击「成交楼宇」名称。抽屉根据所点击记录的 live UUID 在现有读取视图中查找楼宇 ID；仅在确认单栋归属后发起本楼及项目级查询。未确认楼座、未关联楼宇、当前权限范围内无数据分别显示。项目级记录默认折叠，不计入本楼数量。
- 复用地图的 `GET /api/lease-transactions/read` 和服务器有效角色判定；管理员可见当前和历史，编辑者／查看者只见当前，未知角色被拒绝。保留模拟身份请求头；脱敏演示不显示抽屉入口。原有地图默认组合范围、历史成交筛选及团队监控调用方式不变。
- 新入口只读且按点击加载。没有改变数据库定义、RLS、审计、保存、转交、导出或历史流程；原表格的展开、筛选、分页、管理及滚动容器保留。

## 验证

1. 实际页面与读取路由各增加 4 项回归，随 Vitest 入口进入仓库持续验证。页面覆盖 A／B 座切换、项目项折叠、未确认／未关联／空结果、失败重试、后续分页、键盘焦点循环与恢复、全屏保留、演示脱敏。接口在真实 Supabase JS SDK 的 HTTP 边界替换响应服务，执行 UUID 定位、各楼座与项目范围、分页、地图默认组合范围、管理员及模拟编辑者／查看者、未知角色与非法参数。
2. PostgreSQL 17.11 临时实例运行仓库现有视图定义和合成记录，以 `service_role` 执行实际查询，验证同 UUID 的历史记录不会被取为 live、A／B 座分离、参考楼宇、项目范围、排序分页、限制到 live 后的结果及地图原查询范围。探针位于 `/private/tmp/lease-drawer-preview/db-probe.sh`，无生产连接。探针首次因夹具记录编号冲突失败，随后因隔离角色缺少 Supabase 服务角色的 BYPASSRLS 设置返回空；修正临时夹具后通过。
3. Chrome `157.0.8103.50` 加载编译后的实际页面、表格和抽屉，认证和读接口使用合成样例。1440×900 检查右侧定位、A／B 座、项目级展开、Tab 循环、Esc、遮罩关闭、返回触发按钮，以及原页码、滚动和展开状态；390×844 与 320×720 的触控模拟检查全宽、无面板横向溢出、触控开关、管理员及查看者显示。首次焦点检查促成了 Dialog 在面板挂载后再定位焦点；后一次失败是脚本按收起前的按钮名称定位，修正定位后最终三种视口均通过。
4. 截图：本次 Codex 对话可视化目录内的 `lease-building-drawer-desktop.png`、`lease-building-drawer-mobile.png`。截图内容为合成数据，手机视口模拟不等同于真机验收。
5. 最终差异执行 `npm run verify`：审计覆盖、类型检查、Lint（0 错误，831 警告）、176 个测试文件的 1132 项测试和 Next.js 16.2.12 生产构建通过。首次运行发现回归夹具缺少必填的提交人姓名，补齐后通过类型检查。

未使用线上账户或生产数据；未验证真实 iOS Safari／Android Chrome，未提交、推送或部署。

## 补充：从单条成交详情打开抽屉

- 在填报页团队汇总展开公司详情后，「成交楼宇」置于第一项。点楼名复用主表楼名的打开事件，沿用原记录编号、楼宇范围、权限和关闭逻辑。展开本身不请求楼宇数据；无楼名、演示模式及未接入楼宇抽屉的团队监控保持原行为。
- `npx vitest run src/app/lease-submission/__tests__/building-deals-drawer.test.tsx`：旧组件运行新增回归时因展开详情没有楼名按钮而失败；修改后 5 项通过。回归覆盖查看者打开正确楼座、Esc 关闭并恢复到详情内的入口、保留原展开状态、空楼名和演示保护，随现有 Vitest 流程进入 CI。
- Chrome `157.0.8103.50` 加载编译后的实际页面和合成数据：390×844、320×720 触控模拟无需横向滑动即可点击（命中区约 80×44 CSS px）；1280×900 通过键盘打开。三种视口均核对所选楼座的成交结果、关闭后的焦点和原滚动位置；团队监控详情未出现入口。前后及抽屉截图位于本对话可视化目录，文件名前缀为 `lease-detail-building-`。
- `npm run verify` 通过：审计覆盖、类型、Lint（零错误）、176 个文件的 1138 项测试和 Next.js 16.2.12 生产构建。
- 独立搜索焦点门槛相对已取得的 `origin/main` 仍报告此前记录的五项覆盖登记缺口，见[视觉微调验证](lease-visual-polish-20261111.md)。本次仅验证本地差异，未做手机真机验收、提交、推送或部署。
