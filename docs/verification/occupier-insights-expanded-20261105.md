# 企业选址洞察：11张照片的完整滚动研究版（2026-11-05）

## 任务背景

上一轮交付声称生成19个阅读场景、11组图表、62条原始分类数值，但在当前容器和会话文件中均未找到声称存在的预览HTML与代码压缩包。因此本轮依据已发布的最新版报告及用户上传的11张现场演示照片重建，不能冒称与不存在的文件逐字相同。

## 变更边界

- 仅报告路由 \`/occupier-insights\`、该路由的专用内容、视觉、动效、测试与页面描述。
- 沿用上一轮已经进入main的“报告公开阅读、内部地图及返回首页仅登录可见”规则。
- 保留原生滚动、吸顶导航、滚动进度；增加视口内渐进显现及图表条形增长，尊重 reduced-motion，并在无JavaScript时保持完整阅读。
- 封面只保留品牌时间、报告标题、一句主张和滚动入口；不再显示无意义的“第三方调研·北京看楼应用”及页码。
- 11张照片中的有效图表全部进入正文，另提供行业差异、布局策略、全租期成本与现场看楼清单；不照搬照片的背景与原始版式。
