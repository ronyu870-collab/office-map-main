# 数据库编辑保护与手机记录工作区验证

记录日期：2026-10-26（任务于 2026-10-25 开始）。实现基于 main `35540862e71e6b448d568cfa6e622411cd782109`，工作分支 `codex/admin-edit-mobile-20261025`。本记录的截图、查询与操作均使用本机合成数据，不涉及真实账号、密码、业务删除、生产数据写入或外发。

## 实现与保护

- `GridPanel` 将尚未失焦的输入同步至编辑缓冲后再判断修改；保存、取消和待继续动作共用状态。原记录、零／空／false、字段错误与 JSON 原值分别处理。
- 换行、刷新、搜索／范围／视图、导入、删除／特殊动作及已接入后台导航使用保护；缓存核心表／自动发现表保持挂载。退出登录先处理编辑，再清理本账号对应暂存，不改变原鉴权流程。
- 手机 `<640px` 使用数据表选择器、记录列表、字段筛选、排序和全屏详情／编辑；桌面保留 AG Grid。共享字段配置、原始值、权限入口、选择身份及保存。触控表格行高、表单／动作命中区及可视视口处理只在适用变体生效。
- 结果模型同步表格顺序／筛选；统计、手机列表与导出使用同一记录身份，导出从正式记录取值。数值显示沿用桌面规则，保存不按显示舍入。
- 更新按原定位键和已有 `updated_at`（存在时）确认结果；没有返回行时保留编辑并报错。接口用法核对 [Supabase 官方 update 文档](https://supabase.com/docs/reference/javascript/update)，沿用共享客户端和审计，不改 Schema／RLS。
- 读取整批结果后才替换列表，分页失败保留上次完整数据。写入确认与刷新失败分开，刷新重试不会再次写入。解锁后重新获取记录及版本。
- 本页暂存使用 sessionStorage，按真实账号、表、过滤范围和数据视图隔离。首次恢复需显式选择；正式记录已变化时保留内容供核对，不自动覆盖。恢复原值、放弃、保存及退出登录清理相应暂存；存储不可用时明确提示。
- 文本／数字／布尔／枚举／关联／JSON／日期字段、只读／派生／隐藏及掩码沿用元数据。隐藏系统字段不因手机适配开放；时间戳不转成丢失时区或精度的日期。
