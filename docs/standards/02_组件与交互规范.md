# 高力国际组件与交互规范

版本：V2.1｜日期：2026-10-25｜尺寸、字号、层级值引用 [01 第 5 节](01_系统设计语言.md#5-页面容器与响应式)，本文件只维护结构和行为。

本文件中的变体、行为和验收条件是共同目标。已实现组件应优先复用；缺失变体须在后续获授权的实现任务中补齐，不能声称当前代码已经具备。

## 1. 共用组件与状态契约

- 基础组件入口为 `src/components/ui/`（相对仓库根目录）。不得在各页面复制一个同名 Button、Input 或 Dialog，再另写视觉规则。
- SDK 原生地图、AG Grid 等无法直接使用 React 组件的场景，通过适配层映射同一语义，不要求重写底层运行机制。
- 每类组件定义其适用的正常、悬停、按下、焦点、禁用状态；触控不依赖 hover，链接不强行增加无业务意义的禁用状态。涉及请求时补齐进行中、失败和成功状态。
- 字段区分空、已填写、无效、只读。已获权限展示的普通只读值保持可读可复制；掩码与敏感字段仍按原权限处理，禁用不能冒充“没有数据”。
- 操作使用 button，固定目的地导航使用链接；不能用不可聚焦的 div／td／span 承担主要点击行为。
- 图标按钮必须有可访问名称，说明真实动作；装饰图标对读屏隐藏。提示文字不能仅在 hover 时出现。

## 2. 页头、标题与导航

| 类型 | 结构与规则 |
| --- | --- |
| 应用页头 AppHeader | 模块名 → 可选状态 → 返回入口 → 必要动作；使用 01 的页头高度；只放全模块级动作 |
| 内容页头 PageHeader | 主标题 → 必要说明 → 该页动作；不得与应用页头重复同名标题和描述 |
| 后台栏目标题 | 栏目名与栏目动作同一行；简单说明一段即可；基线与下方工具条一致 |
| 路径导航 | 用于资料目录等层级；每段名称对应目的地，当前项可识别；长路径可收拢中间项 |
| 回首页 | 明确指向 `/`，文案为“首页”或“回首页” |
| 返回上一级 | 使用明确名称，如“返回业务智能”“返回地图”；不能写“主页”却指向其他模块 |
| 返回来源 | 需要保留来源状态时使用来源上下文，并提供明确的默认目的地；不得因 history 长度大于 1 就默认来源一定是本系统 |

- 一个页面正文仅设一个 h1，表达该页面主任务；只有模块页头、没有独立内容标题时由页头承担。页面另有主任务标题时，应用页头的模块名使用普通标识，不抢占 h1；字号由文字角色决定，不由 h 标签决定。独立对话框使用有名称的 h2，不改变背后页面的 h1。
- 窄屏可隐藏返回按钮的可见文字，但可访问名称必须保留，命中区执行 01。
- 新入口不得破坏浏览器返回、链接新开标签页和用户预期的导航方式。手机全屏编辑或分步路径需保留对象与草稿；页面内退出、浏览器返回和系统返回分别按可用平台验证。
- 筛选、分页或编辑状态是否随返回保留由模块规定；不得在换皮中默改既有状态行为。

## 3. 按钮与动作

| 变体 | 用途 | 规则 |
| --- | --- | --- |
| primary | 当前工作面的主动作 | 品牌色实底；同一操作组默认一个 |
| secondary | 取消、导出、刷新、辅助操作 | 白底、普通边框和主文字 |
| ghost | 查看、轻量工具、非主导航辅助 | 透明底；悬停有反馈 |
| danger | 已确认语义的删除、不可逆变更 | 危险色；不能仅靠颜色告知后果 |

图标按钮是表现形态，不是第五种颜色变体：使用 IconButton 并选择上述适当动作变体，必须有名称，不靠 title 单独提供必要说明。

- 正常控件使用标准／紧凑两种尺寸；窄屏命中区按 01 扩大，命中区不得互相覆盖。
- 加载中显示具体动作“保存中…”“上传中…”，阻止重复提交，但保持按钮原来的稳定宽度。
- 取消在左、确认主动作在右；返回不与删除混为一种样式。
- 主要动作用“新增成交”“保存草稿”“提交本季数据”等具体名称，避免无上下文的“确定”“继续”。
- 空输入或前置条件未满足时可按业务契约禁用，但必须能看出原因；不能只显示灰按钮。
- 成功通知的动词与动作一致，例如“保存草稿”对应“草稿已保存”，不能显示“发布成功”。

## 4. 输入、选择与表单

### 变体选择

- 一般搜索、表单、资料库筛选使用 01 的标准控件；密集工具条使用紧凑控件；表格内编辑采用紧凑控件及表格行高。
- 客户需求、公告和较长说明使用标准多行输入；表格备注采用 01 已定义的单行起自动增高变体，不再另设未说明的字号例外。
- Input、Select、SearchableSelect、日期控件、数字输入和 Textarea 共享所选变体的参数。同组不能有未经说明的高度、边框、圆角和焦点差异。

### 字段契约

- 每个字段必须有 label 或明确的 aria-label／aria-labelledby，显示标签与输入关联。placeholder 是例子或输入提示，不能代替字段名。
- 输入值使用主文字，placeholder 使用次级文字；不将弱化装饰色用于用户必须读懂的输入示例。只读、禁用和空值仍需可区分。
- 标签说明单位和必填性；特殊计价、时间精度等影响含义的信息在字段附近可见。
- 账号、邮箱、电话和密码按含义设置 type、name、autocomplete；业务搜索和普通编号不误触密码管理器。
- 数字字段允许合法零值和小数。不得仅因显示格式舍入而修改原值，不把空输入转换为 0。
- 已知固定枚举、且无需检索时使用 Select；楼宇、企业、人员等动态或需关键词定位的对象集使用 SearchableSelect。是否切换以检索任务决定，不以开发者随意判定“选项多”为依据。两者都支持键盘与明确选中状态。
- 校验错误紧邻字段，有文字原因和可执行修正方法，并与输入关联。提交失败保留输入；聚焦第一个相关错误，不把全部错误只塞进一条 Toast。
- 焦点轮廓统一且可见；不得使用 outline-none 后不给替代。
- 表单有未保存内容时，关闭／离开按现有保护契约提示或保存；不能因点击遮罩直接丢数据。
- 密码、权限等操作遵守对应服务及工具的授权流程，视觉规范不提供额外操作授权。

## 5. 工具条、筛选、页签与标签

| 类型 | 共同规则 |
| --- | --- |
| 查询工具条 | 搜索 → 主要筛选 → 可展开高级条件 → 重置／结果数；动作与范围一眼能看出 |
| 激活筛选词 | 显示实际条件、可逐个移除，多个条件有统一清除入口；不得只显示“已筛选”而不说明范围 |
| 页面导航页签 | 下划线表示当前页／区；需要导航时使用链接并保持路由状态 |
| 同页内容页签 | 分段底色，只能选一项；有对应内容面板，tablist／tab／tabpanel 关系完整，方向键切换 |
| 同一画布的互斥模式 | 分段控件；按单选组表达当前模式，方向键切换；不为满足 tabpanel 人为复制地图或表格 |
| 多选筛选 | 复选框或明确的可多选按钮组，使用 pressed／checked 状态；不能伪装成单选页签 |
| 状态标签 | 只表达状态，默认不可点击；非必要状态不逐行重复 |

- 页签和筛选使用标准或紧凑控件角色，纯状态标签使用状态标签角色；数值只在 01 维护，不用按钮尺寸误导状态标签可点击。
- 同类筛选控制复用一种选中和清除表现。颜色、图标与文字的作用稳定。
- 默认选项和筛选作用范围必须可知，如“当前目录”“本季”“团队成交”。不默默将页面筛选作用于范围不同的导出。
- 筛选改变后的分页、排序和 URL 行为按既有模块契约保留；需要改变时单独列为产品决策。

## 6. 表格、列表和卡片

- 默认采用一个连续工作面，结构为工具条／结果状态 → 表格或列表 → 分页。卡片用于真正独立的对象，不为每个字段再套卡片。
- 标准／紧凑表格和表头按 01 的文字、行高及内边距角色执行；换行、错误与编辑状态允许增高，不裁切内容或压缩字号。
- 名称、类别左对齐；数值右对齐并采用 tabular-nums；日期在同一列保持一致；单位放列头或字段说明。
- 值的显示执行 [04 第 1 节](04_数据与内容规范.md#1-事实口径与身份) 的唯一映射：无内容占位与有业务含义的未知／未确认不混用；加载或读取失败不显示为空值。
- 长楼名、公司名优先换行或提供完整详情；截断不得导致无法区分对象。原生 title 可作补充，但不能成为手机唯一完整内容入口。
- 排序方向、筛选激活、选中与编辑状态必须可辨；鼠标 hover 不冒充选中。
- 固定表头／关键列用于定位，不能遮挡焦点和菜单。横向滚动限制在表格容器内，窄屏保留主要字段与详情入口。
- 分组折叠使用 button，支持键盘，明确 expanded；不能只给整行 td 加鼠标点击。
- 分页统一显示当前范围、总量及前后页；每页数量按业务契约，视觉统一不等于强改 API 或全部页面大小。
- AG Grid 与普通表格共享颜色角色、密度和工具条语言，保留列筛选、锁定、导入导出及编辑行为。
- 桌面转手机列表／卡片时保持同一对象身份、操作权限、完整详情和反馈；不得维护两份容易漂移的数据事实。

## 7. 弹窗、抽屉与地图非模态面板

| 类型 | 适用任务 | 结构与尺寸角色 |
| --- | --- | --- |
| Dialog | 确认、单任务编辑、聚焦阅读 | 标题与关闭 → 可滚动内容 → 底部动作；按内容选择 01 的 Dialog 尺寸，默认 md |
| Drawer | 与当前工作连续的详情或较长编辑 | 右侧打开，选择 01 的阅读或复杂编辑宽度；窄屏全宽，标题／页脚固定、内容滚动 |
| 非模态地图面板 | 一边看地图一边查关联信息 | 使用 01 的地图面板角色；不加阻断全屏遮罩，不声明 aria-modal=true |

- Dialog／模态 Drawer 有清楚名称，只让最上层模态接收键盘焦点，背景及父任务暂停交互；关闭后回到触发控件，原控件已不存在时回到同任务的合理入口。全宽窄屏面板处理安全区域。
- Esc、关闭按钮、遮罩点击的语义一致；保存中、危险确认或未保存内容可禁止直接关闭，并解释原因。
- 关闭只影响当前层。最多一层主任务与一层必要子任务；子任务统一为 Dialog，不在 Drawer 上再开 Drawer，也不在 Dialog 上开 Drawer。更多详情改为当前面板内导航。
- 非模态地图面板不把焦点强行困住，保留关闭、Esc 和与地图的连续操作；不能为了复用 Dialog 把地图锁死。
- 自定义原件查看器、编辑器等保留必要尺寸和操作，但标题、关闭、页脚与外层规则一致。手机复杂编辑可采用 01 的命名全屏变体；它仍是同一任务层，不借全屏绕过焦点、返回或未保存保护。
- 浏览器系统确认用于离站保护等必要场景；站内可替代的业务确认后续统一为共享确认结构。不得把必要保护删掉来“减少弹窗”。

### 层级与滚动

采用 01 的全局层级表和浮层菜单规则。SDK 内部层级封装在地图局部堆叠上下文中，不能与全局层级直接比较或粗暴批量替换。打开子任务前关闭父菜单；只让当前层处理 Esc，避免一次关闭多层。

内容滚动限制在当前面板内，不把滚动链传给被锁住的页面；标题和动作保持可达。自定义 SDK 面板同样执行可访问名称、关闭及滚动规则。

## 8. 加载、空结果、错误与通知

| 状态 | 默认表达 | 行为 |
| --- | --- | --- |
| 首次加载 | 与目标结构相近的骨架或“正在加载…” | 标识 busy；不能把未加载显示为 0 条 |
| 局部刷新 | 保留已知结果，局部忙状态 | 失败时明确旧数据仍在，不能冒充新结果 |
| 真实为空 | 说明当前范围内没有记录 | 有适用动作时提供新增或返回 |
| 筛选无结果 | “没有匹配记录”，显示筛选上下文 | 提供清除／调整条件 |
| 请求错误 | 原因与重试／修正入口 | 保留输入和可用信息；需处理错误持续可见 |
| 成功 Toast | 简短具体，如“草稿已保存” | 时长及暂停条件按 01，可提前关闭；不承担唯一的重要凭据 |
| 警告／错误通知 | 清楚原因和下一步 | 必须处理时不自动消失；字段错误同时出现在字段旁 |

Toast 统一挂载到顶层通知区，位置、尺寸、时长和层级按 01，颜色按其状态文字规则。一般异步状态使用礼貌通知，需立即处理的错误提供明确告警；不抢走用户正在输入的焦点，字段错误仍在字段旁呈现。

## 9. 组件验收最低条件

新建或调整的组件必须在其适用状态中验证：长文本、空值与零、禁用／只读、字段错误、进行中、失败、窄屏，以及键盘操作。只在静态正常状态“看起来一致”不算组件完成。

图标使用 01 的图标角色，不能混入表情符号作为常规操作图标。

## 10. 手机交互契约

### MOB-02

同一角色在桌面可完成的业务动作，手机必须有可达路径，功能清单以 03 的 MOB-01 为准。所有入口有触控及适当键盘语义，不把 hover、右键、拖拽或快捷键作为唯一操作方式；可用显式菜单、按钮、列表选择等完成同一结果。触控尺寸、全屏编辑和安全区域参数只在 01 维护。

软键盘打开、收起和切换字段后，当前输入、字段错误及保存／取消仍能到达；不因固定页脚覆盖输入而阻断任务。横竖屏切换保留同一编辑上下文与既有草稿能力。密集表格可以横滚、逐行编辑、列选择或详情编辑，不能隐藏必要字段或把只读详情冒充可编辑能力。

浮层内搜索、选项、菜单、关闭与子任务均归属当前操作层；触控滚动不误触地图、背景或批量选择。地图平移／缩放与面板滚动应可分别操作，不要求像素级点按才能打开必要资料。

### MOB-03

手机文件流程覆盖角色可用的选择、上传、取消、重试、原件预览、下载／导出和批量结果；路径、对象与权限沿用业务契约。文件操作被浏览器限制时提供同结果的可用路径并验证，不把失败写成成功，也不以要求切换电脑作为完成标准。无可用路径时该项保持未完成。

批量动作明确选择范围、数量、确认后果及逐项／部分失败结果。手机折叠列表后仍能看到选择状态并取消；缩减屏幕空间不能改变导出范围、批量作用对象或操作授权。

### MOB-04

暂离应用、网络失败、重复点击、页面返回或重新进入时保留既有输入、草稿恢复、对象身份和提交保护。请求尚未确认时说明状态；不得因重试按钮新增重复业务记录。无法保留的非持久交互状态需有清楚恢复路径，不能让手机成为绕过业务可靠性机制的另一套流程。

验证使用隔离数据与已授权环境；不得为测试手机流程执行真实删除、修改真实密码、发送消息或发布生产数据。测试方式与证据按 05 的 MOB-05 执行。
