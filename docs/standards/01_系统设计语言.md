# 高力国际系统设计语言

版本：V2.3｜日期：2026-11-02｜本文是网页视觉参数的唯一维护处；相关组件按 02 使用这些角色。

## 1. 视觉定位与阅读逻辑

系统服务办公楼研究、经纪人检索、填报及管理工作。整体采用柔和浅色工作区、清晰可读的深色正文和少量品牌深蓝；表格、表单和浮层可使用白色内容面，不将大面积纯白或深蓝作为整页默认背景。视觉主次由业务任务、文字成组和共同对齐关系形成，中英文执行同一标准。现有色值见第 2 节，本次不选定新的配色母版。

- 每页先明确一个主任务；主标题、关键操作和主体数据不能同时争夺注意。
- 主体记录、地图或表单应尽早可见。不得为了装饰增加重复标题、无意义英文眉题、无助于任务的 KPI 卡片或常驻技术说明。
- 先建立清楚的文字阅读主轴；相关标题、说明与必要注释成组，共享对齐边界。主次优先由位置、邻近关系、间距和少量字重形成，不把文字任意散放在四角。
- 同类信息的字体、位置、颜色与反馈保持一致；跨章节和模块复用同一组织规则，布局可随任务调整。大面积留白不能把相关内容隔成信息孤岛。
- 精简默认可见的重复说明、并列标题和控制项，通过明确的展开入口承接细节；来源、单位、数据边界及关键操作仍需可达，影响当前判断或安全操作的信息在当前上下文可见。
- 品牌标识使用已有原资产，保持比例。不得拉伸、裁切主体、重新打字替代，或随意添加底色改变识别。
- 白底表格、地图与研究图可以成为主要视觉，不要求每个页面配置照片、插画或大标题封面。

### 色彩强制规则

- 新增／保存／提交等主要业务动作默认使用品牌主色；危险动作按 02 使用危险变体。不得用亮蓝、绿色或橙色分别装饰相同等级的按钮。
- 颜色表示的角色在同一比较中稳定。区域身份、指标大小、指标类型、涨跌方向必须分别定义，不让一个颜色同时表达多种冲突含义。
- 涨跌不自动等于好坏；未经业务定义，不用红绿表达投资机会、风险等级或优劣排名。
- 数据分类色允许超出 UI 品牌色，但必须有图例或直接名称。不得为了“统一蓝色”删除数据区分能力，也不得为了丰富画面给每一项涂不同颜色。
- 普通有效文字与实际背景对比度至少 4.5:1；达到 24px 常规或 18.7px 粗体的大字至少 3:1。禁用／非交互装饰不作为正文验收，但不得承担必读信息；透明度和底色变化后的最终颜色仍要复核。必要状态不得只靠颜色。
- 状态文案默认明确分工：成功提示正文使用主文字，图标／状态线用成功色；警告正文用 `#855100`；错误正文用危险色；普通信息正文用主文字或品牌色。不得直接把成功图标色套给浅底小字。
- UI 不使用装饰性渐变、霓虹色、大面积深色背景或强投影。照片、已有品牌资产及有数据意义的连续色阶不受装饰性渐变禁令限制。

## 3. 字体、字号与字重

网页使用 `Arial, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。独立数值列使用等宽数字特性 `tabular-nums`；业务数字不默认改成等宽字体。中文报告字体另见第 8 节。

同一画面默认从标题、正文两档字号开始，采用一套字体系统、最多两种常规字重；这是落实简约统一偏好的执行默认，不冒称用户逐参数指定的品牌规范。正文、按钮、图例、说明和数值优先同档，不因存在多个内容角色就另设字号。中西文字库的必要回退不算另造风格。

| 文字角色 | 默认选用 | 字重 | 行高与规则 |
| --- | --- | --- | --- |
| 页面主标题 | 20px，作为标题档 | 600 | 1.25；避免与应用页头重复同名 |
| 正文、标准表单、标准表格 | 14px，作为正文档 | 400 | 1.5；段落说明可用 1.7 |
| 紧凑工作面 | 正文档改用 13px | 400 | 1.5；同组工具条、表格、标签和说明共用，不再逐角色分档 |
| 应用页头标识、区域标题 | 复用所选正文档 | 600 | 1.5；靠分组、间距和字重组织，不默认新增字号 |
| 单位、来源、计数、图例、状态与说明 | 复用所在工作面的正文档 | 400 | 至少 1.5；不默认缩小，必要强调沿用 600 |
| 业务数值，包括主要指标 | 复用所在工作面的正文档 | 400 | 与名称、单位成组；必要强调沿用 600，不默认独立放大 |
| 独立开篇标题 | 确需开篇时标题档改用 24px | 600 | 1.25；替代普通标题档，不额外叠一档 |

现有 12/13/14/16/20/24px 令牌继续保留供兼容和有依据的场景使用；令牌存在不表示一屏要用齐。上表替代 V1 按角色逐档配置的默认方法，控件文字选用同步执行第 5.1 节。确需额外字号或字重时，按 06 记录位置、用途、可读性依据与验证；不能以“角色不同”或罗列例外恢复多档层级。

- 新增界面正文、关键表格字段、输入值和必读提示不得小于 12px；标准用 14px，紧凑用 13px。不得继续新增 9—11px 的关键阅读信息。
- 密集地图标记保留名称与必要指标同为 12px 的专项尺寸，不推广为普通说明文字的默认值；任务中列明所用标记范围并在实际尺寸验证。放不下时减少默认信息、改变缩放层级或按需展开；仍需偏离时按 06 记录，不能只缩小数字。
- 每个阅读区域最多一个主要强调组。标题、表头、全部数值、标签和说明不得同时加粗。
- 内容页标题优先完整换行；应用页头的模块身份、导航或紧凑工具条允许截断，并保留完整可访问名称。数据表长名称按 02 处理。

| 页面内边距 | 窄屏 16px、桌面 24px；全屏数据工作区允许 12px 的密集变体 |

## 5. 页面容器与响应式

页面容器采用下列变体。V1 目标值用于后续改造；当前首页等已存在的不同宽度不在本轮自动修改。

| 变体 | 默认宽度 | 用途 |
| --- | --- | --- |
| 阅读页 | 最大 800px，居中 | 连续说明、简单详情 |
| 表单页 | 最大 640px，居中 | 单任务独立表单；复杂填报采用工作台变体 |
| 业务工作台 | 最大 1440px，居中 | 记录查询、常规资料与业务操作 |
| 全屏数据 | 可用宽度 100%，无统一最大宽度 | 地图、数据库、密集多列表格、季度填报 |
| 首页 | 视口小于 1536px 时最大 1240px；从 1536px 起最大 1360px | 保留现有入口与团队动态关系，作为命名例外 |

- 同一容器类型的标题、工具条、主体和页脚共享左右基线。
- 断点按 CSS 视口宽度：窄屏 `<640px`、中屏 `640px≤宽度<1024px`、桌面 `≥1024px`；1280px 与 1536px 可用于宽屏密度调整。输入设备的触控要求另按实际 pointer 能力判断，不因宽屏而免除。
- 固定侧栏在窄屏必须可收起或改成面板；不得始终占用 280px 使主内容失去可用宽度。
- 文本段落不产生页面级横向滚动。密集比较表允许在自身容器横向滚动，固定关键列；不能用裁切隐藏必要列。
- 长表、编辑抽屉和地图应各有明确主滚动区。保持安全区域，底部操作不得遮住最后字段或系统手势区。
- 所有网页模块，包括复杂后台，手机与桌面保持同一角色的完整业务能力、事实和状态，执行 03 的 MOB-01。允许表格转列表、逐项编辑或全屏面板，完整字段和原件入口始终可达；不得以“请用电脑”替代手机操作。

## 6. 图表与地图视觉规则

- 先说明要比较什么，再选择图形。地图定位、图表比较、文字解释通过同一名称、编号和顺序关联。
- 同一比较使用可比尺度；租金与空置率不共用一根数值轴。条形从零起并保留负值；双轴各自标明指标和单位；折线不平滑虚构节点。
- 背景网格最轻，基准线次之，真实数据最突出。没有比较任务的边框、网格和图例删除。
- 所有必要数值、单位和颜色含义能被直接识别。不能只靠鼠标悬停才能了解关键结论。图表标签按坐标、行列或图形关系排列，名称、读数和必要单位成组；不为强调个别数值将文字散放到画面四角。
- 地图主环路连续、地理关系真实，图形简化不能挪站点、改相邻关系或把示意范围画成精确边界。
- 地图区域色、指标色阶、对比组色由对应模式定义；切换模式必须同时更新图例。地图数据色不等于 UI 状态色。
- 仅有子市场汇总数据时，不绘制伪楼宇热力图、企业迁移路径或自创机会评分。

## 7. 动效

普通悬停／按下反馈默认使用现有 120ms，常规状态切换 180ms；抽屉／弹窗默认 180ms，仅长距离位移允许 240ms 并记录所用变体。展示模式的叙事动画由专用稿件规定，不套用网页微交互时长。

- 动效只解释用户动作、状态或空间变化，不给每张卡片做入场动画。
- 优先使用透明度和位移；列明过渡属性，不默认 `transition: all`。
- 减少动态效果模式下移除非必要动画。加载提示仍须清楚，但不得依赖持续跳动表达业务状态。
- 用户关闭、切页或接管后取消旧回调，不让动画把页面带回已离开的状态。
- 自动播放仅用于明确的展示模式；暂停、继续、接管与返回规则按模块规范。

## 8. 网页与其他媒介的边界

网页与打印／报告统一对象身份、指标含义、来源与必要限制；固定画布尺寸和专用字体由相应媒介规范负责，不由网页参数覆盖。客户方案的网页编辑与预览须完整支持手机；打印版可重排分页但不得删除影响判断的字段与限制。

独立网页开发所需参数均在本仓库。跨媒介任务另加载任务提供的报告／展示原始规范；缺少媒介依据时只暂停依赖它的跨媒介部分，不阻塞独立网页工作。不得从网页当前色值反推“高力官方标准”。
