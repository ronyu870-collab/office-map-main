# 高力国际网页系统规范索引

版本：V2.1｜日期：2026-10-25｜适用于本代码仓库全部网页模块，包括复杂后台与手机端。

本目录维护长期网页规范的唯一正文。独立检出本仓库时，从 [AGENTS](../../AGENTS.md) 进入即可完成必需阅读，不依赖开发者本机的父目录。规范随对应代码版本交付；目录存在不等于已提交或已进入远端。提交／推送及当前任务进度由任务记录另行说明。

## 1. 长期原则与状态

**GOV-01：按任务授权执行。** 本地可逆且属于当前任务范围的工作直接完成；审查、规范和计划不自动授权代码实施、生产写入或发布。已有明确授权按其范围执行，不重复确认。关键业务信息缺失时只暂停依赖它的部分，继续独立工作。

**GOV-02：规则、实施与证据分开。** 文档目标基线约束后续已授权工作，不表示系统已经全部符合；当前源码证明现状，不自动成为正确标准；检查通过只覆盖已检查的版本、角色和环境。任务阶段、排期及进度不写进长期 AGENTS。

**必须／不得**为适用范围内的约束；**默认**用于无专项规定的选择；**候选**不能当作已选方案。例外须按 06 记录范围、依据和撤除条件，不能取消授权、业务保护或手机完整能力。

## 3. 规则适用与冲突处理

1. 先遵守运行环境上级指令、工具权限及用户当前明确任务。用户的当前决定可以调整项目默认值；不可据一般审查要求扩大实施范围。
2. 按实际路径读取适用 AGENTS。父目录存在时一并遵守；更深路径的明确专项仅在其范围补充或替代同一事项，不能推定取消未涉及的共同保护。独立检出无需找回本机父目录。
3. 按责任文件选择规则：视觉查 01，交互查 02，模块能力查 03，数据查 04，验证查 05，变更查 06，架构查 07。仓库命令与合并门槛查 AGENTS。
4. 共同视觉、架构与业务保护同时满足。布局和 SDK 例外不能减少手机功能、取消日期确认、权限、草稿和真实数据要求。
5. 若同一范围仍存在不能同时执行的要求，说明证据与建议，只暂停依赖它的工作；由明确用户决定、替代说明或适用例外消解，不能只选最新文件。
