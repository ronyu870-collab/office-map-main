# 高力国际规范维护与决策记录

版本：V2.5｜日期：2026-11-11｜只维护规则元信息和决定，不复制参数表、业务完整流程或实时任务进度。

## 1. 唯一来源与修订方法

- 各主题责任与专项入口由索引登记。先改责任正文，再改必要引用；不得在文末追加相反要求而保留旧正文。
- 网页规范正文在本仓库内，根目录旧路径只做导航转接。参数目标在 01、运行值在代码，通过规则映射核对；如采用生成表，明确生成源，不再维护第二份手工数值。
- 稳定规则的含义改变记录日期、依据、影响、替代项及实现状态，并递增版本。根 AGENTS 与网页规范可各自编号。
- 已提交版本的一般修订用 Git diff 和简短说明追溯；重大基线发布或尚未提交的文档仍保留修订前快照。未入 Git 的规范不能仅因“以后可看 Git”就删除原稿。
- 重大架构、业务或共同接口选择记录正式决策；常规措辞、格式、链接修正不另造决策或重复日志。工程影响由 CHANGELOG 简述并引用，任务范围和进度由当前计划维护。
- 所有规范修改只在当前授权范围执行，不自动启动代码迁移、生产写入、外发或部署。

### N31

**地图搜索首字符后失焦。** 2026-08-25，[地图 2.0 改版 PR #8](https://github.com/ronyu870-collab/office-map-main/pull/8)（`2f4725a`）将任意非空关键词计入已生效筛选，并让输入框和条件标签在同一个位置互斥显示。首个字符立即写入关键词，标签因此替换了正聚焦的输入框；节点被移除、焦点丢失都发生在防抖之前。Chrome 对照重放中，改版前 `b5ad026` 能继续输入，改版后不能。最早可核实的受影响[正式部署](https://vercel.com/ronyu870-9030s-projects/colliersdata/2mM9vzHduwvaTHB6526B2JJ2hNuR)为 2026-09-23 09:40（北京时间，`0954ff2`）；11 月 4 日完整列表上线前的 `c8eb14d` 也能复现。

**测试为何漏掉。** [PR #8 的工作台测试](https://github.com/ronyu870-collab/office-map-main/blob/2f4725aed8f33ec64990fbededffd9d20aeb7a07/src/app/map/__tests__/MapWorkbenchView.test.tsx)用搜索框替身与固定关键词渲染，检查静态显示、按钮回调和面板切换，没有从真实输入走到父级关键词更新和工具栏重新渲染，也没有断言下一字符能继续输入、焦点仍留在原控件。完整列表发布前的共享查询验证也不能替代原地图的逐字输入验证。

**修复证据。** [PR #99](https://github.com/ronyu870-collab/office-map-main/pull/99)固定保留搜索框，把标签放在独立区域；三条新增执行回归在旧实现失败、修复后通过，并随 [Verify](https://github.com/ronyu870-collab/office-map-main/actions/runs/41982215106) 运行。生产版 `b0decab` 发布后，用户刷新正式站确认连续输入和筛选更新期间焦点均正常。本次新增的是长期验收规则，既有地图回归不代表所有搜索入口已经覆盖。
