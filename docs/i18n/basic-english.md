# 基础中英文界面与房地产专业术语库

本轮只做**低风险基础英文化**，默认语言为简体中文；首页右上角用户菜单提供「简体中文 / English」切换，选择保存在当前浏览器的 `localStorage`，无服务端访问、无页面刷新、无账号／角色／业务数据修改。浏览器禁用存储时，本次页面会话内仍可切换，关闭后可能无法保存偏好。

当前接入范围：主页顶部与业务导航、登录页、密码设置页及基础菜单提示。**不承诺全站翻译**：AI 对话、团队动态、地图业务页面、复杂表格、PDF／PNG／Excel 导出、用户填写的名称和备注仍保留原文。未翻译文字保持中文，不对数据做自动翻译，也不按浏览器语言推断业务指标。英文模式与中文模式的数据库 ID、数字、功能权限、数据范围完全一致。

- `src/i18n/messages.ts`：界面原文到英文的轻量映射。切勿把用户数据或数据库状态放入此映射。
- `src/i18n/useLanguage.tsx`：跨页面与标签页同步、本地持久化和 `html[lang]`。
- `src/i18n/professional-glossary.json`：按平台、地理、楼宇、面积、租赁、交易、市场研究、堆叠图、数据治理、单位分类的专业术语。
- `supabase/migrations/20261120021000_basic_english_glossary.sql`：同一词库的只读内部数据库快照，创建 `public.i18n_professional_terms`，开启 RLS、禁止浏览器直读写，仅 `service_role` 可查询。新词或订正应更新 JSON 并通过新迁移同步，不回写历史业务数据。

受影响的主要操作是切换 → 留在原页面 → 客户端即时更新 → 再次访问保留选择。系统未实现全站 i18n，后续应逐模块显式接入，不能将本次标记为“英语全站覆盖”。
