# 地图 Phase 02：紧凑工作台与实心子市场气泡

本阶段从 main `2a64b568` 开始，交付前同步 main `585ddbaa`，整合已合并的 [Phase 01 PR #319](https://github.com/ronyu870-collab/office-map-main/pull/319) 数据契约。独立分支 `codex/map-vnext-02-workbench-design`；合入 main 按当前用户授权执行，不执行生产数据写入。

## 呈现与交互

- 保留顶部导航、工具栏两组结构。标题、统计范围和四项指标成组对齐；KPI 去除独立灰卡，以固定列和等宽数字稳定导航位置。混合季度明确标注，展开显示实际季度范围；面积按万㎡呈现，展开可读精确平方米。
- 页面继续采用 14/16px、400/600 两档字重及共享设计令牌。视图、搜索、模式、图例和工作区入口自然分组；窄手机改用模式选择框，保留全部模式。地图搜索新增可触控清空，取消旧防抖且不触发定位，保留候选、IME 与键盘提交。
- 子市场采用统一 108px 实心圆，不以大小暗示市场规模。薄白边、轻阴影；蓝色色阶只表达当前指标区间，选中状态用外轮廓。租金阈值 100/200/300，空置率 10/20/30%，LEED 20/40/60%；图例随聚合层级及模式同步。
- 活跃 V3、原生回退及区域资料占位共用 `mapSubmarketPresentation.ts`，消费 Phase 01 聚合事实，未增加统计引擎。默认/租金优先租金，空置模式优先空置率，LEED 优先认证；完整事实通过可访问名称和详情保留。产业园显示实际产业园数量，缺行情与仅区域资料各有短状态，真实零不抹去，未经核实的参考租金不展示为正式观测。
- 碰撞避让修复左右工作区作为地图兄弟节点而被遗漏的问题；面板开合与尺寸变化触发重排。读取动画中的实际位移，避免重复稳定事件累积漂移；地图手势期间冻结，结束后稳定，不创建新地图实例。
