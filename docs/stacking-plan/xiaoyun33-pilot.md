## 业务与权限边界

1. “已租／空置面积”是 **来源图片的标注面积合计**，不是当期经营空置率或实时租赁销控。未知面积不计入合计；“其他用途”独立表示。
2. 单元横向宽度用来源面积比例，不代表平面几何。面积未知单元使用等宽占位，不能凭视觉比例估算其面积。
3. 编辑只修改新的草稿空间，不回写原始成交库、楼宇指标或业主销控。数据库禁止前端直接 CRUD。租金阶段源字段只读，待下一批引入有日期/来源证据的专用编辑和批量原件解析。
4. 所有导出先向 Admin 专用 API 登记格式和身份；客户端生成文件。Excel 含来源、审核状态、备注；图片含来源日期提醒，不应外部传播作为确认证据。
5. Admin 若要提升为真实核验事实，必须先确认截图的数据日期及含义，并按 04 DATA-01 进行审批；本次没有代用户猜测日期，也没有开放发布按钮。
6. 库中的原图尚未另行归档为项目私有 Storage 原件，本次来源凭据为对话截图及其文字转录。未来源文件私有落库应另行建立可回溯的 object_key，不应把对话路径当作长期可下载链接。
