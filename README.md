# Colliers Data Platform

高力国际办公楼市场数据平台。

系统包含核心地图、季度数据填报、云端资料库、租赁成交填报、公告与市场信息交流，以及相应的管理功能。

## 本地开发

```bash
npm install
npm run dev
```

环境变量请参考 `.env.local.example`，不要将真实密钥提交到代码仓库。

## 规范与开发入口

开始任务前先阅读 [AGENTS.md](AGENTS.md) 和以下四类规范，并检查本次涉及的模块说明、代码与测试。

| 文档 | 解决的问题 |
| --- | --- |
| [产品规范](docs/standards/product.md) | 模块职责、角色权限、数据口径和需求边界 |
| [设计与交互规范](docs/standards/design.md) | 保留现有成熟设计，统一同类用途，记录场景差异和代码核查基线 |
| [开发与数据规范](docs/standards/engineering.md) | 组件复用、数据访问、可靠性、性能、验证和维护 |
| [验收与发布规范](docs/standards/acceptance.md) | 影响范围检查、每批前后对照、功能验证、发布和回退 |

**执行已确认的部分，保留待定状态。** 文档中的“沿用”和明确“已确认”内容继续执行；“建议”“待定”不因存入仓库自动变为已批准要求。规范调整时同步记录确认状态、适用范围和理由。规范入库不代表全站重构或功能改版已获授权。

现有模块经过反复打磨。以实际界面和业务行为为基准，保留合理的布局、信息密度、操作位置及细节；发现差异先区分应保留、已确认需修复和待核实。先完善兼容现状的公共组件，再小批迁移，每批界面改动提供前后对照，检查实际受影响页面并保留回退依据。

有实质影响的代码改动执行 `npm run verify`；所有合并遵循 `AGENTS.md` 的最终提交 Verify 门槛。变更原因、影响、验证和遗留工作记录在 [CHANGELOG.md](CHANGELOG.md)。
