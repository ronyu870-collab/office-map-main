# Colliers Data Platform

高力国际办公楼市场数据平台。

系统包含核心地图、季度数据填报、云端资料库、租赁成交填报、公告与市场信息交流，以及相应的管理功能。

## 本地开发

```bash
npm install
npm run dev
```

环境变量请参考 `.env.local.example`，不要将真实密钥提交到代码仓库。

所有模块含复杂后台必须支持同一角色在手机完整操作。规范是后续开发约束，不表示现有系统全部符合；规则采用、代码实现、验证、合并和生产发布分别记录。原四类规范只保留转接与历史锚点，具体替代关系见索引。

保护经过打磨的合理设计、业务含义和未提交修改；先核对明确版本与实际问题，再在授权范围内渐进修改。命令与 CI／合并门槛以 AGENTS 为准，非平凡变更记录在 [CHANGELOG](CHANGELOG.md)。报告和展示任务使用该任务提供的媒介资料，网页开发无需本机父目录。

向开发者或 Agent 交代任务时可使用：

> 先读取当前检出版本的 AGENTS.md 与 docs/standards/README.md，再读任务涉及的责任正文和专项。核对版本、入口、权限、既有修改与验收；保护现有合理设计，在授权范围内完成任务。手机与桌面保留同角色完整业务能力，准确记录验证、限制、提交和发布状态。
