# 季度研究的可维护源文件

2026Q3 的实际制作入口为 `2026Q3/原型/index.html`。这里只保留实际加载的 JS/CSS、已内嵌的路网、季度内容包、封面和字体子集；不依赖原始 PDF、外网字体或本机绝对路径。

在仓库根目录重新生成系统中的 HTML：

```sh
node scripts/quarterly-research/pack.mjs 2026Q3 private/quarterly-research/source/2026Q3/原型/index.html
```

`季度内容包/q3.json` 与 `editions.js` 保存同一季度内容，回归测试核对二者一致。`demo.js` 分别标记 `reported` 与 `illustrative`：Q2/Q3 为披露值，之前的季度序列为本次用户授权的管理员交互示意；区域历史示意不是原件底表。年度预测图除供应总量及2027空置率外也为示意。替换历史底表时应同时更新状态和页面图例，不只覆盖数字。

三季度指标表采用本期原列环比；各期披露水平之差作为另一字段计算。不能把这两种变化混写。原件疑点详见本次内容审计，本版不改写原件数值。

CBD、丽泽、运河及轨道图为网页原生区位/连接示意。全市线网为线路级概览，不复刻每个站名、不承担出行导航。未来分区堆叠图按原图结构示意，年度总量仍用原列值，不能把示意分段作为精确供应底表导出。

地图共享打包器位于 `scripts/quarterly-research/bundle.mjs`，识别 JS 动态地图资源并内嵌，不能放宽 CSP。Q2 仅修复相同路网依赖；其业务内容及交互脚本保持原有版本。

字体为沿用的 Research/Noto CJK 子集。增加新汉字后需确认字形覆盖，禁止用每种内容单设字号掩盖字体缺失。最终浏览器复核仍必需。
